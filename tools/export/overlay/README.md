# @APP@

어린이들이 종이 판 위에 지은 마을을 3D로 옮긴 마을 놀이예요.
우리 집 현관 앞에서 첫 아침을 맞고, 이웃의 부탁을 들어 주고, 마을을 걸어 다니며 알아낸 것으로 첫 마을 잔치를 함께 준비해요.

- 산·들·바다·강이 이어진 마을 하나를 걸어서, 자전거로, 버스·지하철로 돌아다녀요.
- 이웃의 쪽지(이야기)를 따라가며 방위·지도·지역 문제 같은 사회 공부를 몸으로 해요.
- 날씨·계절·하루 시간이 흐르고, 일터 일·장터·도감·마당 꾸미기가 있어요.
- 마법·몬스터 없이 실제 세상의 규칙만 써요.

## 실행

빌드 과정이 없어요. 폴더를 그대로 웹 서버로 열면 돼요.

```sh
python3 -m http.server 8000
# 윈도우: py -m http.server 8000
```

브라우저에서 <http://localhost:8000/> 을 열어요. 파일을 더블클릭해서 열면(file://) 모듈을 못 읽어서 안 돼요.

GitHub Pages에 올릴 때도 저장소 루트를 그대로 배포하면 돼요(`index.html`이 곧 게임이에요).

### 주소 뒤에 붙이는 것

| 붙이는 것 | 하는 일 |
|---|---|
| `?intro=0` | 처음 영상(인트로)을 건너뛰어요 |
| `?intro=1` | 처음 영상을 처음부터 끝까지 다시 봐요 |
| `?login=1` | 학급 번호로 들어가요(반 코드 + 번호 + 비밀번호 · 학급 저장소에 이어 저장) |

## 조작

| 키보드·마우스 | 터치 | 하는 일 |
|---|---|---|
| W A S D · 마우스 | 왼쪽 아래 막대 · 화면 끌기 | 걷기 · 둘러보기 |
| Shift · Space | — | 달리기 · 뛰기 |
| E | ✋ 행동 | 말 걸기 · 들어가기 · 같이 하기 |
| B | ☰ 메뉴의 🚲 | 자전거 타기·내리기 |
| Q | 이야기 칩 | 이야기(이웃 쪽지) |
| M · F · J | 칩 | 지도 · 장소 찾기(빨간 선 길 안내) · 바로 가기(이야기를 따라가면 하나씩 열려요) |
| I | 가방 칩 | 가방 |
| Esc | ☰ | 창 닫기 · 메뉴(언어 바꾸기·저장 칸·처음부터도 여기) |

처음 영상은 Space·클릭·터치로 언제든 건너뛸 수 있어요. 한 번 보면 다음부터는 짧게 나와요.

## 저장

- 이 기기(브라우저 저장소)에 칸 셋으로 저장해요. 서버로 보내지 않아요.
- `?login=1`로 학급 번호로 들어오면 학급 저장소(Cloudflare Workers)에도 이어 저장해요. 이름은 보내지 않아요.

## 외부 연결

- 아이 집 마당 꾸미기는 Firebase Realtime Database에서 읽어 와요.
- 함께하기 방(같은 방 친구)과 학급 저장은 Cloudflare Workers 서버를 써요.
- 그 밖의 그림·소리·글꼴은 모두 이 저장소 안에 있어요(three.js도 `lib/`에 들어 있어요).

## 폴더

| 폴더 | 무엇 |
|---|---|
| `index.html` | 게임 시작 쪽 |
| `js/` | 3D 엔진(카메라·물리·화면·학교 맵) · `intro.js` = 처음 영상 |
| `games/` | 마을 게임(`town.js`와 그것이 부르는 `town_*.js`) |
| `towns/` | 마을 자료(어린이들이 지은 판을 옮긴 것) |
| `lib/` | three.js |
| `img/photos/` | 장소 카드 사진(출처 = `CREDITS.md`) |

이 저장소는 원본 저장소에서 내보내기 스크립트로 만들어요. 여기서 직접 고친 것은 다음 내보내기 때 덮여요.
