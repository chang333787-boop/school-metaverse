# 품질 숫자 척도 (교사 10-08)

교사가 "○○ 4 · △△ 5"처럼 숫자로 요청한다. 1 = 아이들이 판에 올린 그대로, 5 = 유튜브에 올라올 정도.
**숫자를 안 주면 기본값**: 풍성 4 · 놀이 4 · 그래픽 3~4 · 효과 3~4(홍보판·영상 5) · 이야기 4 · 각색 3 · 완성도 4~5 · 직관성 높게.
마감 보고에는 항목별로 지금 몇인지 숫자로 적는다.

## 📦 풍성함 (분량·플레이 시간)
1. 장면만 이어서 3분
2. 장면 사이 이동·대화를 더해서 5~8분
3. 15분쯤 · 발견·할 일 8개쯤
4. 20~30분 · 발견 16개 · 자유 탐험
5. 40분 넘게 · 숨은 요소 · 결말 여러 개 · 다시 하고 싶어짐

## 🎮 놀이 (하는 방법)
1. 걸어가서 E만
2. 고르기·퀴즈·물건 줍기
3. 몸으로 하기 (이고 나르기·쫓기·타기·차례대로 밟기)
4. 능력 키 + 발견마다 하는 방법이 다름 + 내 행동으로 세상이 바뀜
5. 날씨·능력·주민 반응이 서로 엮이고, 같은 문제를 여러 방법으로 풂

## 🎨 그래픽 (모델·장소)
1. 빛기둥·상자 · 원래 학교 그대로
2. 기본 도형을 묶은 캐릭터 (몸통·머리 정도)
3. 표정·옷·소품 있는 캐릭터 + 장소 꾸밈
4. 장소를 통째로 새로 짓기 + 시간대·색감
5. 장면마다 새 배경 · 직접 만든 모델이 많음 · 그림 같은 구도
(로우폴리·새 조명 금지·크롬북 속도 안에서의 5)

## ✨ 효과 (움직임·연출·소리)
1. 글자·알림만
2. 반짝이·빛기둥·말풍선
3. 생물이 실제로 움직임 (뛰기·날기·쫓기) · 내 몸이 바뀜
4. 카메라 연출 · 화면 전환 · 소리 · 장면마다 분위기가 바뀜
5. 컷신 · 음악 · 타이밍을 맞춘 연출 (오프닝 영상 수준)

## 📖 이야기·세계관
1. 판 문장 그대로
2. 말투를 다듬고 빈칸을 채움
3. 인물마다 성격·말버릇 · 장면 사이 이음
4. 세계 규칙 · 안내서 · 다음 이야기 씨앗 · 작은 반전
5. 웃기고 찡한 감정선 · 복선과 반전 · 인물이 자람

## 🧒 각색 (아이 생각에서 얼마나 바꾸나 — 높을수록 좋은 게 아니라 방향)
1. 쓴 그대로 + 빈칸만
2. 문장 다듬기 · 빠진 연결만 채움
3. 하고 싶은 이야기는 그대로, 순서·장소만 다듬기
4. 장면을 몇 개 새로 더함 · 아이 장면은 다 살림
5. 아이디어만 씨앗, 줄거리는 새로

## 🛠 완성도 (다듬기·검증)
1. 돌아가기만 함
2. 끝까지 한 번 해 봄
3. 자동 시험으로 끝까지 · 오류 0
4. 3 + 실제로 걷고 점프해서 다 닿는지 · 휴대폰·크롬북 확인
5. 4 + 장면마다 사진 확인 · 여러 번 반복해서 다듬기

## 🧭 직관성 (처음 봐도 바로 아는지)
1. 설명 없음
2. 시작 때 글 한 덩이
3. 하는 법 창(그림 세 줄)
4. 3 + 화면 위 '지금 할 일' 줄 · 막히면 힌트
5. 4 + 처음 10초 안에 아무 설명 없이도 할 일을 앎(아이 시험)
