## 1. 모양(person 다시 짓기)
- 참고: `v2/js/kid.js`(buildKid 'a'·'b') · 스크래치 `char/sheet_v4.jpg`(시안) · `char/preview.html`(나란히 찍는 틀 — 네 작업 폴더에 복사해 써도 된다).
- 같은 결: 둥근 머리(아이 = 키의 ~38%, 어른은 ~30%로 덜 크게) · 목 없음 · 짧고 통통한 팔다리 · 얼굴 = 작은 세로 타원 눈 둘 + 가는 웃는 입(+ 아이만 아주 옅은 볼) · 코·귀·눈썹·입술·반짝임 없음 · **매끈한 음영**(world.js dGeo의 flat:false로 원래 법선 유지 — 확인할 것).
- 머리 모양: 바가지(kid.js 'a' — 위 덮개 + 뒤 반구 껍질) 기본에 여 = 단발·포니테일·양갈래, 남 = 짧게, 어른 = 조금 길게/묶음. 급식선생님 = 흰 위생모 + 앞치마, 청소선생님 = 작업복 색. 옷 색은 지금 TOPS/BOTS 팔레트 유지 가능.
- 성능: 사람은 청크에 합쳐진다(드로우콜 0). 한 명 ≤ 900 삼각형 목표(지금 몇인지 먼저 재라). 구역 닻 최악·9시점 예산(≤150k/200) 안.

## 2. 자세(서 있는 사람을 앉히거나 일하게 — 교실 선생님 제외)
- **그대로 둘 것**: 학년 교실 선생님(1~6학년 — 칠판 앞에 서서 학생 쪽) · 이미 자기 자리에 앉은 학생들.
- 바꿀 것(data.js `staff` — 지금 place()가 방 빈자리에 세운다): 보건선생님 · 사랑반/나래반/유치원/돌봄 선생님(교실형이지만 '교실 선생님'으로 볼지 판단 — 방 한가운데 멀뚱히 서 있으면 부자연스럽다: 책상에 앉아 있거나 아이들 옆에 앉아 있거나, 서 있더라도 칠판·교구 앞에서 설명하는 자세) · 유치원 아이 셋(작은 탁자·바닥 매트에 앉아 놀기) · 사서선생님(대출 데스크에 앉아) · 행정실 3(책상에 앉아 모니터) · 교무실 3(자기 책상에 앉아 — 교감은 앞쪽 큰 책상) · 교장선생님(교장실 책상 또는 소파에 앉아) · 급식선생님(배식대 뒤 — 국자 든 배식 자세 또는 손 앞으로) · 청소선생님(빗자루·대걸레로 쓰는 자세, 복도나 급식실 한쪽).
- 앉을 의자·책상·소파가 방에 없으면 알맞은 가구를 **하나** 둔다(그 방 가구 결에 맞춰 — 사람 수는 그대로). 앉은 사람 충돌은 지금 규칙(의자 위 0.85~키) 그대로, 길을 막지 않게(도달성·문 경로).
- 자세 표현: person(…, pose)로 'stand' · 'sit'(의자) · 'sitFloor'(바닥 매트 — 유치원) · 'work'(팔 앞으로 — 배식·키보드) · 'sweep'(빗자루 쥔 손 + 빗자루 소품) 정도. 팔다리 각도는 간단히(둥근 부품을 돌려 놓기).

## 3. 확인
- 사람마다 가까이서 1장씩(작게) + 방 전체 1장씩 비교판 → Read로 확인: 얼굴이 징그럽지 않은가(눈만 크고 텅 빈 느낌·입 두꺼움·목 긴 것 없게), 의자·책상과 몸이 맞는가(허공에 앉음·책상 뚫음 없게), 겹쳐서 깜빡이지 않는가(zf).
- ⚠️이미지를 볼 때는 작게(한 장 960×540 이하, 여러 장은 한 판에 모아) — 큰 그림을 연달아 읽으면 응답이 늦어져 작업이 끊긴다.
- 게이트 전부(감사 0 · 도달 전 구역 · 옥상 0 · 문 0 · passCheck 0 · 지도 계약 0 · 빠른/전체 검진 17/17 · --perf ≤150k/200).

## 결과(09-26 · world.js v117 · main v123)
- **모양**: `person()`을 kid.js 결로 다시 지음 — 둥근 머리(아이 ≈39%·어른 ≈29%)·목 없음·통통한 알약 팔다리(`pillG`)·작은 세로 타원 눈(팔각 윤곽)·가는 웃는 입·아이만 옅은 볼 · 코·귀·눈썹·반짝임 없음. 머리 = 바가지(덮개 + 뒤 껍질) + 여 아이 단발/포니테일/양갈래 · 남 정수리 한 올 · 어른 여 긴 단발/묶음/올림머리. 급식 = 흰 위생모 + 앞치마 + 국자 · 청소 = 회청색 작업복 + 빗자루.
- **매끈한 음영**: 예전 `dGeo`는 법선을 싣지 않아 병합 때 면 법선(flatNormals)이 되어 `flat:false`여도 각졌다 → `dGeo(..., { smooth: true })`가 원래 법선을 역전치로 돌려 청크의 `ch.nor`에 싣는다(그 청크만 · splitRooms도 따라감). 확인: 디테일 메시 17개가 정점마다 다른 법선.
- **삼각형(한 명)**: 전 652~824(평균 731) → 후 724~896(평균 ≈840, 55명 ≈ 46k). 목표 ≤900 충족. 사람 부품은 곡면(dGeo)이라 감사(상자) 밖 — 겹치는 둥근 부품은 크기를 달리(머리 R·뒷머리 1.06R·덮개 1.08R·단발 1.12R·위생모 1.14R).
