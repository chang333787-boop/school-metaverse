## 로컬에서 검사하기(맥)
- 도구 = `tools/harness/`(클라우드에서 쓰던 것 — 저장소 밖 경로 없음). 한 번: `npm i -D playwright && npx playwright install chromium`.
  - 게이트: `node tools/harness/check.cjs . --full` → 감사·도달·옥상·문·지도 계약·빠른/전체 검진 줄.
  - 캡처: `node tools/harness/shot.cjs . out.png "x,y,z,방위°,올려보기°,화각°" …`(0=북 −z · 90=동) · 시간대 `…@sunset|@night`는 `shot2.cjs` · 휴대폰 `node tools/harness/mob2.cjs . '[["이름","?game=watergun"]]'` · 모으기 `combine.cjs out.png a.png b.png`.
  - 맥은 실제 GPU라 fps를 잴 수 있다. 소프트웨어 GL로 돌리려면 `SWGL=1`.
- 영상(카카오톡 mp4)은 맥에만 둔다 — 저장소 커밋 금지(아이들 얼굴). 프레임이 필요하면 `ffmpeg -i x.mp4 -vf fps=1/2,scale=640:-2 f_%03d.jpg`(저장소 밖 폴더).
- 캐시 버스터: js를 고치면 `v2/index.html`의 `main.js?v=`(지금 151)와 main.js 안 import의 `?v=`를 올린다(CLAUDE.md ⚠️캐시).
