# 설계 메모 — 행동 사전(이야기·방탈출·잠입·숨바꼭질 공용 엔진) · key actions
> 09-26 사용자와 아이디어 발산에서 정한 것. 아직 **구현 전**(설계). 게임 계약은 docs/map_api.md §5를 따른다.
> 규칙: NPC 수를 늘리지 않는다(기존 NPC를 옮기거나 이름 없는 역할로) · 대사·쪽지·문제는 아이들/교사가 쓴 것만(임의 생성 금지) · 사람을 과녁·적으로 쓰지 않는다(술래·쫓는 것 = 로봇·유령·가상의 '순찰 선생님' 역할 — 실제 선생님 NPC는 쓰지 않음).

## 목표
아이들이 쓴 이야기를 **표 모양 이야기 파일**로 옮기기만 하면 게임이 되게 한다. 엔진 = '동사' 목록. 없는 동사가 나오면 그때 하나씩 더한다.

## 행동 사전(1차)

### 플레이어가 하는 것
| 동사 | 뜻 | 메모 |
|---|---|---|
| 파기 | 모래·흙 칸을 파면 물건이 나온다 | 운동장·농구 모래 구역·텃밭·큰 나무 밑 |
| 줍기·들기·놓기 | 물건을 들고 다니다 제자리에 놓는다 | 식판 들기(kid tray) 확장 |
| 주기 | 인물에게 물건 건네기 → 반응 장면 | |
| 조사하기 | 칠판·게시판·책장·사물함 → 쪽지·그림 | |
| 열기·잠그기 | 문·사물함·서랍·창고(열쇠·조건) | 문 61개 재사용 |
| 앉기 | 의자·벤치 | 기존 hotspot 'sit' |
| **웅크리기** | 버튼/키를 누르는 동안 키 ≈ 절반(1.5 → 0.8) · 느리게 걷기 · 발소리 작음 | 낮은 덤불·책상 뒤·식탁 옆에 몸이 가려진다. 일어설 때 머리 위가 막혀 있으면 웅크린 채 유지(ceilAt). 물리 몸 높이·카메라 높이·kid 자세(무릎 굽힘) 함께. 게임이 켰을 때만(평상시 끔 — 도달성 게이트 영향 0) |
| **숨는 자리** | 게임 중에만 켜지는 자리에 다가가 '행동' → 쏙 들어감 · 다시 '행동' → 나옴 | 들어가면 캐릭터 숨김 + 카메라 = 틈새 시점(좁은 시야·가장자리 어둡게). 술래 시야에 안 잡힘 — 단 술래가 바로 앞에서 '뒤지기'하면 발견 |
| 켜기·끄기 | 교실 불·방송실·수도꼭지 | 불 켠 방 = 유령 모드 안전지대 |
| 고르기 | 선택지 2~3개 → 갈래 | |

#### 숨는 자리 후보(장소별 — 구현 때 실제 가구 좌표에 맞춤)
- 교실: 청소함 · 교탁 밑 · 커튼 뒤
- 복도: 사물함
- 체육관: 무대 커튼 · 뜀틀
- 급식실: 큰 냉장고 옆 · 배식대 밑
- 도서실: 책장 사이 끝 칸
- 바깥: 덤불 속 · 큰 나무 구멍 · 미끄럼틀 밑 · 숲놀이터 데크 밑

### 세상이 바뀌는 것
| 동사 | 뜻 |
|---|---|
| 인물 옮기기 | 장면마다 NPC 자리·자세(서기/앉기/일하기)·방향 바꾸기(수는 그대로) |
| 물건 나타나기·사라지기 | 땅에서 나온 상자, 사라진 열쇠, 새 쪽지 |
| 길 열기·막기 | 테이프 친 복도, 비밀 문, 무너진 울타리 |
| 시간·날씨 | 낮/노을/밤 → 나중에 계절(봄 벚꽃·여름·가을 낙엽·겨울 눈) |
| 카메라 연출 | 천천히 비추기 · 어두워졌다 밝아지기 · 회상 색 |
| 소리 | 종·발소리·문 삐걱(WebAudio로 만든 소리) |

### 쫓는 것(잠입·유령·숨바꼭질)
- 종류: 순찰 선생님 역할(낮) · 유령(밤) · 술래 로봇 — 모두 치비 장난감 모양
- 찾는 방법: **시야**(앞쪽 부채꼴 — 바닥에 옅게 표시) + **소리**(뛰면 들림, 웅크리면 거의 안 들림) + 숨는 자리 **뒤지기**(가까이 와서 잠깐 멈춤 → 조마조마)
- 잡히면: 벌·체력 없음 — "딩동" 하고 방 입구/출발점으로
- 판마다 **구역 제한**(zones 계약 사용 — 예: "서관 1층만", "운동장+큰 나무")

### 이야기 뼈대(보이지 않는 것)
- 기억 표시(플래그) · 가방(인벤토리) · 장(章) 넘기기

## 이야기 파일 모양(예시 — 내용은 자리표시)
```
장면: 큰나무_밑
  조건: 삽 있음
  파기(36.8, 28.4) → 나타남: 낡은 상자
  상자 열기 → 쪽지("아이들이 쓴 글") · 기억: 상자_찾음
  인물 옮기기: ○학년 선생님 → 구령대, 서기, 동쪽 보기
  시간: 노을
```

## 이 엔진 위의 게임 후보(09-26 발산에서 추림)
1. 실제 실과 연계한 **방탈출**(과학실·도서실·보건실·급식실 — 실마다 그 실다운 퍼즐)
2. **잠입·괴담 확인**(교무실 잠입 / 밤 괴담 확인 — 쫓는 것 켜기)
3. **아이들이 설계하는 스토리 게임**(아이마다 실 하나: 퍼즐 + 쪽지 + 괴담 한 줄)
4. **숨바꼭질**(웅크리기·숨는 자리 · 술래 로봇 / 반대 모드: 내가 술래)
- 별도: 물총 놀이(v2/games/watergun.js — 진행 중) · 계절 바뀌기(맵 기능)

## 순서
1. 행동 사전 엔진 + 동사를 다 써 보는 **빈 예시 장면**(삽 줍기 → 큰 나무 밑 파기 → 상자 → 인물 이동 → 노을) + 웅크리기·숨는 자리
2. 터치로도 되는지(터치 조작 위에서 — 웅크리기·행동 버튼)
3. 아이들 설계를 받아 채우기

# 멀티플레이 방향(09-26 발산 — 아직 결정 전)
> 사용자: "나중에는 결국 멀티플레이가 필수일 듯". 지금은 GitHub Pages(정적) + CLAUDE.md '외부 네트워크 의존 0' 원칙 → 멀티는 **원칙 변경이 필요한 교사 결정 사항**.

## 방법 후보
| 방법 | 내용 | 장점 | 걱정 |
|---|---|---|---|
| A. 작은 실시간 서버(Cloudflare Workers+Durable Objects / PartyKit 등) | 방 코드로 모여 위치 주고받기(WebSocket) | 무료 범위로 한 반 충분 · 설치 없음 | 외부 의존 원칙 변경 |
| B. 교사 노트북 = 서버(같은 와이파이) | 교실 안에서만 | 데이터가 학교 밖으로 안 나감(개인정보 최선) | 수업 시간에만 · 학교망 설정 영향 |
| C. P2P(WebRTC) | 기기끼리 직접 | 서버 비용 ≈ 0 | 연결 중개(시그널링)는 필요 · 학교망 차단 가능 |
| D. 비동기 | 기록·유령 경로·QR 도전장 | 지금 구조로 가능 | 동시에 함께 있는 느낌 없음 |

추천: 1단계 = A 또는 B로 **'함께 있기'만** — 같은 방 코드 → 친구 캐릭터가 보임.
- 채팅은 **자유 입력 없이** 이모티콘·정해진 말만(👋 😂 "여기야!" "같이 가자")
- 이름 = 교사가 정한 별명/번호(성·실명 없음) · 방 = 교사가 만든 코드로만
- 먼저 실제 학교망·크롬북 관리 설정에서 연결 시험(사이트·WebRTC 차단 여부)
- 성능: 한 반 25~30명 → 원격 캐릭터는 단순화(LOD)·위치 보간

## 멀티가 되면 살아나는 게임
진짜 숨바꼭질(웅크리기·숨는 자리) · 물총 팀전(청/백, 젖으면 우리 진영 개수대에서 말리고 복귀) · 협동 방탈출(두 실에서 동시에 풀어야 열림) · 얼음땡/경찰과 도둑 · 학교 투어 가이드 · 보물찾기 레이스 · 반 전체 수업 모드(교사 화면에 전원 위치, "모두 과학실로")

## 그 밖에 열어 둔 생각
- 맵이 살아 있기: 시간표 따라 움직이는 NPC(1교시·점심·하교) · 실제 날씨 연동 · 학교 행사 맵(운동회 만국기·졸업식)
- 흔적이 쌓이기: 발자국 지도(교사용 통계) · 반별 복도 벽화 · 졸업 앨범 맵(그해 맵 동결 — classroom/ 동결본처럼)
- 현실과 섞기: 실제 교실 문 QR → 맵 그 교실 · 분실물 게시판(사진 없이 설명만)
- 계절 바뀌기(사용자 호응) — 봄 벚꽃·여름·가을 낙엽·겨울 눈

## 순서 제안
1. 터치 + 물총 마무리 → 2. 행동 사전 + 웅크리기·숨는 자리(혼자) → 3. 멀티 1단계 '함께 있기'(A/B 교사 선택) → 4. 멀티 숨바꼭질·물총 팀전
