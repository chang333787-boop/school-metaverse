# 「드래곤 길들이기」(2010) — 그래픽 분석(F) · 크롬북 기법(F+) · 영화가 주는 느낌(G)

조사일 2026-10-31 · 4학년 기획 3D 게임(three.js r170 · 크롬북 1366×768)의 그래픽 방향을 정하려고 모은 자료.

**표기 규칙**
- **[확실]** = 서로 다른 출처 둘 이상이 같은 말을 함
- **[불확실]** = 출처가 하나뿐이거나, 출처 없이 우리가 영화를 보고 짐작한 것(이때는 '관찰'·'우리 분석'이라고 적음)
- 출처 번호는 맨 끝 목록. '검색 요약만 봄'이라고 적은 출처는 본문이 막혀(403·유료) 검색 결과 요약으로만 확인한 것
- 영화 그림은 내려받지 않았고, 글은 모두 우리 말로 요약함. 영어 원문 인용은 없음(저장소에 올리며 우리 말로 바꿈)

### F-2. 색 — 장소·때마다

> 알려진 큰 원칙: 북쪽 땅의 빛(낮은 해 · 흐린 하늘)을 사진 자료로 잡았고 [2], 안개 낀 숲·안개에 잠긴 바다·빈 공간을 많이 쓴다 [5]. 실내는 촛불·불빛만으로 비춰 채도가 낮고 대비가 크다 [2][5]. 디킨스는 색과 분위기를 아주 다르게 보게 해 줬고, 감정에 맞으면 새까만 그림자도 피하지 말라고 했다 [3]. → 이 큰 원칙은 [확실]
> 아래 표의 **색 이름은 우리가 영화를 떠올려 적은 '관찰'**이라 따로 출처가 없다. 게임 색표를 만들 때 교사가 영화로 한 번 확인할 칸이다.

**컬러 스크립트**: 아트북에 스토리보드·스케치·컬러 스크립트·콘셉트 그림이 실려 있다는 도서관 소개가 있다 [21]. 그러나 누가 그렸는지, 영화 전체 색 흐름이 어떻게 짜였는지 설명한 출처는 못 찾았다 → [불확실]. 아트북 목차가 드래곤 세계 · 바이킹 세계 · 드래곤 · 제작 과정(스토리보드·레이아웃·애니메이션·효과·조명·편집) 순서라는 것은 두 리뷰가 같다 [8][9] → [확실].

**게임에 쓰는 색 흐름(우리 제안)**: 차가운 청회색(일상·두려움) → 따뜻한 주황(불·집·아빠) → 초록(코브·우정) → 분홍·금(하늘·자유) → 검붉은 회색(둥지·위기) → 다시 맑은 청록 + 따뜻한 빛(공존). 감정 따라 색이 바뀌는 원리만 빌리고 실제 색값은 우리가 새로 고른다.

### F-3. 모양 언어

**인물**
- 크게 과장한 덩어리 모양 + 실감 나는 질감·빛 [2] · 길쭉하게 늘린 만화식 인물(리뷰어가 처음엔 낯설어함) [12] → 과장한 비례 [확실]
- 주인공 히컵은 관객이 자신을 겹쳐 봐야 해서 과장을 가장 덜 해, 오히려 가장 재미있게 만들기 어려웠다 [6] → [불확실](6만)
- 스토이크는 큰 네모 덩어리로 지었다는 말과 키 2m가 넘는다는 말이 있으나 출처가 약함 → [불확실]
- 관찰: 어른 바이킹 = 큰 통 같은 몸통 · 짧은 다리 · 거대한 수염과 투구 / 아이들 = 가늘고 머리가 큼 / 히컵 = 가장 가늘고 팔다리가 김. "큰 어른 사이의 가는 아이"가 그 자체로 이야기(힘 대 꾀)를 보여 줌 → [불확실](관찰)
- 스토이크 수염만 리깅(움직임 준비)에 몇 달이 걸림 [6] · 수염·털 표현 기술이 늘었다 [2] → 수염이 인물의 큰 덩어리라는 것 [확실]

**드래곤 — 실제 동물 섞기 + 종마다 다른 실루엣**
- 드래곤마다 실제 동물을 바탕으로 해 성격과 움직임이 거기서 나옴 [13] · 종마다 서로 아주 다르게 보이도록 함 · 색도 밝고 다양하게 [2][6] → [확실]
- 그롱클: 둥글고 무거운 몸(악어 + 호박벌 + 오토바이 [6] · 바다코끼리 [13]) → 둥근 동물 바탕 [확실] · 오토바이 [불확실]
- 데들리 내더: 새 같은 몸(티라노 + 타조 + 앵무새 [2] · 앵무새처럼 굶 [13]) → [확실]
- 테러블 테러: 도마뱀붙이 같은 작은 드래곤, 원래 투슬리스 첫 디자인이 이리로 옮겨 감 [6][22] → [확실]
- 지퍼백(머리 둘·꼬리 둘)·몬스트러스 나이트메어(길고 스스로 몸에 불붙임) — 디자인 의도 출처 못 찾음 → [불확실](관찰)
- **우리 분석(64px 실루엣 시험용)**: 그롱클 = 동그라미(공) · 내더 = 세모 + 뾰족 가시 볏 · 지퍼백 = 긴 V자 둘 · 나이트메어 = 긴 S자 + 큰 날개 · 테러 = 작은 물방울 · 투슬리스 = 매끈한 화살촉 + 큰 날개, 위협적인 대장(레드 데스) = 산 같은 덩어리. 영화가 이렇게 설계했다고 말한 출처는 없음 → [불확실](우리 분석)

**투슬리스 디자인 의도**
- 흑표범을 바탕으로 생김새·몸짓·살금살금 걷는 모습을 잡음 [1][2][6][7][13] → [확실]
- 몸짓 = 고양이 + 개 섞임(귀 쫑긋·눈 깜빡임·주둥이 움직임을 고양이·개에서) [2][6][13] → [확실]
- 날개 = 박쥐 날갯짓 · 작은 맹금류 [2][6] → [확실]
- 감정이 잘 보이게 큰 귀와 큰 눈 [1] · 감독의 이전 캐릭터(스티치)를 닮은 큰 눈·귀가 영향 [22 검색 요약만 봄] → 큰 눈·귀 [확실]
- 감독 샌더스가 처음 그린 투슬리스가 이전 캐릭터와 너무 닮아 이야기를 위해 다시 디자인함 [6][22] → [확실]
- 도롱뇽을 섞었다는 말 [2] · 늑대의 눈빛 [6] · 웜뱃 자세 [6] → 각각 [불확실](하나씩만)
- 파충류보다 포유류처럼 보이게 해 관객이 정 붙이게 함 [7] → [불확실]

### F-4. 빛 · 안개 · 질감

- **실사 같은 빛을 쓴 이유**: 감독들이 레이아웃과 조명 사이 시간을 줄이고 더 자연스러운 그림을 원해서 실사 촬영감독을 불렀다 [2], 실사 영화 느낌을 더하려고 [1], 실사 기법이 스타일에 준 영향 [10] → [확실]
- **빛을 빼는 쪽**: 애니메이션은 흔히 너무 밝게 비추니 몇 개의 광원만 두고 깊은 그림자가 화면을 채우게 함 [2] · 새까만 그림자도 감정에 맞으면 씀 [3] · 디킨스가 더 어둡게 하자고 해서 애니메이터들이 서운해했다(표정이 그림자에 묻혀서) [4] → [확실]
- **안개·대기 원근**: 안개 낀 숲 · 안개에 잠긴 바다 · 빈 공간 [5] · 흐린 하늘 [2] → 흐리고 축축한 대기 [확실] · 높이마다 다른 안개(섬이 안개 위로 솟는 모습)는 관찰 → [불확실]
- **구름**: 구름을 배경이 아니라 이야기를 돕게 숏마다 놓고, 나는 인물 둘레에서 움직이게 하는 작업 방식을 시리즈 내내 썼다 [11] · 비치는 느낌·번지는 구름을 위해 새 렌더 도구를 만듦 [7] → [확실]
- **질감 단순화**: 모양은 과장, 질감은 실제처럼 [2] — 털·나무·돌을 '어떻게' 줄였는지 설명한 출처는 못 찾음 → [불확실]. 관찰로는 큰 면은 고르고 부드러운 색 변화, 가까운 데서만 결(나무 결·돌 거칠기)이 보임 → [불확실](관찰)
- 3편 이야기지만 참고: 사실 같음을 지키되 때로 그림자를 더 진하게, 색을 더 진하게 꺾어 그림처럼 만든다 [20] (1편에 대해서는 [불확실])

### F+-3. three.js(r170)에서 쓸 구체 기법

**셰이딩**
- `MeshToonMaterial` + `gradientMap`: 3~4픽셀 `DataTexture`, `minFilter`·`magFilter` = `NearestFilter`, 색 공간은 기본값(NoColorSpace) [54]. 그림책처럼 경계를 부드럽게 하려면 `onBeforeCompile`로 톤 경계를 `smoothstep` 폭으로 바꿈
- 가장자리 빛(림 라이트): 법선과 시선의 각(프레넬)으로 해 쪽 가장자리만 밝게 — 툰 셰이더 교본의 기본 요소 [55]. `onBeforeCompile`로 몇 줄
- 빛 = `DirectionalLight` 하나(해) + `HemisphereLight`(하늘빛·땅빛). 그림자 지도는 가까운 몇에게만, 나머지는 바닥 얼룩 판
- 불빛: Light를 더하지 않고 `emissive` + 더하기 혼합 빛 퍼짐 판(가짜 bloom). 마을 불·대장간 화로는 공용 셰이더에 '불 자리 uniform 몇 개'를 넣어 거리만큼 주황을 더하는 가짜 빛(전체 화면 bloom 패스는 크롬북에 무거움 — 우리 판단)
- 색: 정점색(`vertexColors`) 또는 색 아틀라스 한 장(UV로 칸 고르기) → 재질 하나로 많은 메시를 합쳐 그리기·셰이더 수를 줄임. 작은 붓 결 무늬 몇 장을 아주 옅게 곱함
- 셰이더 수 관리: `onBeforeCompile`을 쓰면 `customProgramCacheKey`로 같은 변형은 한 프로그램을 나눠 씀(기획 §7 셰이더 ≤ 25)

**대기·하늘·구름**
- 높이 안개: `onBeforeCompile`로 `fog_fragment`를 바꿔 거리 × 높이로 짙기 계산(바다 가까이·골짜기에서 짙음) — 실제 예제 있음 [56]. 전역 `ShaderChunk`를 고치는 방식은 깨지기 쉬움 [56]
- 대기 원근: 안개 색을 해 방향 쪽은 따뜻하게, 반대쪽은 차갑게 섞음 · 파이어워치처럼 거리 띠마다 다른 안개 색 [36]
- 하늘: 큰 구(뒷면) + 3색 그라데이션 셰이더 [37] · 때(낮·노을·밤)마다 세 색만 바꿈
- 구름: 멀리는 빌보드 몇 장(`InstancedMesh` 판 또는 합친 판 하나 [46][47]), 가까이 스치는 구름은 **불투명** 덩어리(합친 둥근 메시 + 툰 + 안개)로 겹침 비용 없이 시차감. 구름 속을 지날 때는 판 대신 안개 색·거리를 바꿈(기획 §7)
- 바다: 카메라를 따라오는 격자 판 + 정점 셰이더 거스트너 물결 2~4개 [57][58], 물결 꼭대기 밝게 · 거품 띠 · 프레넬로 하늘색 섞기. three.js `Water`(반사 그림판)는 장면을 한 번 더 그려 무거움

**외곽선(B를 쓸 때)**
- 반전 헐: 같은 지오메트리 + `side: BackSide` 검정 재질 + 정점 셰이더에서 법선 방향으로 밀기. 그리기 +1/메시 · 뼈대 메시도 같은 뼈로
- `OutlineEffect`(examples/jsm/effects): 툰 재질 메시용으로 만든 것 · 장면을 두 번 훑어 장면이 크면 비용이 커짐 · `InstancedMesh`에는 안 붙음 [52][53]
- 화면 공간 선(`OutlinePass`·Sobel): 픽셀 수만큼 비용, 해상도 따라 선이 깨짐 [52] → 크롬북엔 비추
- 단단한 모서리만 선: `EdgesGeometry` + `LineSegments`(WebGL 선은 굵기 1픽셀 고정) — C 판화 결에도 쓸 수 있음

**속도감(비행)**
- 시야각 살짝 넓히기(빨리 날 때 60 → 72도 쯤) · 가까이 스치는 구름·물보라·돌기둥이 시차를 만듦 · 바다 스치기 때 물결 높이를 키우고 물보라 입자 · 카메라는 뒤따르되 부드러운 지연(디킨스식 절제 [2][23]) · 빠른 순간엔 흔들림·화면 효과를 줄임(입체 상영에서 깊이를 줄였던 원리 [2])

**해상도**
- `renderer.setPixelRatio` 0.6~1.0 자동 조절 + CSS로 늘림(낮은 해상도 원리 [40][41]). 그림책 결은 살짝 흐려져도 덜 티 남 — A가 B보다 해상도 낮추기에 강함(B는 선이 먼저 깨짐, 우리 판단)

### G-2. 어린이 관객이 특히 좋아하는 것

- **투슬리스의 얼굴·몸짓**(말 없이 표정으로 감정) — 어린이 매체 단체가 '드래곤 표정과 성격'을 아이들이 즐길 것으로 꼽음 [29] · 리뷰도 말 없는 투슬리스의 표정·몸짓·소리를 칭찬 [5] → [확실]
- **나는 장면** — 가장 칭찬받는 부분 [5] · 입체 비행 장면 칭찬 [24][28] → [확실]
- **웃음 + 모험 + 음악** — 아이 리뷰 모음에서 아름다운 그림·음악·웃음과 모험이 되풀이됨 [27] → [불확실](요약 하나)
- 시험 관객 가운데 8살 아이가 히컵이 다리를 잃은 결말을 '잃었지만 더 많이 얻었다'고 받아들임 [61] → [불확실](하나)
- 드래곤 종 알아맞히기·드래곤 훈련 안내서 만들기를 교육 자료가 활동으로 씀(아이들이 종 구별을 좋아한다는 방증) [63] → [불확실](우리 짐작)
- **무서워하는 것**: 마을 습격 · 묶인 드래곤이 소리치는 장면 · 꼬리 잃고 떨어지는 장면 · 마지막 거대 드래곤 공중전 — 어린 아이일수록 [29] · 큰 '여왕 드래곤'이 작은 드래곤을 삼킴 [25] → [확실]. 게임의 '예고 2~3초' 규칙과 맞음

### G-3. 교실에서 던지는 질문(요약)

- 히컵은 왜 마을에서 겉돌까? 아빠의 기대는 히컵에게 어떤 영향을 줬고, 둘 사이는 어떻게 바뀌었을까? 누가 히컵을 도왔을까? [25]
- 사람들이 드래곤에 대해 믿던 것이 틀렸다는 걸 보고, 우리가 당연하다고 믿는 것도 따져 볼 수 있을까? 싸움으로 푸는 것과 힘을 합치는 것은 어떻게 다를까? 어른이 아이 말을 안 들어 줄 때는? [29]
- 이야기 들려주는 사람(내레이터)은 인물을 어떻게 보이게 할까? 말이 적은 장면은 무엇으로 이야기할까? 의족은 영화에서 어떻게 쓰였을까? 북극광은 이야기에서 무슨 일을 할까? 음악은 분위기를 어떻게 도울까? [30]
- (7~11살) 드래곤 훈련 안내서 만들기 · 바이킹 아이의 하루 일기 · 바이킹은 왜 그 자리에 마을을 지었을까 · 짧은 장면 읽기 [63]
- 8~12살용 영화 안내 자료도 있음(내용은 열어 보지 못함) [64]
