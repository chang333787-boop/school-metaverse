# 발전판 그래픽·성능 로드맵 (2026-07-30 기획)

**진행 현황 (v0.9 `2595b70`)**: G0 ✅(맥 기준선: 복도 2,073콜) · G1 ✅병합/인스턴싱(복도 426콜, 4.9×↓ — 자동 프리셋은 기존 픽셀드롭만, 확장 보류) · G2 ✅ACES+PCFSoft+버텍스AO+실내천장 (하늘 태양·노을 프리셋 남음) · +TPS 마우스 잠금 조작 전환. **남은 것: G3 CC0 에셋, G4 모션, G2 잔여(하늘)**. 크롬북 실측은 기회 될 때.

목표: 기능 추가 없이 **그래픽 품질과 프레임 부드러움**을 끌어올린다.
불가침(정체성): 정림초 실배치 · 노란 벽+초록 지붕 · 거대나무/텃밭/숲놀이터 · 실제 실 이름 · NPC 명단 · 아이들이 만든 상호작용 · `classroom/` 보존판.

## G0. 기준선 측정
- 크롬북 실기기 `SD.perf()` — fps·rayObjs·drawCalls 기록
- 목표: draw call ≤ 80, 크롬북(1366×610) 55~60fps

## G1. 성능 기반 공사 (부드러움)
- 구역별 청크 지오메트리 병합 (BufferGeometryUtils.mergeGeometries) — 정적 상자류 통합, 청크 단위 컬링 유지
- InstancedMesh: 책걸상·창문·나무·울타리 등 반복물
- 품질 자동 프리셋 low/mid/high: 초기 5초 fps 측정 → pixelRatio(1.0/1.25/1.5)·그림자 해상도(1024/2048/4096)·AA 자동 선택 + 수동 전환 UI

## G2. 라이트·톤 (때깔)
- ACESFilmicToneMapping + exposure 튜닝
- 구운 그림자 PCFSoft·4096 (1회 굽기 유지)
- 버텍스 AO 굽기: 벽 모서리·처마 밑·실내 구석 음영 — low-poly 입체감 핵심
- 팔레트 조화 패스 (채도·명도 정리, 불가침 색상은 유지 범위 안에서)
- 하늘: 태양 디스크·구름 품질 개선. 기본=밝은 낮, 옵션=노을 프리셋(시연용)

## G3. CC0 에셋 교체 (디테일)
- 소스: Kenney / Quaternius 등 **CC0만** (공개 repo 라이선스 무결). credits는 README에
- 교체 대상: 나무·수풀·꽃·벤치·놀이기구·급식실/교실 소품
- 유지: **건물 전체 자작**(실배치=정체성), **거대나무 커스텀**(랜드마크)
- GLB 로드 후 G1 병합 파이프라인에 통합 (개별 draw call 금지)

## G4. 생동감 (모션)
- 캐릭터: 가속/감속 이징, 착지 스쿼시, 코너 기울임, 걷기 사이클 개선
- 카메라: 위치 스무딩·충돌 완화
- 세계: 나뭇잎 흔들림(저비용), 깃발 물결 개선, NPC 숨쉬기+플레이어 시선 추적

## G5(옵션). 상위 프리셋 전용
- high 프리셋에서만: SSAO·bloom·색 그레이딩. 크롬북(low/mid)에는 절대 미적용
