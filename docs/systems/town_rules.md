# 🧮 마을 규칙표 — 제한·관문 전수(RULES-1 · 10-18)

사용자 10-18: "그런 것들 좀 세밀하게 설정해 줘 · 12월 학기말에 오픈베타하는 게임이라 생각하고". 계기 = 1-2 '목장의 아침' 건초 주기가 일터 하루 셋에 막혀 다음 날까지 멈춘 것(a9a92f1에서 먼저 고침).
새 제한을 만들 때는 이 표에 한 줄을 더하고, 아래 원칙 여섯을 지킨다. `town_lessons.md`가 먼저다.

## 오픈베타 원칙
1. **이야기는 곁 제한에 막히지 않는다.** 지금 이야기 단계가 그 일터·가게·물건·선물을 쓸 때만 그 자리에서 예외를 둔다(`stNow`·`stWants`·`stWork`·`stGift`·`stShop` — town.js RULES-1). 이야기 글은 그대로 둔다.
2. **막히면 '언제·어떻게'를 한 줄로.** "안 돼요"로 끝내지 않는다. 날씨 칩처럼 아직 안 연 길은 말하지 않는다(`wxHint`는 `hudOn('wx')`일 때만).
3. **하루 제한은 그만 모으기에만 쓴다.** 넘으면 놀이는 그대로 열리고 '연습'(받는 것 없음)이 된다. 배움 글·놀이는 막지 않는다.
4. **돈이 모자라서 이야기가 멈추지 않는다.** 심부름 돈은 단계가 시작될 때 필요한 만큼 받는다. 다 써 버렸으면 심부름 물건만 가진 만큼 내고 산다.
5. **보상은 두 번 받지 않는다.** 다시 하기·새로고침·시간 건너뛰기 모두 같다. 하루 몫은 날짜 열쇠(`GAME.S.day`) 하나로 센다. 저장은 2초마다, 그리고 창을 닫을 때(pagehide) 한다. 상(돈·물건)과 센 수는 같은 저장 `S`에 함께 들어간다.
6. **하루 리셋은 잠 한 번(다음 날 아침 6시).** 하는 곳은 `GAME.sleep()` 하나다(`picked`·`uses`·오늘 할 일을 비움). 24시가 되면 저절로 잠든다. 실제 날짜(Date)로 바뀌는 하루 몫은 없다.

열 이름 — **막나** = 이야기를 막을 수 있나: X = 못 막음 · 예외 = 이야기 단계일 때만 풀림 · 기다림 = 이야기가 일부러 기다리게 함(아래 E).
