# 📊 학급 기록(REC-0 · 10-18 · `v2/games/town_rec.js`)

왜: `town_quests.md` §0 "배운 것이 **기기에만** 남아 교사가 볼 수 없음" · `town_lessons.md` G "학급 기록 화면(단계별 해낸 수 · 힌트 단계 수 · 고른 것 분포 · 한 줄 카드 · 투사 모드·번호 숨김) — 지금부터 같은 이름으로 기록해 둠".
지금 단계 = **서버 없이 이 기기 안에서만**. 선생님은 이 기기에서 보고, '복사하기'로 모은다. 서버는 사용자가 나중에 정한다(이 문서 §5는 설계만).

## 1. 자료 꼴 — `GAME.S.rec`(마을 저장 한 칸 안 · `sm-town-game:<마을>`)
```js
GAME.S.rec = {
  v: 1, mig: 1,                       // mig = 예전 이야기 기록(S.story.rec)을 한 번 옮겼음
  days: {
    '2026-10-18': {                   // 하루 = 실제 날짜(이 기기 시계) · '0000-00-00' = REC-0 전 예전 이야기 기록
      g0: 12, g1: 15,                 // 그날 거친 게임 날(일째) 처음·끝
      st:   [{ c, s, h, tr, p, w, l, t, f }],   // 이야기 단계 끝냄(이야기 S.story.rec.st와 같은 이름)
      cd:   [{ c, star }],                     // 장 끝냄(★ 도전 성공 = 1)
      q:    [{ id, ok, m }],                   // 보너스 문제(m: mid 낮 · rec 잠들 때 · prac 다시 풀기)
      help: [{ k, g }],                        // 일꾼 곁 거들기(g: 0 아쉬움 · 1 잘함 · 2 아주 잘함)
      job:  [{ k, done }],                     // 직업 체험(fire 소방관 · post 집배원 · lib 사서 — done 1 끝냄 · 0 멈춤)
      show: [{ id }],                          // 끝까지 본 쇼(aquarium · otter · butterfly)
      rank: [{ k, L, s, h, done }],            // 승급 미션(k 솜씨 · L 레벨 3·6·9 · s start 시작 / done 배지 · h 본 힌트 단계)
      play: [{ k, g }]                         // 강·들 놀이(stream · bend · paddylife · terrace · g = 0~2)
    }
  }
}
```
| 이름 | 뜻 | 남는 것 |
|---|---|---|
| `c` | 장 id(`town_story.js` CHAPTERS) | 모든 장 |
| `s` | 단계 id | 모든 단계 |
| `h` | 그 단계에서 본 힌트 단계(0 = 힌트 없이 · 1~3) | 모든 단계 |
| `tr` | 틀린 수 | 모든 단계 |
| `p` | 고른 것(보기 열쇠 · 여럿이면 여럿) | choose · contour · judge |
| `w` | 까닭(고른 근거 — 글 그대로) | judge |
| `l` | 불편해질 사람 | judge |
| `t` | 한 줄 쓰기 | line |
| `f` | 잰 값(걸어서 잰 초 등 수) | pace |
| `id` · `ok` | 개념 id(`town_quiz.js` BANK) · 맞힘 1 / 틀림 0 | 보너스 문제 |
| `k` · `g` | 일꾼 갈래·놀이 갈래 · 점수(0 아쉬움 · 1 잘함 · 2 아주 잘함) | 일꾼 곁 거들기 · 강·들 놀이 |
| `k` · `done` | 직업 갈래 · 끝냄 1 / 멈춤 0 | 직업 체험 |
| `k` · `L` · `s` · `h` | 솜씨 · 레벨 · start/done · 힌트 단계 | 승급 미션 |

**지키는 선**: 아이 이름 · sid · 기기 번호를 넣지 않는다(화면엔 '이 기기'로만). 글(`t`·`w`)은 아이가 쓴 그대로라 아이가 이름을 쓸 수는 있음 → 기기 밖으로는 선생님이 '복사하기'를 눌렀을 때만 나감.

**크기**: 최근 14일 · 갈래마다 하루 상한(st 80 · cd 30 · q 60 · help 60 · job 20 · show 20 · rank 30 · play 60) · 글 자름(한 줄 60자 · 까닭·고른 것 40자 × 6) · 새 날이 생길 때 전체가 80KB를 넘으면 오래된 날부터 지움(보통 하루 3~4KB · 꽉 찬 하루 약 15KB).
**렉**: 매 프레임 일 0 — 일이 끝날 때 `REC.add()` 한 번(배열에 하나 넣기) · 크기 셈은 하루 한 번 · 선생님 창은 열 때만 셈 · 저장은 원래 마을 저장(바뀐 뒤 2초에 한 번).

## 2. 무엇이 언제 남나(훅)
| 갈래 | 곳 | 줄 |
|---|---|---|
| `st` | `town_story.js` `recStep()`(단계가 끝날 때 — 예전부터 `S.story.rec`에 쓰던 것과 같은 값) | `api.rec('st', { c, s, ...o })` |
| `cd` | `town_story.js` `finish()` | `api.rec('cd', { c, star })` |
| `q` | `town_quiz.js` `settle()` | `A.rec('q', { id, ok, m })` |
| `help` | `town.js` `playEnd()`(그만 누르지 않고 끝난 일꾼 곁 판) | `REC.add('help', { k, g })` |
| `job` | `town_jobs.js` `endJob()`(끝냄·멈춤 둘 다) | `A.rec('job', { k, done })` |
| `show` | `town_show.js` 쇼 끝(`o.seen`) | `REC.add('show', { id })` |
| `rank` | `town_rank.js` `start()`(미션 열기) · `finish()`(배지) | `api.rec('rank', { k, L, s: 'start' })` · `{ k, L, s: 'done', h, done: 1 }` |
| `play` | `town_rf.js` `end()`(그만 = 안 남김) | `A.rec('play', { k, g })` |
예전 저장: 처음 열 때 한 번 `S.story.rec`(장마다 마지막 기록)을 `'0000-00-00'`(화면 '이전') 날로 옮김. `S.story.rec`은 이야기가 계속 씀(지우지 않음).

## 3. 선생님 보기(이 기기)
- 여는 곳: 이야기 목록(Q) 맨 아래 접이 칸 **'📊 선생님용 — 학급 기록(이 기기)'** → '🔒 기록 보기' → **선생님 비밀번호 창**(`lobby.js` `teacherPin` — 메모장·블록 놀이·함께하기와 같은 창 · 이 탭에서 한 번 맞히면 다시 묻지 않음 · 인터넷이 없으면 열리지 않음).
- 화면(교과서 '학급 기록 화면' 꼴):
  1. **이야기 단계 — 해낸 수와 힌트**: 장마다 단계별 '○번 해냄 · 힌트 없이 n, 1단계 n …' · 틀린 수 · 끝낸 수
  2. **고른 것**: 고르기·판단 단계마다 보기 이름(장소 이름 · 방위 · 판단 방법)과 수 막대
  3. **한 줄 카드**: 한 줄 · 까닭 · 불편해질 사람(최근 30장)
  4. **보너스 문제**: 맞힌 수 / 푼 수 · 낮 · 잠들 때 · 다시 풀기 · 자주 틀린 것 다섯
  5. **해 본 일**: 직업 체험(끝냄 · 멈춤) · 승급 미션(시작 · 배지 · 힌트 단계) · 일꾼 곁 거들기와 강·들 놀이(아주 잘함 · 잘함 · 아쉬움) · 끝까지 본 쇼
- **투사 모드**: 날짜 · '이 기기' 표시를 숨기고 카드 글을 크게(교과서 화면의 '번호 숨김'과 같은 뜻 — 지금은 한 기기라 번호가 없음).
- **복사하기**: §5의 JSON 한 덩어리를 클립보드로(안 되면 창 안 글 상자에 담아 골라 둠) → 메모장·패들렛에 붙여 모음.

## 4. 새 갈래를 더할 때
- `town_rec.js` `KINDS`에 하루 상한 · 이름 한 줄 → `recSum`에 세기 한 줄 → 선생님 보기에 한 칸 · 이름은 이야기와 같은 것(h · tr · p · t · g · done)을 먼저 씀.
- 이름(직업·놀이·솜씨)은 마을 쪽이 넘김(`jobName` · `playName` · `rankName` · `helpName` · `showName`) — 기록엔 열쇠(k)만.

## 5. 나중에 서버로(설계만 — 구현 X · 사용자가 정함)
- **올리는 단위 = '복사하기' JSON 그대로**:
```json
{ "kind": "sm-town-rec", "v": 1, "town": "ourtown", "made": "2026-10-18", "days": { "2026-10-18": { "g0": 12, "g1": 15, "st": [], "cd": [], "q": [], "help": [], "job": [], "show": [], "rank": [], "play": [] } } }
```
- **누구 것인지는 기기에 두지 않는다**: 올릴 때 선생님 쪽에서 반 코드 + 자리 번호를 붙임(예: 함께하기 방 코드 · 교사가 정한 번호표) — 아이 이름은 서버에도 두지 않고 교사 화면에서만 번호 ↔ 이름을 맞춤.
- 저장 길(예 — Firebase 실시간 DB를 쓴다면): `recs/<반>/<자리>/<날짜>` = 그날 묶음 한 덩어리(**같은 날을 다시 올리면 통째로 바꿔 씀 = 몇 번 올려도 같음**) · 14일 지난 날은 지움 · 함께하기 스트림(EventSource)은 새로 열지 않음(올릴 때 한 번 PUT).
- 크기 어림: 30명 × 14일 × 4KB ≈ 1.7MB(반 하나) · 날마다 올리면 한 번에 4KB 안팎.
- 반 화면(교과서 학급 기록 화면과 같은 꼴): 단계별 해낸 아이 수 · 힌트 단계 분포 · 고른 것 분포 · 한 줄 카드(자리 번호 · 투사 모드 = 번호 숨김) · 자주 틀린 개념.
- 서버 규칙 메모: 아이 기기는 자기 자리 칸에 쓰기만 · 읽기는 교사 비밀번호 뒤에서만(지금 memoPin과 같은 결) — 공개 읽기 X.
