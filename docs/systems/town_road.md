## 4. 고친 것 — 떨어진 것 줍기 0/3(10-24)
- 들은 말: 'E를 눌러도 0/3'.
- 원인 둘(시험으로 확인 — 순간이동하면 3/3, 걸어가면 0/3):
  1. **지붕 밑에 떨어짐** — 자리를 고를 때 땅 높이를 '땅 + 2m'에서 아래로 재서 표고 재배장 차광막 밑 땅(17.7m)에 공을 놓았다. 걸어가면 몸은 차광막 위(20.4m)에 서고, E는 높이 차 1.6m 안에서만 잡혀 아무 일도 없었다.
  2. **레벨 보상 창이 E를 삼킴** — 모자·고리 코스로 솜씨가 오르면 1초 뒤 '🎁 레벨 보상' 창이 떴다. 창이 열린 동안 E는 창이 가져가서(FIX-ST4) 줍기가 안 되고, 시간도 멈췄다.
- 고침: 자리마다 **위가 트였는지**(8m 위에서 재도 같은 높이) · 둘레 1m 넷이 막히지 않았는지 · 일꾼 자리에서 **걸어서 닿는지**(`walkLen` · 곧은 거리 × 1.6 + 6 안) 본다(모자 굴러가는 길도 지붕 밑 X). 레벨 보상 창은 길 위 사건(고리 코스·부탁)이 끝난 뒤에 뜬다. 주울 것은 0.26m 이상 · E 둘레 1.7 → 2.0m.

## ④ 길 막힘 · 내 기록(DEPTH-3 · 10-26)
- 자전거로 한 번 완주한 코스만 · 판(그 코스를 몇 번째 달리나) × 날 씨앗으로 고리 j와 j+1 사이 가운데가 🚧 공사 또는 🎪 장터 행사로 막힘(판 다섯에 하나쯤은 막힘 없음 · 바로 앞 판과 같은 자리·갈래 X)
- 막힘 = 자전거 도로(차도 쪽 끝 −1.0m)부터 인도 바깥 w(3.4~4.4m · 금메달 뒤 4.4~6.0m)까지 길이 6m 울타리 · 몸 막이 0.6m 상자 · 바깥쪽 3m가 빈 땅이고 막힘 안이 비어 있고 다른 E를 덮지 않는 자리만 · 팻말 = 「공사 중 · 자전거 도로 막힘 / 돌아갈 길을 찾아요」(어느 쪽인지는 쓰지 않음)
- 달리는 중 막힘 앞뒤에서 차도 쪽(l < −1.5)으로 나가면 = 「차도예요 · 멈춰서 차를 먼저 보내요」 3초 멈춤(한 판 한 번 · 시계는 감) · 바깥쪽(l > w)으로 돌면 = 멈춤 없음 · 끝 알림에 한 줄(차도로 돌아가 기다렸어요 / 바깥쪽으로 안전하게)
- 막힘 판 메달 시간 = 돌아가는 거리(2 × (w + 1.6)m ÷ 22m/s)만큼 넉넉히 · 기록 S.ring[id] = { b 최고, m 메달, n 판, h 지난 다섯 판 [{ t, d, k, rd }], bx 막힘 판 최고, lp 지난 막힘 } · 끝 알림 '지난 판보다 n초' · town_lad.js 기록판은 읽기만
- 그리기 = 울타리 인스턴스 1 + 고깔 인스턴스 1 + 팻말 1(가까운 코스 하나만 · 자전거를 탈 때만) · 시험 `town_depth3.cjs --only=road`
