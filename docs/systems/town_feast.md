# 🎉 마을 잔치(FEAST-1)

사용자 10-25~26: "하루하루가 따로 놀고 다음 날 이거 해야지가 없다 · 성취가 뭔지 모르겠다 · 생산 말고도 길 · 조급함 · 유기적" → 10-26 제안 1순위 「첫 마을 잔치」(그동안 모은 것이 한꺼번에 보이는 끝판).

**핵심 = 새 놀이를 만들지 않고 이미 있는 것을 하나로 꿴다.** 코드 `v2/games/town_feast.js` · 시험 `tools/harness/town_feast.cjs`.

## 1. 줄기
| 때 | 아이가 겪는 것 |
|---|---|
| 첫날(할 일 화면이 열린 뒤 첫 1초 칸) | 배너 「첫 마을 잔치(추수 잔치)까지 열세 밤」 + 맡긴 이웃 한 줄 + 칩 「🎉 잔치 게시판」(누르면 빨간 선) · 잔치 마당에 게시판 하나가 섬 |
| 준비 날(날마다) | 아침 6시 뒤 알림 한 번(창이 떠 있으면 미룸 · `say(t, s, 1)`): '잔치까지 ○밤이에요. 오늘은 ○○이 맡긴 ○○를 해 볼까요?'(가장 덜 된 갈래 · 날마다 돌아가며) · 아침 소식판 한 줄 · 날씨 창 달력 줄 · 하루 마무리 '오늘 도운 잔치 준비' + 이레 안이면 '내일 기다리는 것'에 「잔치까지 ○밤」 |
| 준비 | 평소 하던 놀이를 하면 갈래에 보탬이 쌓임 · **갈래마다 하루 두 번까지**(셋째는 '오늘 몫은 했어요. 내일 또') · 두 번 = 한 단계 = 잔치 마당에 물건 하나(배너 한 줄 + 「잔치 마당 보기」 칩) |
| 잔치 날 | 아침 소식·알림 「오늘은 ○○ 날」 · 10시~23시 일꾼이 잔치 마당에 모임(준비한 만큼 4~11명 · 있는 일꾼 그대로) · 준비한 것만 나와 있고 못 한 갈래는 빈 자리 |
| 잔치 날 E | 무대(공연 단계 하나 넘게) = 🥁 장단 치기(저장한 내 장단이 있으면 그 자리에서 들려주기 · 없으면 장구 선생님 창 한 판) → 모인 이웃 손뼉 배너 · 상(음식 단계 하나 넘게) = 🍲 음식 나누기(가방 요리가 있으면 한 접시 올리기) · 게시판 = 📷 올해 잔치 사진(이 기기 앨범 · `photo.js`) |
| 가까이 가면 | 모인 이웃 둘이 말풍선: 잘된 갈래 한마디 + 못 한 갈래 '다음 잔치엔 …'(벌·실패 화면 X · 무엇을 하면 되는지 한 줄) |
| 18시 | 잔치 마당 → 야시장(NIGHT-1 자리) 등불 길 14개까지 + 배너 + 「야시장 가기」 칩 · 18:30부터 줄 등이 주황(MeshBasic 색만 · 새 Light X) |
| 20시 | 아직 안 찍었으면 '잔치가 끝나기 전에 게시판에서 올해 잔치 사진을 찍어요' 한 번 + 칩 |
| 다음 날 | 지난 잔치가 기록(준비 단계 · 만남 · 공연 · 나눔 · 사진)으로 남고 잔치 마당에 **지난 잔치 판**이 섬 · 물건은 치움 · 다음 잔치 = +14일 · 주제는 그 날의 계절 · 아침 소식 '어제 잔치가 끝났어요. 다음은 꽃 잔치, 열세 밤' · 일기 한 줄 |

태풍 날(TYPH-1 storm)에 잔치 날이 걸리면 하루 미룸(알림 한 줄).

## 2. 다섯 갈래(맡긴 이 = 하는 일 · 실명 X)와 잇는 체계
| 갈래 | 맡긴 이 | 채우는 것(이미 있는 기록) | 단계마다 생기는 것 |
|---|---|---|---|
| 🍲 잔치 음식 | 식당 요리사 | 요리하기(`tally:cooked`) · 요리 나눠 주기(`tally:shared`) · 빵집 주문 끝(`job bake order-end`) · 바쁜 부엌(`job kitchen`) · 일꾼 곁 거들기(`help`) · 텃밭 물(`tally:farmW`) · 꾸러미 요리·가을·텃밭(BUNDLE-2) · 야시장 장보기(`night mkt`) · 게시판에 요리·재료 드리기 | 긴 잔칫상(그릇 열둘) → 가마솥·화덕 + 둘째 상(떡 판) → 흰 음식 천막 |
| 🏮 마당 꾸미기 | 정원사 | 꾸러미 봄·여름·숲·겨울(꽃밭·밤길 등·쉼터·모래 상자) · 우리 집 마당 꾸미기(`deeds t:'deco'` 그날 늘어남) · 게시판에 솔방울·마른 가지·양털·해바라기 화분·풍경 드리기 | 들머리 현수막(글 = 잔치 이름) → 마당을 가로지르는 줄 등 열하나(밤에 켜짐) → 들머리 꽃 화분 여덟 |
| 🥁 공연 준비 | 장구 선생님 | 장구 한 판(`janggu` s) · 내 장단 들려주기(`busk`) · 판 놀이 한 판(`table end`) · 모내기 노래 박자(`job rhy:mo`) | 낮은 마루 무대 → 북·장구 + 파란 차양 → 오방색 뒷막·깃발 |
| 🙇 손님맞이 | 행정복지센터 직원 | 새 칸 가 보기(저장 `cells` 늘어남 · **하루 한 번만**) · 직업 체험 끝(마을 여권 `job done`) · 여권 부탁(`job passreq done`) · 이웃 부탁 들어주기·선물(`tally:gift` — BAG-2 부탁도 이 꼬리) · 우체국 소포(`bldg post send`) | 「어서 오세요」 안내판 → 돗자리 둘·걸상 넷 → 파란 안내 천막·방명록 |
| 🧯 안전 | 소방관 | 긴급 출동 끝(`emerg done`) · 고칠 곳 신고(`fix rep`) · 사건 수첩 풀기(`case fixed`) · 태풍 준비(저장 `typh.reqs` done 늘어남) · 112 연습 · 응급 처치(`bldg`) · 밤 순찰(`night patrol`) | 구급함 탁자 → 소화기 둘·무대 앞 안전 고깔 → 안전 쉼터 천막(구급 깃발 · '길 잃은 어린이는 여기로' 팻말) |

- 기록 → 갈래 표 = `srcOf(k, o)`(순수 함수 · 시험이 그대로 부름). 새 놀이를 만들면 그 놀이의 `REC.add` 한 줄이 이 표 어디에 들어가는지만 정함.
- 꼬리 셋: town.js `REC.add` 감싸기(`FEAST.tap`) · `GAME.tally` 감싸기(모듈이 걸고 끝나면 되돌림) · 1초 칸 저장 칸 늘어남(`counters`).
- 보상은 바뀐 마당 자체(돈·솜씨 X · rwCheck 문을 새로 지나지 않음). 가방 드리기는 그 물건이 빠짐.
- 나의 길(PATH-1)·꾸러미(BUNDLE-2)·사건 수첩·태풍·야시장·장구·사진관은 그대로 — 잔치는 그 기록을 읽을 뿐.

## 3. 잔치 마당 자리
- 기준 = 나의 길 자리의 정자(이웃이 저녁에 모이는 곳 · ROUTINE-2) → 없으면 장터 → 행정복지센터 → 학교 앞.
- town.js `feastSite` = `workSpot({ w: 26, d: 18, sl: 1.5 })`(건물·길·물·학교·마당 X · 기울기 1.5m 아래) 80m → 140m · STORY-2 잔치 천막(FTN) 34m 안은 피함.
- 들머리(로컬 +z) = 학교 울타리를 보지 않는 쪽, 그다음 가까운 길 쪽. ourtown = 정자나무 쉼터 앞(어울목) [-52.3, -100.2].
- 물건마다 제 땅 높이 · 큰 것(상·화덕·무대·뒷막·장대·천막 탁자·판)만 충돌 · 등은 인스턴스 하나.

## 4. 저장 `GAME.S.feast`
`{ v, n, fd, d0, th, lv {갈래: 보탬}, dc { d, b {갈래: 그날}, s {출처: 그날} }, ann, ann0, fx { met, show, ate, ph, want, bk, nm, phc }, cn { cells, typ, deco, d }, past [{ n, d, th, st, met, show, ate, ph }] }`
- 단계 = `min(3, 보탬 / 2)` · 첫 잔치 날 = `max(14, 오늘 + 7)`(이미 오래 한 저장도 이레는 준비) · 다음 = +14(오늘 + 7보다 앞이면 한 번 더).
