- **MEMO-3 장면 중심(10-03 교사 '종류가 많으면 아이들이 헷갈림 — 사건을 먼저, 거기에 인물·장소·대사·물건 · 깃발은 몇 번 장면인지')**: 판 = 📖 이야기 판(L) — 장면 카드(🎬 '무슨 일이 일어나요?' · 번호 = 순서 · 번호 줄을 끌어 순서 · 선생님 ⚙️ 칸) 아래에 덧붙이기(🧑 인물 · 💬 대사 · 📦 물건 · ❓ 고르기 · 📍 일어나는 곳). 데이터 = 같은 flags 모음 — 장면 `k:'scene'`(또는 p 없는 예전 카드) · 덧붙인 것 `p:<장면 id>`. 🚩 깃발 = 꽂을 때 '몇 번 장면?'을 고름 → 깃발 천 색·이름표 동그라미 번호 = 장면(SC 색표). ❤️·💬 댓글은 장면에. ▶ 장면 따라 걷기(N/B). 📤 정리 = 장면별(덧붙인 것·자리·댓글). 지난 MEMO-2의 담벼락·종류 거르기는 뺐다.
- **🌍 세계 만들기(WORLD-1 · 10-03 교사 '메타버스는 두 갈래 — 이야기 설계 · 마법 세계처럼 새로운 세계 만들기(세계관 상상) · 교사가 관리에서 보고 Claude에게 넣으면 구현')**: 같은 memo.js의 판 종류 `boardList ty:'world'`(세계 1~20번 판 w01~w20 · 이야기 판 1~20번 b01~b20 — 10-07 늘림). 카드(registry `memo_world` v2 · `world_v3` v3 상상의 세계 — `params.kind:'world'`면 세계 판만 보임) = 여섯 칸 WC(🌍 어떤 세계? · 📜 규칙 · 👫 누가 살아? · 🏰 어떤 곳? · ✨ 신기한 것 · 🎮 무엇을 해? — 칸마다 질문·예시·줄기 문장 · 목표 수 1·2·2·3·3·3) + 💡 까닭(`why`). **세계는 우리 학교와 따로인 새 세계(10-04 교사 '마법 세계 같은 걸 만드는 건데 왜 학교에 깃발') → 학교 깃발 없음** · 🏰 장소 카드 = '📍 어디쯤?'(가운데·북쪽·남쪽·동쪽·서쪽·하늘·땅속·물속 = `loc` — 세계 지도 배치용) · F = 카드 쓰기 · ❤️ 많은 순. 🧭 세계 코치 = 구현 준비 %(칸별 목표) · 이름만 있는 세계 · 짧은 카드 · 까닭 비율 · 할 일이 장소·주민·신기한 것과 이어지나(낱말 겹침) · 규칙이 할 일에 쓰이나 · 장소의 어디쯤. 📤 정리 = 칸별 ❤️ 순 + 코치 + 'Claude에게 구현 부탁 틀'(imagine/<영문>/에 마법사 마을처럼 · 🌍 첫 화면 · 📜 놀이 규칙 · 👫 말 걸기 · 🏰 지역(📍 어디쯤으로 세계 지도) · ✨ 상호작용 · 🎮 퀘스트). **교사가 '세계 n번 판 만들어'라고 하면 REST로 `boards/w0n/flags` 읽어 imagine/에 새 세계를 짓는다.**
- **리뷰 마감(10-04 · 울트라코드 — 93건 중 85건 확인·수정)**: 📤 정리의 퀴즈 정답·Claude 부탁 틀은 선생님만(아이 = '세계 채우기 %') · 장면 자리 = sceneSpot(장면 깃발 → 📍 일어나는 곳 → 🧑·💬 · 📦·🔐 깃발은 따로 찾아가는 곳) · 덧붙인 카드에도 깃발 꽂기·옮기기(같은 id PATCH) · 깃발을 누르면 그 장면 · 보기 번호는 줄 끝 '→ N번 장면'만 읽음('1번 사물함'은 글) · 🔗 '갈래를 일부러 합쳤어요'(장면 `go`) · 걸어가기 = standSpot(방 바닥·같은 구역·시야 — 가구 위 깃발에 갇히지 않음) · 근처 표지점은 같은 구역만 · ⏹ 때 장면 창·타이머 정리 · 안 쓴 장면 = 🚧 · 세계 판은 들어가면 판이 바로 열림(여섯 칸 3×2 격자) · 견본 판 by = '견본 4·5·6학년'(**견본·시뮬레이션 글에 실제 명단 이름 금지**) · 견본 퀴즈 정답은 layout.js·tour_data.js로 확인.
- **일자형 이야기 + 💥 게임 오버(LINE-1 · 10-04 교사 '막 써도 내가 그걸 토대로 만든다 · 갈림은 웬만하면 말고 일자형 · 실패하면 게임 오버되고 다시 선택 — 교훈 이야기')**: 덧붙이기 '＋ ❓ 선택' = 보기마다 [✅ 계속 | 💥 게임 오버] + 💥면 '어떻게 돼요?'(교훈 결과) · 저장 opt 줄 = '보기 → ✅' / '보기 → 💥 결과'(✅ 하나 이상 · 💥마다 결과) · 해 보기(걷기·📖 책·🏫 현실) = 💥 → '💥 게임 오버' + 결과 + [🔄 다시 고르기] → 같은 선택 · ✅ → 다음 장면 · 끝 화면 '다시 고른 횟수'. '→ N번 장면' 갈림은 선생님 🗂 관리 '🔀 갈림길 허용'(boardList `br`)일 때만 — 예전 갈림 카드는 그대로 동작. 코치: br 아니면 갈림 말 없음 · ✅ 없는 선택·결과 없는 💥·지운 장면(→ ?번) 짚음 · 💥가 하나도 없으면 파란 권유. 장면 카드 '📍 이 장면은 어디서 일어나요? — 🚩 꽂기'(깃발 = 그 장면 자리 · 다음 장면 깃발 = 다음 목적지 · 따로 '목적지' 칸 없음 · 안 꽂으면 그 자리에서 바로). 견본 demo1 = 일자형 교훈 이야기(선택 2 · 💥 2).
- **세계 판 주제 칸 + ＋ 자세히(WORLD-2 · 10-04 교사 '하나의 주제가 있으면 그 밑에 애들이 자유롭게')**: 선생님 '⚙️ 칸 바꾸기' = 기본 여섯 칸 이름·질문 고치기(질문을 바꾸면 옛 예시·줄기 문장은 빠짐) + 칸 더하기 최대 3(u1~u3) · 저장 boardList `wl`('k|그림|이름|질문' 줄 · 기본으로 돌리면 지움 · 카드 있는 칸은 못 뺌). 카드마다 '＋ 자세히' = `k:'wd'`, `p`=카드, `tag` look·sound·job·why(👀 모습 · 🔊 소리·말 · ⚙️ 하는 일 · 💡 까닭 — 🖼은 윈도10에서 깨져 안 씀) · 내 것만 고치기 · 남의 자세히가 있는 카드는 아이가 못 지움. 코치 '🔎 자세히를 덧붙인 카드 n/m' · 📤 정리 = 칸 → 카드(❤️) → └ 자세히 나무.
- **🌋 제일 큰 문제 + 🙋 고르기(BIG-1 · 10-10 교사 8단계 '큰 문제 칸 + ❤️ 투표' 채택 — 아이들은 칸마다 작은 것은 잘 쓰지만 세계 전체를 끌고 가는 큰 줄기가 없었다 · 아이에게 설계를 더 시키지 않고 AI가 큰 틀을 보기로 냄)**: 세계 판 맨 위 넓은 칸 `wprob`('이 세계에서 제일 큰 문제는? 누가 곤란해요? 해결하면?' · 목표 1 · 줄기 문장 '이 세계의 제일 큰 문제는·그래서·해결하면') · 🙋 고르기 카드 = 세계 카드 + `tag:'vote'`(**DB 규칙 그대로** — tag ≤8) · 카드에 '🙋 고르기' 표 + '✨ AI가 낸 보기' · ❤️ = '이걸로!' — **칸마다 하나만**(다른 보기의 내 ❤️는 뺌) · 아이 카드 수·목표에 안 셈 · 보기에 ❤️가 하나라도 있으면 그 칸은 정해진 것(✓) · 코치 '🙋 … 고르기 n장 — 지금 1등「…」(❤️n)' · ❤️ 같으면 '더 골라요' · 📤 정리 = '🙋 고르기 (❤️n) …' + 부탁 틀 두 줄(🌋 = 메인 퀘스트 줄기 · 🙋 = ❤️ 많은 보기로) · 선생님 쓰기 창 '🙋 고르기 카드로'(체크) · 보기에도 ＋ 자세히·💬. 기존 판의 '세계 채우기 %'는 칸이 7개가 되어 조금 내려감(정상).
  - **2바퀴 수업 흐름**: 1차시 아이들이 판 채우기(🌋에 아이 생각도 써도 됨) → 교사 **"세계 n번 판에 고르기 올려줘"** → Claude: REST `boards/w0n/flags` 읽기 → 아이 카드들을 묶어 🌋(필요하면 🎮·🏰) 칸마다 보기 2~3장 → `PATCH boards/w0n/flags {<id>: {k, tx, by:'✨ AI', tag:'vote', why, t:{'.sv':'timestamp'}, ord}}`(id = 'f' + 시각 base36 + 3글자 · tx ≤300 · why ≤200 = 어느 생각에서 왔는지('🌍·🏰 카드 3장에서') — **실제 아이 이름은 글·why에 넣지 않음** · 아이 생각에서 너무 벗어나지 않게) → 2차시 아이들 ❤️ 고르기 + 고른 보기에 ＋ 자세히 → 교사 **"세계 n번 판 만들어"** → 거친 시제품(10분) → 해 보고 💬 → 다듬기. 시험 = 스크래치 kv/bigvote.cjs(zz 판 · 세 창 · 끝나면 flags PATCH null + boardList DELETE).
- **SIM-1(10-03 · 4~6학년 시뮬레이션 — 세 아이가 실제 화면으로 이야기 판·세계 판을 끝까지)**: 결과 = 둘 다 완성(이야기: 두 갈래 모두 결말까지 · 세계: 구현 준비 100%). 시뮬레이션이 찾아 고친 것 — 이야기 줄기 점검(처음 → 문제가 생겨요 → 해결 → 끝 · 마지막 장면이 끝맺음 말이 아니면 '끝인가요?') · **고르기 = 보기마다 '→ 어느 장면?' 고르는 칸**(새로 쓸 장면 3개까지 · 저장은 예전처럼 '글 → N번 장면') · 줄기 문장 겹침 정리(dedupe) · 세계 코치 '이름만'·'짧은 카드' · 정리 글 장소 줄. 결과는 잠긴 견본 판 `demo1`(📖)·`demo2`(🌍)에 남김(n 90 — 목록 끝). 대본 = 스크래치 sim_story.cjs·sim_world.cjs.
