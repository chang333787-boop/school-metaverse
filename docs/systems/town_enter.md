## 지킨 것
- 실제 상호·상표 X(간판은 갈래 이름) · 판타지 X · 실명 X(주인·손님·이웃·요리사·선생님 = 이름 없는 역할 · 몸 있음 · 말풍선은 몸 위) · 사실만(꽃·음식·도구·명절·과학·우리말) · 셈 X · 지역 비하 X(바다·들·산·시내 이웃이 모두 자기 일) · 홍보판(SM_PROMO) = 들어가지 않음
- 보상 = 솜씨만(꼬리표 `ent:<갈래>` → rwCheck · `RW_XP.ent = 1` 갈래마다 하루 한 번) + 보이는 결과(봉투·접시·제자리·별·초록 표) · 다시 들어가면 "또 왔네요! 지난번에 고마웠어요." · 가방 팔기 = `ITEMS` 기본 값 · `mv:sell` · 가게에서 산 것(botN) 제외
- 렉: 방은 들어갈 때만 지음(town_indoor KIT · 합친 부품 + 인스턴스 · 글씨판 한 장) · 나오면 치움 · 결과 모습은 미리 숨겨 지은 부품(그리기 +0~4) · 매 프레임 일 0 · 새 Light X · 문 표시 고리·글자판은 예전 곳만(1,300곳에 그리지 않음 · E 안내만) · 문 자리 고치기(doorFix)도 예전 곳만
- 세상 짓기·기록 화면·구역 대표 건물은 예전 '들어가는 곳'(inKind0) 그대로 — 판 모습이 바뀌지 않게

## 더하는 법
`v2/games/town_enter.js` CATS에 한 줄: `re`(간판 이름 규칙) · `st`(방 꼴) · `h`(여는 때) · `slots`([이름, 진열 꼴, 물건 꼴, 색, 사실 한 줄] 넷) · `asks`([손님 말, 칸 번호, 칸(1·2)]) · `want`(가방에서 사 주는 것). 식당은 `menu`, 학원은 `quiz`([물음, [정답, 보기, 보기], 까닭]). 새 시간은 `town_hours.md`에 한 줄.
