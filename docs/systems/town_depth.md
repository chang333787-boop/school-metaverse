# 🧱 깊이 감사 — 다섯 겹 표(DEPTH-1 · 10-25~26)

> 사용자 10-25: "소방서 퀘스트 지금 한 10번 깨니까 개노잼이야 · 뭔가 다양하게 되어야 하는데 · 콘텐츠가 다양해지면서 깊이가 한 칸인 것들이 너무 많은 것 같아."
> 덧붙임: "단순히 가서 E 누르는 것도 싫고, 막대기 놀이(타이밍 막대·꾹 누르기)도 싫고, 적지 않은 스트레스를 받아 가며 성취하는 걸 하고 싶어."
> 규칙(town_lessons.md D): **새 활동은 다섯 겹 가운데 셋 이상 · 같은 활동이 열 번째에도 다르게 · 판단·구조는 막대·꾹 대신 몸과 자리로.**

## 다섯 겹(0/1)
| 겹 | 1점 기준 | 0점 예 |
|---|---|---|
| ① 상황 | 판마다 날씨·계절·때·자리·씨앗으로 **할 일 자체가** 달라짐 | 겉모습(색·날씨 그림)만 바뀜 |
| ② 판단 | 상황을 보고 고르는 것 · 틀리면 세상이 나빠짐(벌·점수 X) | 정답 하나 맞히기 · 때 맞춰 누르기 |
| ③ 대상 | 돕는·구하는·상대하는 대상이 판마다 다름 | 늘 같은 상대·같은 물건 |
| ④ 칸 | 잘하면 다음 판이 한 칸 어려워짐(도전 사다리 `town_lad.js` 꼴) | 솜씨가 올라도 같은 판 |
| ⑤ 이어짐 | 끝나도 세상·다음 날·기록·도감에 남음 | 끝 창 한 장으로 끝 |

- **막대·꾹** = 판의 본체가 '때 맞춰 누르기 막대' 또는 'E 꾹(채우기)'인가(✔ = 그렇다 → 몸·자리 판단으로 바꿀 후보).
- 표는 10-26 origin/main(JUDGE-1·2 · CASE-2 · TYPHOON-1 · BAG-2 반영) 코드와 문서를 읽고 매김. 화면으로 다 해 보지 못한 줄은 '(추측)'.
