### 사람 옮기기·세상 바꾸기(NPC-MOVE·WORLD-FX · 09-27 found2)
- 코드 = `v2/js/worldfx.js`(mapapi가 만든다 · 게임 파사드 `map.npc`·`map.world`) · 정본 docs/map_api.md §16 · 예시 `?game=fx_demo`(dev).
- 사람: world.js `person()`이 빌드 때 사람마다 청크 삼각형 범위·이름표 칸·몸 충돌을 `world.people`에 적는다(모양 변화 0). 숨기기 = 청크에서 그 삼각형을 빼고 그리기 범위를 줄임 · 옮기기 = 같은 부품으로 구운 대역(6명까지)이 길격자로 걸어감. **게임이 멈추면 정점 배열까지 원래대로**(`map.npc.checksum()` 같음). `person()`·`dGeo`·`sign()`·청크 병합을 고치면 found2 시험(`world.people` 58명 모두 parts·sign·cols)을 다시.
- 세상: 소품(발판·비탈·컨테이너·상자·단추·선풍기·현수막·풍선… — 보이는 것 = 충돌 + 길격자 막기) · 움직이는 발판(위에 선 나도 같이) · 방마다 불 · 문 연 채/닫은 채 · 칠판 그림 · 바람·튀는 판. 새 조명 없음 · 게임이 부르지 않으면 만들지 않음(게이트 영향 0).

### 오프닝 화면·놀이 고르기(TITLE-1 · 09-27)
- `v2/`를 그냥 열면 오프닝('정림초에 오신 것을 환영합니다!' · 3D 학교 한 바퀴 · ▶ 시작하기) → 놀이 카드 → 고르면 동그라미 닦기 + 카메라가 날아와 게임 시작(🎮 칩과 같은 `game.load`) · 게임 중 `🏠 메뉴` 칩으로 돌아옴. **`?game`·`?tour=1`·`?shot`·`?check=1`·`?health=1`·`?title=0`이면 오프닝 없음**(게이트·시험 주소는 예전 그대로 — 오프닝 없이 걸으려면 `?title=0`). 정본 docs/map_api.md §18.
- **멈춤 창·단축키(PAUSE-1 · 09-28 "Esc/Alt+Tab 안 누르면 메뉴를 못 누름")**: 마우스 잠금이 사용자 Esc로 풀리면 '⏸ 잠깐 멈춤'(▶ 계속하기 · 🏠 메뉴로 · 🎮 놀이 바꾸기 — 게임·창이 스스로 푼 잠금은 제외 `busy()`) · **P = 멈춤 창**(잠금 중에도) · **G = 🎮 놀이 고르기** · 창 안 1/Enter 계속 · 2 메뉴 · 3 놀이 · Esc 닫기. 코드 = main.js PAUSE-1 블록(`window.__pause`). 새 단축키를 쓸 때 P·G와 겹치지 않게.
- 코드 = `v2/js/title.js`(main.js 고리: `CAM_OVR` 카메라 · `CTRL.wave` 손 흔들기 · `window.bootP` 로딩 막대) · 모양 = `v2/title.css`(휴대폰 배치도 이 파일 `@media` — 고치면 index.html `title.css?v=`). **카드는 `v2/games/registry.js`에서 자동**(dev 아닌 것) — 새 게임은 `icon`·`group`('탐험'|'대결'|'모험'|'이야기')·`short`(카드 한 줄)·`best`(카드 기록 `{k, u, lbl}`)를 적으면 카드가 예쁘게 나온다(없어도 🎮·'놀이'로 보임).

### 보이는 행동·버스 안(ACTION-1 · BUS-1 · 09-28 아이 "상호작용이 말만 되고 실제로 보이지 않는다")
- **말풍선만 뜨는 지점은 만들지 않는다.** 지점(E/✋)을 누르면 `v2/js/actions.js`의 `play(이름, o)`가 대상 쪽으로 돌아서서 한 발 → 자세(허리·팔·고개) → 손 소품(분무기·마이크·물뿌리개·책·펜·지우개·숟가락) → 물줄기(관 1)·알갱이(인스턴스 1)·음표(인스턴스 1) → 원래 자세 → 알림 글은 동작 뒤. 움직이면 바로 멈춤 · 새 조명 없음 · 쉬는 동안 비용 0. 게임은 `map.player.act(이름, o)`. 정본 docs/map_api.md §19.
- 앵커는 world.js 지점 필드만: `at`(대상 · wash는 넷째 값 = 물 닿는 높이) · `ats`(여럿 중 가까운 것) · `mic`(스탠드 마이크) · kind 'sit'의 `seat {x,y,z,yaw,table?}`(서는 칸 = h.x·h.z 통로, 몸은 좌석 위 — 식탁 90·버스 18) · `pump`(손소독제). 앉아 있을 때 E = 일어나기.
- 급식실: 배식대에서 식판 → 빈 빨간 의자에 앉으면 식판이 식탁에 놓이고 숟가락질(8초에 빈 식판) → 반납대. 음수대(로비·급식실 입구)는 물받이에서 위로 솟는 꼭지. 신발장 = 신발 색이 바뀜(운동화 파랑 ↔ 실내화 흰색 · kid.js `setShoe`).
- 버스(`SCHOOL.bus`): 앞문(북) 접이문이 다가가면 열림 → 계단 3단 → 좌석 2+1 아홉 줄 · 구역 '버스 안'(도달 구역 101) · 교감선생님은 앞문 앞을 비워 0.8m 서쪽.
