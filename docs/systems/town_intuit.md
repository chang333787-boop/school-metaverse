# 🧭 직관 — 이야기가 등뼈(INTUIT-1 · 10-18)

사용자 10-18: "4학년 애들한테 동물의 숲을 시켜 · 그럼 스토리 따라다니면서 무난하게 할 거 할 것 같은데 · 우리 게임은 직관이 부족한 것 같은데?"

먼저 `town_lessons.md`를 지킨다. 이 문서는 그 위의 '흐름' 규칙이다.

## 왜 동물의 숲은 4학년이 그냥 따라가나
| 동물의 숲 | 우리(10-18 전) |
|---|---|
| 길잡이 하나(너굴·여울)가 늘 직접 다음 할 일을 말함 | 오늘 할 일 · 이야기 · 의뢰 게시판 · 승급 미션 · 보너스 문제가 첫날부터 같이 나와 서로 겨룸 |
| 첫날 화면이 거의 비어 있고, 할 수 있는 것이 하나씩 늘어남(도구·다리·가게) | 첫 화면부터 칩 열 개 넘게(함께하기·바로 가기·장소·마을 모습·자전거·메뉴·칸·시간·작은 지도·나침반 띠·키 안내) |
| 다음 목표 = 그 사람 머리 위 말풍선·느낌표(세상 안 표시) | 다음 목표 = 화면 위 글 줄을 읽어야 함 |
| 한 번에 한 동작을 해 보며 배움(삽 → 파기) | 창에 설명 글이 먼저 |
| 하루에 할 것이 몇 개로 정해져 있음 | 할 것이 너무 많아 무엇부터인지 모름 |

## 규칙
1. **이야기가 등뼈.** 메인 이야기는 끝나면 다음 장이 저절로(10-18 완료). 다른 갈래(오늘 할 일 · 의뢰 게시판 · 승급 미션 · 보너스 문제 · 도감 · 직업 체험)는 **이야기 안에서 처음 소개되기 전까지 숨김**. 소개되는 순간 = 새 친구나 이웃이 말로 소개 + 그 칩·창이 그때 나타남.
2. **화면은 점점 열림(진행 열림 · HUD 단계).**
   - 0단계(정문 밖 첫걸음): 이야기 할 일 줄 + 나침반 띠 + 메뉴만.
   - 1막 중: 작은 지도(접힘 → 1-1에서 지도 배울 때 펼침) · 큰 지도 M(1-1).
   - 2막: 자전거 B(자전거 배우기 장) · 오늘 할 일(2-x에서 '이웃 일 돕기' 소개) · 가방.
   - 3막: 버스·지하철(그 장에서) · 의뢰 게시판(본부 소개 장) · 도감 · 솜씨·승급.
   - 장소 찾기 F · 마을 모습 Y · 함께하기 · 바로 가기 J = 메뉴 안에(첫날 칩 X).
   - 선생님 칸·시험 주소(`?all=1`)는 모두 열림.
3. **다음 목표는 세상 안에.** 이야기 다음 목표(사람·장소) 머리 위에 큰 표시 하나(📜 또는 ❗ · 멀리서도 보임 · 하나만). 글 줄은 보조.
4. **한 번에 한 동작.** 처음 10분은 단계마다 새 조작 하나(걷기 → 둘러보기 → E → 대화 넘기기 → 지도 M → 고르기). 창 글은 두 줄 안.
5. **하루 몫이 보임.** 이야기 한 장 + (열렸으면) 오늘 할 일 셋. 그 밖은 '더 하고 싶으면' 메뉴에.

## 짓는 순서
1. HUD 진행 열림(엔진·UI) — 칩마다 `unlock` 키 · 저장 · 열릴 때 새 친구 한 줄 + 칩이 살짝 나타남(튀는 움직임 X)
2. 다음 목표 표시(이야기) — 세상 안 표시 하나 + 가까워지면 작아짐
3. 이야기 장에 '소개' 단계 넣기 — 오늘 할 일·가방·자전거·버스·지하철·게시판·도감이 처음 나오는 자리
4. 끝까지 깨기 봇(PLAYTHRU-1)으로 처음 30분을 다시 재기: 막힌 곳 0 · 손 놓고 기다린 시간 · 칩 수
