# 학교 맵 — 배치·지형·물리·재질·실제 학교 맞추기·기준선

> CLAUDE.md에서 옮긴 정본(10-10 — 줄은 그대로). **언제 읽나**: 학교 맵(layout.js·world.js — 벽·바닥·가구·지형·문)을 고치거나 실제 학교와 맞출 때. 늘 지킬 규칙(개인정보·홍보판·이모지·캐시·게이트·NPC)은 CLAUDE.md에 있다.

## 배치 규약 (v1 data.js에서 이어진 개념 — 지금 값은 v2/js/layout.js)
- 좌표: x=동서(동쪽+), z=남북(남쪽+), 단위 미터. 실 `span=[x0,x1]`은 월드 좌표 x 구간. 실 폭은 배치도 픽셀 실측 비율
- `building.front`: 앞줄(원무실~3학년, 1층만) — 문은 북측 주 복도로, 현관은 남쪽 바깥과 연결. westDoor/eastDoor = 바깥문 z
- `building.wings[]`: 주 복도에 바로 접한 서관만 (twoStory). `innerOnly: true`(문서고)는 복도 문 없이 옆방(나래반)에서 진입
- `building.kitchen`: 급식동 — 문은 동쪽 세로복도(doorZ), 뒤쪽 바깥문(backDoorX)
- `building.linkCorridor`: 현관 북쪽 세로복도 → 동관 복도와 연결
- `building.eastWing`: 동관(2·4학년·과학실·창고) — **앞줄과의 사이는 야외 마당**. 복도는 건물 북측, 방 문은 북쪽으로. yardDoor = 주복도→마당 문 x
- `building.upper`: 서관 위 2층(6학년|5학년|소담실). 계단실(type 'stair') = **실내 12단 직선 계단**(경사로 아님 — 2026-07-31 정정). 서관 계단실 동측 x −15.1~−12, 남(z−39)→북(z−47.5) 오름. ⚠️실물은 계단참에서 180° 꺾이는 U자형 — 미반영(계획 Phase 8)
- room `type`: classroom / office / nurse / cafeteria / library / science / computer / hall / toilet / storage / stair / daycare
- 가구는 방 상대 좌표 자동 배치(furnish) — 방 폭·깊이 바뀌어도 벽 뚫림 없음

## 지형 단차 (v0.12)
- 학교 부지=테라스 y0, 운동장 쪽(z > TERR_Z=-18)=y-1. 경계엔 옹벽·중앙 계단·동서 경사로·구령대
- world.js의 `YOFF`(구역 오프셋)와 `terrY(z)`가 지형 기준 — **남측(운동장 레벨)에 오브젝트를 추가할 땐 YOFF=-1 구간 안에서 생성하거나 terrY(z)를 적용할 것.** tree/pine/bush는 자동 지형 대응
- 공(BALLS)은 `gy`(지면 높이) 프로퍼티 사용

## 시간대·공 (v0.10)
- 시간대: 우하단 버튼 낮→노을→밤 순환, `SD.time('day'|'sunset'|'night')`. 전환 시 그림자 1회 재굽기. **실시간 시간 흐름은 넣지 않는다** (연속 재굽기=프레임 붕괴)

### 배치·높이·무늬 (LAYOUT-3 · 09-24)
- **v2 배치의 단일 수정 지점 = `v2/js/layout.js`**(v1 `js/data.js`는 참고용 그대로). 근거표 = `docs/layout_v3.md`.
- **높이 세 층**: 건물 바닥 0 / 앞뜰·대지 `terrain.yard`(-0.3) / 운동장 `terrain.field`(-1.35). 바깥 물건은 `tY(z, x)`(= `terrainAt`)로 놓는다. 건물 밑은 `foundation()` 상자(드러난 면만 벽 바깥 면까지 — 이웃 건물 기초와는 맞댐, 겹치면 감사).
- **무늬 층(PATTERN-1)**: 바닥·천장·겉벽 무늬는 `patQuad`/`patWall`(무늬마다 캔버스 1장·메시 1개). 바닥은 벽 안쪽 면 사이를 정확히(`floorQ`), 문 밑은 `wallRun`이 문턱을 채운다. 천장은 `ceil(…, kind)` — 벽이 없는 경계는 ±0.16을 넘겨 틈 없이 맞댄다.
- **조명은 `lamp()`**(한 메시). `flatBox`처럼 등마다 메시를 만들지 않는다.
- **비탈은 `slope()`**(보이는 비탈 사각형 + 보이지 않는 계단 충돌). 끝의 세모 면은 `slopeCap()`.
- 옆 고정 유리가 붙은 유리 양문은 `slideOver: true`(유리 앞으로 12cm 비켜 미끄러짐 — 간섭 검사 제외). 문 색은 gap의 `color`.
- **실내 디테일 컬링(INTERIOR-CULL)**: 건물 안 디테일 청크('i')는 카메라가 밖이면 20m·안이면 30m, 바깥 디테일은 55m까지만 그린다(main.js `detailTick`).
- **팻말·비상구는 `sign()` 아틀라스**(조명 무시 → 밤에도 빛남). 비상구 유도등 = `exitSign(x, z, y, [nx, nz])`(벽 안쪽 면 위 점·면 법선). 바깥으로 나가는 문을 새로 내면 인방에 하나 단다.
- **넓게 퍼진 먼 배경(산 등)은 `dGeo(..., { far: true, at: [x, z] })`로 한 청크에 합친다** — 그냥 두면 16m 청크마다 드로우콜이 는다(먼 산 15덩이 = +9콜이었다).
- 하늘(구름 한 메시·태극기 펄럭임)은 main.js `skyTick`. 시간대 색은 `CLOUD_TINT`.

### 물리 규칙 (PHYS-1/2 · 09-23)
- 몸: 반지름 0.26(충돌 상자 부풀림)·키 1.5·오름 **발+0.55**·점프 정점 0.97 → 점프로 닿는 윗면 = 발+1.52.
- 바닥 찾기는 **발+0.55까지만**(`groundAt(x,z,max(이전y,현재y))`). 예전 `P.y+0.6`(=발+1.15)은 가구→천장→지붕으로 계단 타듯 올라가는 구멍이었다. 머리 부딪힘은 `ceilAt`.
- **올라서면 안 되는 것**(책상·의자·식탁·사물함·신발장·차·울타리·담장·개수대·배식대)은 `NS`/`noStand()` — 충돌 높이 ≥1.6(점프 도달 1.52보다 높게)·`nc`(카메라 무시).
- **보이는 것은 뚫리면 안 된다** — 사람(선 사람 0.44각·앉은 사람 의자 위)·골대 그물·정글짐·그네 의자·시소 판·정자 난간에 충돌. 학교 둘레 울타리(bounds)로 밖에 못 나감.
- 원래 올라서는 곳(계단·구령대·체육관 무대·미끄럼틀 발판·그루터기·벤치·침대)은 그대로 둔다.

### 재질 규칙
- **아래를 향한 면은 HemisphereLight의 groundColor(갈색 땅)에 물든다.** 천장·형광등은 정점색을 밝게 해도 소용없으므로 조명을 받지 않는 `MeshBasicMaterial`로 만든다.
