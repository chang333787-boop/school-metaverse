# 🎨 사진을 보고 땅 결 올리기(ART-3 · 10-18 설계안)

사용자 10-18: "갯벌처럼 사진 넣을 수 있는 곳들 찾고 그래픽 갯벌처럼 업데이트 방안도 해야지"

먼저 `town_lessons.md`를 지킨다. 갯벌(ART-2)과 같은 길을 따른다.
- **사진은 참고만 해요.** 사진에서 색·무늬 간격·물기·계절 변화만 읽어 숫자로 옮겨요.
- **실사 텍스처는 쓰지 않아요.** 사진 원본도 저장소에 넣지 않아요(CLAUDE.md 개인정보·안전).
- **렉 규칙**
  - 땅 종류마다 메시 하나에 셰이더 하나를 써요. 땅 삼각형 가운데 그 칸만 떼어 내요(같은 정점값이라 같은 평면 겹침이 없어요).
  - 그리기 횟수는 종류마다 +1을 넘기지 않아요.
  - 새 Light와 후처리는 넣지 않아요.
  - lite(크롬북) 판은 한 겹만 그려요.

## 짓는 차례(한 곳 = push 하나)
1. 논(사진이 없으면 지금 있는 자료로 먼저 · 사진이 오면 색만 맞춤) — 견본 캡처를 보여 주고 확인을 받은 뒤 나머지로 넓혀요(모션그래픽 규칙과 같게).
2. 그다음 밭 → 강 → 염전 → 모래사장 → 숲 가장자리 → 보도 차례로 해요.
3. 곳마다 `?artoff=` 키를 하나씩 더하고, GPU 몫과 크롬북 CPU 4× p95를 재요(`art2/gbench.cjs`).

## 선생님이 정할 것
- 사진을 어디서 찍을지(학교 둘레 논·밭 · 현장 체험 사진). 얼굴과 학교 이름은 나오지 않게 해 주세요.
- 1번(논) 견본을 먼저 볼지, 1~3번을 한꺼번에 할지.

## 짓기 기록(10-24)
논·밭·강은 이미 땅과 따로 그리는 판(논·밭 = 구역마다 판 · 강 = 물 띠 · 둔치 = 덮개 메시)이라 땅 삼각형을 떼지 않았어요. 그 판의 재질에 셰이더 조각만 덧붙였어요(`town_look.js` `art3()` · 그리기 수 +0 · 새 Light·후처리 X · 매 프레임 새 객체 X · lite = 한 겹).
사진은 일반 공개 사진을 보는 셈으로만 숫자(모 줄 30cm 안팎 · 그루터기 40×30cm 언저리 · 자갈 24cm · 물가 젖은 띠 1m)를 정했고, 사진 파일은 쓰지 않았어요.

| 곳 | 끄는 키 | 바꾼 것 |
|---|---|---|
| 논 | `?artoff=paddy` | 봄 = 줄 사이 물 거울(흙탕 바탕 + 하늘 비침 + 잔물결 + 좁은 해 빛) · 여름 = 벼 줄 곁 그늘(해 반대쪽이 더 어둡게) · 가을 = 줄 사이도 누런 이삭 + 갈대와 같은 바람 물결 · 겨울 = 그루터기 점(조금씩 어긋남 · 멀면 사라짐 · lite 없음). 판에 `ac_a`(줄 건너는 축)를 더함 |
| 밭 | `?artoff=field` | 이랑 비탈 = 해 쪽 밝게, 반대쪽·고랑 어둡게(멀면 고르게) · 비 = 땅과 같은 젖음 조각(wetChain)을 밭 재질에도 + 고랑에 물기 더 진하게(lite는 윤기 없음) |
| 강·둔치 | `?artoff=river` | 강 물낯 = 하늘 비침 + 흐름 따라 길게 흘러가는 물살 결 + 여울 흰 물결(강 따라 군데군데 · 자리는 그대로) + 좁은 해 빛 · 둔치 덮개 = 새 재질 `MAT.cap`(땅과 같은 조각 + 물가 4m 자갈 띠 · 1m 젖은 띠 · 겨울엔 눈이 덮어 옅게) · 덮개 밑 땅 꼭짓점도 물가는 자갈빛(덮개 가장자리 톱니가 풀빛으로 튀지 않게). 덮개에 `sd_a`(석축 선까지 거리)를 더함 |

- 계절 = `uSea_a`(봄·여름·가을·겨울 무게) · 비 = `uRain_a`(내 자리 비 세기 · 몇 초에 젖고 1분쯤에 마름) — 0.5초마다 한 번 고침.
- **성능(크롬북 CPU 4× · town_tour)**: 전 all.p95 18.3ms · over33 4 → 후 18.2ms · 4. town_check frames.worst 전 48ms → 후 38ms(이 판은 전부터 38을 넘나듦 · 흔들림). 같은 자리 GPU 몫(끈 판 ↔ 켠 판 · 두 번씩): 데스크톱 0.99~1.28ms ↔ 0.99~1.28ms · lite 0.76~1.05 ↔ 0.76~0.97 — 차이 0.05ms 안. 그리기 수는 곳마다 같음(논 130·밭 142·강 131).
- 관문: 게이트 17/17 · town_check 같은 평면 0 · 뚫림 0 · 오류 0 · town_hud 실패 0.
