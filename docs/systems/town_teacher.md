사용자 10-31 '2주 믿게 만들기' 셋째. 비판 보고서(town_critique_1031.md) 기준 8 · §4-2 · §6-4: 반 기록을 보려면 기기마다 JSON을 복사해 패들렛에 붙여야 했고, '이 장 바로 열기'·'다시 세는 날로 넘기기'·날씨 단추가 비밀번호 없이 아이에게 열려 있었다.

선생님 칸 들어가는 곳: 이야기 창(Q) 맨 아래 「🔒 선생님 칸」 · 마을 메뉴(☰) 「🔒 선생님 칸」.

**아이가 몰라도 막히지 않게**
- 날씨 창: 예보·기온은 그대로. 계절이나 날씨가 고정된 판(예전에 아이가 눌러 둔 판)이면 「📅 달력대로 돌아가기」·「📅 예보대로 돌아가기」만 보임 — 반 공통 흐름으로 돌아가는 단추라 비밀번호 없음.
- 계절 문(반딧불이·벼·비 오는 계절): '기다리는 동안 다른 이야기 · 선생님이 바꿔 줄 수도' · 계절이 멈춘 판이면 '달력대로 돌아가기'를 알려 줌. 비 기다리기는 예보대로(넷 중 하루꼴 비).
- 이야기 진행 단추(계속하기·힌트·쉬기·저녁까지 기다리기·자기·침대에서 쉬기·태풍 날 ⏩)와 시계 멈추기(내 판만 쉼)는 그대로 — 내 판의 놀이 흐름이라 반 진행을 갈라 놓지 않음.
- 아이 글에서 '날씨 칩에서 계절을 바꿀 수 있어요'를 뺌(계절 힌트 셋 · 비 그치기 힌트 · 스키 · 텃밭 겨울 안내) → '선생님이 바꿔 줄 수도'·'예보에서 맑은 날 찾기'. 선생님 모드일 때는 예전 글 그대로.
- 남은 길(이번에 안 막음): 주소 꼬리 `?all=1`·`?plan`(시험 하네스 81개가 씀) · 함께하기 방 선생님 신호는 방을 만든 기기만(lobby.js · 비판 §6-1 별건).

## 2. 교사 화면(반 표)
선생님 칸 → 「📋 반 표 열기」. 한 줄 = 한 아이(번호). 칸 다섯: **번호 · 지금 장(n/m · 끝낸 장 수) · 오늘 한 일(단계·장 끝·문제 맞힘/푼 수·일·보물 지도… · 힌트 끝까지 간 단계 = 빨간 '막힘') · 남긴 결과물(가장 새 한 줄 카드·까닭·불편해질 사람 · 외 n) · 마지막 접속**. 줄을 누르면 자세히(남긴 것 셋 · 그날 끝낸 장 · 끝낸 장 목록). 아래 한 줄 = 줄 수 · 오늘 기록 수 · 오늘 막힌 번호 수 · 안 보이는 번호. 25줄이 1366×768 한 화면에 들어감(창 높이 768·680 둘 다 창 스크롤 0 · 680 = 크롬북에서 주소창을 뺀 어림 · 낮은 창이면 줄 높이를 줄임).

자료 셋(위 띠에서 고름):
1. **이 기기 판** — 이 크롬북의 같은 반 번호 판(`sm-town-game:<마을>@<반>:sNN`) + 번호 없는 칸(칸 1~3). 이 탭 판은 지금 상태 그대로.
2. **붙여 넣기** — 기기마다 학급 기록 「복사하기」로 받은 글을 여러 개 한꺼번에(패들렛 칸을 통째로 복사해도 됨 · 앞뒤 다른 글·깨진 덩어리는 건너뜀). 복사 글에 이제 `n`(출석 번호 · v4 번호 로그인일 때만)과 `sum`(표 한 줄 요약)이 들어감. 같은 번호가 여럿이면 마지막 저장이 새것 하나만.
3. **☁️ 서버** — 반 코드 + 교사 열쇠 → `/class`. 서버는 배포돼 있음(11-08 `/class`가 '이 반은 아직 교사 열쇠가 없어요'로 답함) — 반에 교사 열쇠가 없으면 처음 정하기 칸이 나옴. 받은 표에만 여섯째 칸 **🔑 비밀번호**가 붙음 — 줄마다 「풀기」(PIN-1 · §3-1).

요약 = `v2/games/town_tsum.js`(순수 함수 · 마을과 서버가 같은 것): 지금 장 · 쉼 · 며칠 뒤 · 끝낸 장 · 마지막 기록 날 갈래별 수 · 남긴 결과물 셋 · 마지막 저장 시각. 이름·비밀번호·기기 번호 X. 한 아이 약 0.4KB.

## 3. 서버 엔드포인트(server/cf-rooms · 11-08 배포 확인 — 예전 글 '배포 X'는 옛말)
| 주소(POST · JSON) | 본문 | 답 |
|---|---|---|
| `/tclaim/<반코드>` | `{tkey}` | 처음 정함 `{ok, made:1}` · 같은 열쇠 `{ok, made:0}` · 다른 열쇠가 이미 있음 409 |
| `/class/<반코드>` | `{tkey}` | `{ok, at, L:[{n, at, s, np}]}` — s = 요약 · np = 비밀번호가 비어 있음(풀림 · PIN-1) · 열쇠 없음 404 `{nokey:1}` · 틀림 403 · 잠김 423 |
| `/pinclear/<반코드>/<번호>` | `{tkey}` | 그 번호 비밀번호만 비움 `{ok, had:1}` · 그 번호 줄이 없음 `{ok, had:0}` · 열쇠 검사·잠금은 `/class`와 같은 함수(404 `{nokey:1}` · 403 · 423) — PIN-1(§3-1) |
| `/treset/<반코드>` | `{admin, tkey}` | 비밀값 `ADMIN`이 맞을 때만 교사 열쇠를 바꿈 · `ADMIN`을 안 넣은 서버는 늘 403 |

- 교사 열쇠 = 띄어쓰기 없이 6~32자 · 서버엔 `SHA-256(PEPPER | 반코드 | T | 열쇠)`만 · 5번 틀리면 10분 잠금(정하기 다툼 409도 틀림으로 셈) · 이 탭 메모리에만 두고 잠그면 지움.
- 요약은 아이 저장(`/save`) 때 한 번 만들어 `s.sum` 칸에 둠 → 표를 열 때 판 25개를 다시 읽지 않음. 예전 판(요약 없음)은 표를 열 때 열 개씩 채움. 표 하나 = 요청 1건(25명 약 11KB).
- 표 칸 더하기는 `ALTER TABLE s ADD COLUMN sum`(있으면 그대로) + 교사 열쇠 표 `t` 한 줄. 아이 저장·이어 하기(`/save`·`/load`·`/drop`)는 그대로.
- Origin·반 코드 꼴·크기 검사는 저장과 같음. Firebase 규칙은 손대지 않음.
- 흉내 시험: `node --no-warnings server/cf-rooms/test_teach.mjs`(64개 · ⑥ PIN-1 28개) · 흉내 서버 `node server/cf-rooms/mock.mjs <포트>`(마을을 `?cf=http://127.0.0.1:<포트>`로) · 마을까지 잇는 시험 `zsh tools/ops/b2.sh node tools/harness/town_teach.cjs ourtown <포트> [--pics=폴더]`(40개 · 흉내 서버를 빈 포트에 스스로 띄움 · 시험 반 zzteach는 메모리 DB라 끝나면 사라짐).

### 3-1. 아이 번호 비밀번호 풀기(PIN-1 · 11-14)
- **화면**: ☁️ 서버 판을 받은 뒤에만 여섯째 칸 「🔑 비밀번호」 — 줄마다 작은 「풀기」(이 기기 판·붙여 넣기 판·열쇠 넣기 전에는 없음). 누르면 그 줄 바로 아래 한 줄로 한 번 더 물음 「7번 비밀번호를 풀까요? 판(진행)은 그대로예요」 [🔑 풀기] [그만] → 「7번 비밀번호를 풀었어요. 그 아이가 들어와서 새 비밀번호를 정하면 돼요」 · 그 줄은 「풀림」(아이가 새로 정한 뒤 표를 다시 받으면 「풀기」). 맨 아랫줄에서 눌러도 묻는 줄이 창 안에 보임. 영어 글도 같이(Clear · cleared). **아이 화면에는 새 창·새 단추 없음.**
- **서버**: `POST /pinclear/<반코드>/<번호>` 본문 `{tkey}` — `/class`와 같은 함수·같은 잠금(틀리면 세고 다섯 번이면 10분). 그 번호의 비밀번호만 비우고 틀린 횟수·잠금을 0으로(`data`·`sum`·`at` 그대로). 그 번호 줄이 없으면 만들지 않고 `{ok, had:0}`.
- **비밀번호가 빈 줄**: `/load`·`/save`가 오면 그때 보낸 비밀번호가 새 비밀번호(처음 잡는 것과 같음 · 판은 그대로 돌려줌) · `/drop`은 받지 않음(403 `{nopin:1}` — 비어 있는 동안 아무 네 자리로 판을 지울 수 없게 · 새로 정한 뒤에는 예전처럼) · `/class` 줄에 `np:1`.
- **알림**(있는 알림 한 줄 꼴): 틀린 열쇠 403 「교사 열쇠가 달라요. 열쇠를 다시 넣고 받아요」(열쇠 칸으로 돌아감) · 잠김 423 「잠깐 잠겼어요. 10분 뒤에 다시 해요」 · 주소 없음 404 「서버가 아직 준비 중이에요. 조금 뒤에 다시 해요」 · 끊김 「서버에 닿지 못했어요. 인터넷이 끊겼거나 서버가 아직 준비 중이에요. 조금 뒤에 다시 해요」(이 주소를 모르는 옛 서버는 미리 묻기(OPTIONS)에 허락 머리 없이 404로 답해 브라우저에는 끊김으로 보임 → 두 까닭을 한 줄에).
- **정한 것**: ① 번호를 직접 골라 푸는 줄은 만들지 않음 — 서버 줄은 첫 저장 때 생기고, 줄이 있으면 요약이 비어도 표에 나옴(줄이 없으면 풀 비밀번호도 없음 · 그 아이는 그냥 들어와 정하면 됨) ② 교사 열쇠를 새로 저장하지 않음(받을 때 넣은 것을 이 탭 메모리에서 그대로 씀 · 잠그면 지워짐) ③ 줄 단추 글은 「풀기」만(🔑는 칸 머리와 확인 단추에만 — 25줄에 같은 그림을 늘어놓지 않음).
- **알아 둘 것**: 그 번호로 **열려 있는 창**이 있으면 다음 저장(45초마다)·확인(3분마다)이 옛 비밀번호로 다시 잡음 → 그 창을 먼저 닫고 풀기 · 푼 뒤 먼저 들어오는 사람이 새 비밀번호의 주인(반 코드와 번호를 아는 다른 아이일 수 있음 → 바로 정하게) · 해 본 적 없는 기기에서는 새 네 자리 한 번으로 정해짐(아이 화면을 바꾸지 않음 · 잘못 눌렀으면 다시 풀기) · 노란 번호(그 기기에서 해 본 번호)는 「비밀번호를 잊었어요」 → 선생님 비밀번호로 기기 기록도 지워야 새로 정할 수 있음.
- **시험**: 서버 흉내 `node --no-warnings server/cf-rooms/test_teach.mjs`(⑥ 28개) · 마을까지 `zsh tools/ops/b2.sh node tools/harness/town_pin1.cjs ourtown <포트> [--pics=폴더]`(44개 · 흉내 서버를 8923에 스스로 띄움 · 시험 반 zzpin1 = 메모리 DB) · 배포 서버 확인 `node --no-warnings server/cf-rooms/test_teach.mjs https://<배포 주소>`(시험 반 zzpin1 31번 · 끝나면 그 번호 판을 지움 · 교사 열쇠 해시 한 줄은 남음).

## 4. 배포하면 무엇이 되나 · 교사가 정할 것
(예전 '배포 전' 때: 선생님 칸 잠금 · 이 기기 판 표 · 붙여 넣기 표만 됨.) 11-08 = 서버 배포 확인 · 선생님 칸은 닫으면 늘 잠김(✕·Esc·바깥 포함) · 켜져 있는 동안 오른쪽 칩 「🔒 선생님 모드 — 눌러서 잠그기」 · 선생님 비밀번호 세 번 틀리면 1분 쉼(이 탭 `sm.tpf`) · v4 번호 비밀번호 두 번 틀리면 '선생님께 풀어 달라고 말해요'(DEB-1) → 푸는 길 = 반 표 ☁️ 서버 판 「풀기」(PIN-1 · §3-1).

배포 뒤(`npx wrangler deploy` 한 번): 반 코드로 이어 하는 아이들(v4 `?cls=`)의 판 요약이 저장 때마다 서버에 생기고, 선생님은 어느 기기에서든 반 코드 + 교사 열쇠로 25명 표를 한 번에 받음. 패들렛 붙이기가 필요 없어짐.

교사가 정할 것:
1. **배포할지** — `server/cf-rooms`에서 `npx wrangler deploy`(로그인은 이미 됨 · 아이 저장 코드는 바뀌지 않음).
2. **교사 열쇠를 언제 정할지** — 반 코드를 아이에게 주기 **전에** 선생님 칸 → 반 표 → ☁️ 서버에서 처음 정하기. 먼저 정한 사람이 주인이라, 아이가 먼저 정하면 3번이 필요함.
3. **관리 열쇠를 넣을지** — `openssl rand -hex 16 | npx wrangler secret put ADMIN`. 넣으면 열쇠를 잊거나 빼앗겼을 때 `/treset`으로 바꿀 수 있음(넣지 않으면 그 반 열쇠는 바꿀 길이 없음 · 새 반 코드로 옮겨야 함).
4. 선생님 비밀번호(memoPin)는 숫자 넷이고 해시가 공개 DB에 있어 마음먹으면 풀림(예전부터 · 비판 §3-5). 아이 화면 잠금은 '모르고 누르는 것'을 막는 문이고, 반 기록 서버는 그와 별개인 6자 넘는 교사 열쇠로 지킴.
