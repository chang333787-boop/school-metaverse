# 🔒 선생님 칸 · 교사 화면(TEACH-1 · 10-31)

사용자 10-31 '2주 믿게 만들기' 셋째. 비판 보고서(town_critique_1031.md) 기준 8 · §4-2 · §6-4: 반 기록을 보려면 기기마다 JSON을 복사해 패들렛에 붙여야 했고, '이 장 바로 열기'·'다시 세는 날로 넘기기'·날씨 단추가 비밀번호 없이 아이에게 열려 있었다.

## 1. 잠근 단추(선생님 칸 하나로 모음)
비밀번호 = 지금 있는 선생님 비밀번호(lobby.js `teacherPin` · Firebase `memoPin` 해시 · 메모장·블록·함께하기 방과 같은 숫자 넷). 맞히면 그 탭만 선생님 모드(`sessionStorage sm.t`).

| 단추 | 예전 자리 | 지금 |
|---|---|---|
| ▶ 이 장 바로 열기(장 = 차시 카드) | 이야기 창 맨 아래 `<details>` | 선생님 칸 → 장 고르기 |
| ▶ 바로 열기(단원별로 보기) | 이야기 창 맨 아래 `<details>` | 같은 창 아래 |
| ⏩ 다시 세는 날로 넘기기 | 이야기 창 `<details>` | 선생님 칸(며칠 뒤 의뢰가 있을 때만) |
| 계절 고정(봄·여름·가을·겨울) · 날씨 고정(맑음·비·눈) | 날씨 창(누구나) | 날씨 창은 선생님 모드에서만 이 단추를 보임 · 누름도 선생님 모드만 받음 |
| 📊 학급 기록(이 기기) | 이야기 창 `<details>`(비밀번호) | 선생님 칸 |
| 선생님 모드 끄기 | 없었음(탭을 닫아야 꺼짐) | 선생님 칸 「잠그고 닫기」 = `sm.t` 지움 → 칩·바로 가기 제한도 아이 화면으로 |

선생님 칸 들어가는 곳: 이야기 창(Q) 맨 아래 「🔒 선생님 칸」 · 마을 메뉴(☰) 「🔒 선생님 칸」.

**아이가 몰라도 막히지 않게**
- 날씨 창: 예보·기온은 그대로. 계절이나 날씨가 고정된 판(예전에 아이가 눌러 둔 판)이면 「📅 달력대로 돌아가기」·「📅 예보대로 돌아가기」만 보임 — 반 공통 흐름으로 돌아가는 단추라 비밀번호 없음.
- 계절 문(반딧불이·벼·비 오는 계절): '기다리는 동안 다른 이야기 · 선생님이 바꿔 줄 수도' · 계절이 멈춘 판이면 '달력대로 돌아가기'를 알려 줌. 비 기다리기는 예보대로(넷 중 하루꼴 비).
- 이야기 진행 단추(계속하기·힌트·쉬기·저녁까지 기다리기·자기·침대에서 쉬기·태풍 날 ⏩)와 시계 멈추기(내 판만 쉼)는 그대로 — 내 판의 놀이 흐름이라 반 진행을 갈라 놓지 않음.
- 아이 글에서 '날씨 칩에서 계절을 바꿀 수 있어요'를 뺌(계절 힌트 셋 · 비 그치기 힌트 · 스키 · 텃밭 겨울 안내) → '선생님이 바꿔 줄 수도'·'예보에서 맑은 날 찾기'. 선생님 모드일 때는 예전 글 그대로.
- 남은 길(이번에 안 막음): 주소 꼬리 `?all=1`·`?plan`(시험 하네스 81개가 씀) · 함께하기 방 선생님 신호는 방을 만든 기기만(lobby.js · 비판 §6-1 별건).

## 2. 교사 화면(반 표)
선생님 칸 → 「📋 반 표 열기」. 한 줄 = 한 아이(번호). 칸 다섯: **번호 · 지금 장(n/m · 끝낸 장 수) · 오늘 한 일(단계·장 끝·문제 맞힘/푼 수·일·보물 지도… · 힌트 끝까지 간 단계 = 빨간 '막힘') · 남긴 결과물(가장 새 한 줄 카드·까닭·불편해질 사람 · 외 n) · 마지막 접속**. 줄을 누르면 자세히(남긴 것 셋 · 그날 끝낸 장 · 끝낸 장 목록). 아래 한 줄 = 줄 수 · 오늘 기록 수 · 오늘 막힌 번호 수 · 안 보이는 번호. 25줄이 1366×768 한 화면에 들어감(창 높이 768·680 둘 다 창 스크롤 0 · 680 = 크롬북에서 주소창을 뺀 어림 · 낮은 창이면 줄 높이를 줄임).

자료 셋(위 띠에서 고름):
1. **이 기기 판** — 이 크롬북의 같은 반 번호 판(`sm-town-game:<마을>@<반>:sNN`) + 번호 없는 칸(칸 1~3). 이 탭 판은 지금 상태 그대로.
2. **붙여 넣기** — 기기마다 학급 기록 「복사하기」로 받은 글을 여러 개 한꺼번에(패들렛 칸을 통째로 복사해도 됨 · 앞뒤 다른 글·깨진 덩어리는 건너뜀). 복사 글에 이제 `n`(출석 번호 · v4 번호 로그인일 때만)과 `sum`(표 한 줄 요약)이 들어감. 같은 번호가 여럿이면 마지막 저장이 새것 하나만.
3. **☁️ 서버** — 반 코드 + 교사 열쇠 → `/class`. 서버가 아직 배포 전이면 '서버에 아직 교사 표가 없어요(배포 전)' 한 줄만.

요약 = `v2/games/town_tsum.js`(순수 함수 · 마을과 서버가 같은 것): 지금 장 · 쉼 · 며칠 뒤 · 끝낸 장 · 마지막 기록 날 갈래별 수 · 남긴 결과물 셋 · 마지막 저장 시각. 이름·비밀번호·기기 번호 X. 한 아이 약 0.4KB.

## 3. 서버 엔드포인트 설계(server/cf-rooms · 코드와 흉내 시험까지 · 배포 X)
| 주소(POST · JSON) | 본문 | 답 |
|---|---|---|
| `/tclaim/<반코드>` | `{tkey}` | 처음 정함 `{ok, made:1}` · 같은 열쇠 `{ok, made:0}` · 다른 열쇠가 이미 있음 409 |
| `/class/<반코드>` | `{tkey}` | `{ok, at, L:[{n, at, s}]}` — s = 요약 · 열쇠 없음 404 `{nokey:1}` · 틀림 403 · 잠김 423 |
| `/treset/<반코드>` | `{admin, tkey}` | 비밀값 `ADMIN`이 맞을 때만 교사 열쇠를 바꿈 · `ADMIN`을 안 넣은 서버는 늘 403 |

- 교사 열쇠 = 띄어쓰기 없이 6~32자 · 서버엔 `SHA-256(PEPPER | 반코드 | T | 열쇠)`만 · 5번 틀리면 10분 잠금(정하기 다툼 409도 틀림으로 셈) · 이 탭 메모리에만 두고 잠그면 지움.
- 요약은 아이 저장(`/save`) 때 한 번 만들어 `s.sum` 칸에 둠 → 표를 열 때 판 25개를 다시 읽지 않음. 예전 판(요약 없음)은 표를 열 때 열 개씩 채움. 표 하나 = 요청 1건(25명 약 11KB).
- 표 칸 더하기는 `ALTER TABLE s ADD COLUMN sum`(있으면 그대로) + 교사 열쇠 표 `t` 한 줄. 아이 저장·이어 하기(`/save`·`/load`·`/drop`)는 그대로.
- Origin·반 코드 꼴·크기 검사는 저장과 같음. Firebase 규칙은 손대지 않음.
- 흉내 시험: `node --no-warnings server/cf-rooms/test_teach.mjs`(36개) · 흉내 서버 `node server/cf-rooms/mock.mjs <포트>`(마을을 `?cf=http://127.0.0.1:<포트>`로) · 마을까지 잇는 시험 `zsh tools/ops/b2.sh node tools/harness/town_teach.cjs ourtown <포트> [--pics=폴더]`(40개 · 흉내 서버를 빈 포트에 스스로 띄움 · 시험 반 zzteach는 메모리 DB라 끝나면 사라짐).

## 4. 배포하면 무엇이 되나 · 교사가 정할 것
배포 전(지금): 선생님 칸 잠금 · 이 기기 판 표 · 붙여 넣기 표는 바로 됨(마을 코드만). 서버 칸은 '배포 전' 안내.

배포 뒤(`npx wrangler deploy` 한 번): 반 코드로 이어 하는 아이들(v4 `?cls=`)의 판 요약이 저장 때마다 서버에 생기고, 선생님은 어느 기기에서든 반 코드 + 교사 열쇠로 25명 표를 한 번에 받음. 패들렛 붙이기가 필요 없어짐.

교사가 정할 것:
1. **배포할지** — `server/cf-rooms`에서 `npx wrangler deploy`(로그인은 이미 됨 · 아이 저장 코드는 바뀌지 않음).
2. **교사 열쇠를 언제 정할지** — 반 코드를 아이에게 주기 **전에** 선생님 칸 → 반 표 → ☁️ 서버에서 처음 정하기. 먼저 정한 사람이 주인이라, 아이가 먼저 정하면 3번이 필요함.
3. **관리 열쇠를 넣을지** — `openssl rand -hex 16 | npx wrangler secret put ADMIN`. 넣으면 열쇠를 잊거나 빼앗겼을 때 `/treset`으로 바꿀 수 있음(넣지 않으면 그 반 열쇠는 바꿀 길이 없음 · 새 반 코드로 옮겨야 함).
4. 선생님 비밀번호(memoPin)는 숫자 넷이고 해시가 공개 DB에 있어 마음먹으면 풀림(예전부터 · 비판 §3-5). 아이 화면 잠금은 '모르고 누르는 것'을 막는 문이고, 반 기록 서버는 그와 별개인 6자 넘는 교사 열쇠로 지킴.
