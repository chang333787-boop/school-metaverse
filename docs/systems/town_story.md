## 인물 · 감정선
- 주인공 = 나(말없는 주인공 · 고른 것이 말). 쪽지 = 행정복지센터 직원(공고) · 일꾼들 · 새 친구 — 모두 이름 없는 역할.

- 동네 표(지역 존중 — 자랑·어려움 같은 무게): 산 = 고랭지 배추·표고·꿀·전망대 / 큰비 때 고갯길 · 들 = 논·딸기·배 / 한여름 더위 · 바다 = 갯벌·염전·김·굴 / 간척 고민(정답 없음) · 강 = 호수·캠핑장·반딧불이·현수교 / 물가 안전 · 시내 = 터미널·빵집·영화관 / 바빠서 이웃을 모름·차 소음 · 읍내 = 도서관·우체국·소방서 / 길가 주차.
