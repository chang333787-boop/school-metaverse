# 🗺 보물 지도 — 설계안 한 쪽(TREASURE-1 · 10-19)

사용자 10-18: "슴슴 1·2·3·5 좋은 듯" + "ㄱ" → `town_minis.md` 상위 1위 🗺 보물 지도. 설계안은 보여 주되 기다리지 않고 짓는다.
먼저 `town_lessons.md`를 지킨다. 특히 C('볼 자료는 창 안에' · '스스로 찾기는 지도 배움 단계에서만' · 셈 X), D(손동작 겹침 · 순간이동 X), E(렉 · 상태 교차), G(슬롭 X · 4학년 난이도).

## 1. 흐름(한 판 = 지도 하나 · 하루 하나)
1. **받기** — 본부(작은 도서관) 📌 의뢰 게시판 옆 '🗺 낡은 지도 조각'에서 E. 하루에 하나만 붙는다. 큰 지도(M)가 열린 뒤부터 받는다(그 전엔 🔒 + 언제 열리는지 한 줄).
2. **읽기** — 창 안에 종이 지도 조각 한 장(그림) + 지시문 한 문장 + 낱말 상자(새 낱말 둘). 빨간 선·화살표는 없다. 기호·방위표·축척 막대만 그린다.
3. **걷기** — 왼쪽 할 일 줄 밑에 작은 쪽지 카드(조각 그림 축소판 + 지시문). 누르면 다시 크게 본다. 아이는 큰 지도(M)·나침반 띠·축척으로 직접 찾아간다.
4. **파기** — 상자 자리 30m(★★·★★★ 40m) 안에 오면 갓 판 흙더미와 작은 말뚝이 보인다. 흙더미 3m 안에서 '⛏️ 땅 파기 (E 꾹)'. E를 누르고 있으면 1.6초 동안 판다(터치는 ✋를 여러 번 톡톡). 손을 떼면 멈추고 다시 누르면 이어서 판다. 파는 동안 카메라가 어깨 너머로 비켜 서서 아이 몸이 상자를 가리지 않는다.
5. **상자** — 흙더미가 꺼지고 상자가 땅에서 올라온다(엔진 `map.prop` 상자). 2초 뒤 창에서 상자 안 물건(정해진 것)과 사실 한 줄을 보여 준다(다른 창이 떠 있으면 닫힌 뒤).

## 4. 걸어서 닿는 곳만(걸러 내기)
학교 안 X(`inSchool`) · 물 위 X(`wAt` · 물가 2m · 바다 4m) · 길·다리·건물·마당·나무 X · 굴 위 ±8m X · 몸이 서는 칸(`map.q.blocked` 가운데 + 둘레 0.7m) · 비탈 완만 · 본부에서 `SM_TOWN.routeXY`(같은 `route`)로 길이 이어짐 · 길 끝이 굴 속이면 X(굴 위 산에 상자가 있으면 길 안내가 굴 길에 붙어 '닿는다'고 속음) · 길 끝에서 상자까지 몸 규칙 걷기(`walkLen`) · 끝 120m 토막마다 마을 `legOK`(빨간 선을 그대로 걸을 수 있나 — 길·다리 위와 등산로 토막은 길이 맡음). 하나라도 걸리면 그 자리는 버린다.
- ★★★ 산 자리: 꼭대기 둘레(±156m)에서 가장 높은 곳 → 높이 차 12m 넘는 산만 · 등고선 간격 5m(높이 차 40m 넘으면 10m) · 꼭대기와 바닥 가운데 높이 줄을 받는 곳 쪽 방위부터 8방위로 찾음 · 길에서 6m 넘게 떨어진 비탈 먼저.

## 5. 보상(정해진 것 하나 · 뽑기·확률 X)
- 상자마다 옛 물건 하나(위 표 · 조각 구석에 '상자 안: 📯'으로 미리 그림) → 도감 '🗺 보물 상자' 칸(`tmap:<id>`).
- 단계를 처음 해내면 칭호: ★ 둘 = 「🗺 기호 탐정」 · ★★ 둘 = 「🧭 방위 탐험가」 · ★★★ 하나 = 「⛰ 등고선 탐험가」(도감 갈래 제목 줄 · 쪽지 카드).
- 탐험 솜씨(`skUp('explore', 3)`) · 돈 X · 물건 X.

## 6. 하루 하나 · 저장
`GAME.S.tmap = { cur: 지금 지도(자리·단계·받은 날) | null, got: { id: 찾은 날 }, n: [★, ★★, ★★★ 찾은 수], last: 마지막으로 찾은 날, title }`. 지도를 받았지만 못 찾았으면 다음 날에도 같은 지도(새로고침·쉬기·잠 뒤 그대로). 오늘 이미 찾았으면 '내일 새 조각이 붙어요'. 기록 `REC.add('tmap', { lv, id, h, t })`.

## 7. 도움(힌트 셋 · 이야기 힌트와 같은 결)
지도를 받고 1분 · 2분 · 3분이 지나면 카드에 '💡 도움'이 하나씩 열린다. ① 어떻게 읽는지 한 줄(예 '큰 지도에서 🚒 기호를 먼저 찾아요') ② 지금 자리에서 본 방위와 어림 거리('보물은 남동쪽, 200m쯤') ③ 빨간 선(`guidePath`). 쓴 도움 수를 기록에 남긴다(벌 X).

## 8. 렉·화면
그리기 +1(흙더미·말뚝 한 메시 · 30m 안에서만 보임) · 상자는 엔진 소품 풀(상자 창이 닫히면 치움) · 새 Light X · 매 프레임 일 0(0.25초 칸에서 거리·E 글·높이 읽기) · 조각 그림은 받을 때 캔버스 한 번 · 종이 결(누런 바탕 · 잉크 선 · 찢긴 가장자리 · 접힌 금) · 글로우·그라데이션 X · 이모지는 제목 앞 하나.

## 9. 짓는 차례 · 시험 `tools/harness/town_treasure.cjs`
짓는 차례 = 틀 + ★(tm1a) → ★★(tm1b) → ★★★(tm1c) · `town_treasure.js`의 `LVMAX`가 내주는 단계를 막는다. 걷기는 게임의 자동 걷기(`map.player.steer` — 걷기 봇과 같음 · 걸리면 옆으로 반 걸음)로 길 점을 따라간다(W + 시선 돌리기는 산 비탈에서 카메라 방향으로 미끄러져 못 씀). 상태 교차 `town_state.cjs`에 '보물 지도(반쯤 판 흙더미 앞)' 상태를 더했다.
지도 받기·자리 계산(걸러 내기 통과) → 걸어서 도착(W) → E 꾹으로 파기 → 상자·도감 칸·칭호 → 같은 날 두 번 X → 새로고침 뒤 지도 이어짐. 단계마다(★ → ★★ → ★★★) 같은 순서.
