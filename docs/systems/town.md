# 마을 세계 엔진 (TOWN-1 · 10-12)

> **언제 읽나**: 아이들 매트·모눈 사진으로 마을을 지을 때 · 마을 엔진(`v2/games/town.js`)을 고칠 때 · 교사가 "이 사진으로 마을 만들어 줘" · "○○ 구역에 넣어 줘" · 아이 요구("가로등이 없어요")를 전할 때.
> 늘 지킬 규칙(개인정보·홍보판·이모지·캐시·게이트)은 CLAUDE.md.

## 한 줄
**엔진이지 마을이 아니다**(교사 10-12 '메타버스가 마을을 만들어 버릴까 봐 무섭다'). 마을 내용(건물·길·구역)은 아이들이 매트에서 만든 것 — Claude는 사진을 **자료 한 장**(`v2/towns/<이름>.js`)으로 옮길 뿐이고, 엔진이 학교 정문 밖에 짓는다. 시험은 메뉴에 없는 `zz_` 자료로만(마을처럼 꾸미지 않음).

**엔진 = 능력, 내용 = 아이**(교사 10-14 '엔진만 만드는 거지? 애들 아직 완성 안 했는데 저수지·버섯 하면 안 돼'): 엔진은 **땅을 다루는 능력**(산 지형·물가·층층 땅·비탈 집터)만 미리 갖춘다. 저수지·버섯 재배사·약초밭·등대·항구·수산물 가게 같은 **내용물은 아이 판(소품·이름표·블록)이 요구할 때만** 짓고, ✨ 채우기나 구역 성격만으로 저절로 놓지 않는다(예외 = 교사가 정한 자연 틀에서 나오는 땅 모양: 바다면·모래사장·하구). 아이 판에 아직 없는 내용물은 미리 만들지 않는다 — 10-14에 시험으로 만든 산지 내용물(버섯 재배사·약초밭·저수지 둑·여수로·임도)은 가지 `park/mtn-content`에 보관(사진에 나오면 그때 꺼냄).

하나의 세계: 우리 학교 → 정문 → 우리 마을 → 자연환경. 쌓이는 세계(앞 활동 결과가 다음 무대 · 판 묶음). 배움이 먼저('우와'는 배움에서). 현실(매트·진짜 학교)과 견주는 메타버스 — 그래서 **누가 만든 것인지 기록을 섞지 않는다**.

## 여는 법
- `v2/?town=<이름>` — registry `town`(dev · 메뉴에 없음) · **홍보판(SM_PROMO)에선 열리지 않음** · `&layer=<판>` · `&look=mat`(🧱 매트 모습) · `&plan=1`(📐 읽은 도면 확인부터)
- 다른 놀이(20개)의 학교 경계·길격자·성능은 그대로 — 학교 밖은 **이 놀이가 켤 때만** 바뀐다(`map.world.outside` · 놀이가 멈추면 원래대로 · 시험 t3: 땅 높이·충돌 칸 6,981·숨긴 메시 0으로 복원 확인).

## 수업 흐름(교사 → Claude)
1. 아이들이 판에 마을(블록 = 꼭 정한 건물 · 색종이 = 구역) → 위에서 사진. **바닥판(10-13 확정 — 교실 마루 위 검은 테이프 테두리 250×150 · 25cm 칸 가로 10 × 세로 6)**: 매트는 치움 · 판 가장자리 = 검은 테이프 테두리(사진에서 네 모서리를 이 선으로 잡음) · **바둑판 = 매트 판 이음매(10-13 다시)**: 세로선 25cm마다(10칸) — 이음매 50·100·150·200 = 큰길(빨간 4.8cm) · 판 가운데 25·75·125·175·225 = 작은길(좁은 테이프) · 가로선 25·50·100·125 = 작은길 · 75 = 큰길(10-13 교사 확정 — 줄 가~바 · `ys: [25,50,75,100,125]`) · 칸 주소 왼→오 1~10 · 위→아래 가~바(한 칸 25×25cm = 실제 125×125m) · 학교 = 가5(100~125 × 0~25 — 실제 학교가 칸보다 조금 커서 둘레 길이 울타리 밖 비닐하우스·밭과 겹칠 수 있음 · 울타리 안은 길을 안 그림) · 뒷산 = 가1·가2 · 강 = 교사가 파란 색종이(아래 → 오른쪽 위 · 큰길 테이프가 덮은 곳 = 다리 · 작은길은 강가에서 끊김) · **빈 칸은 빈 땅**(색종이·블록이 있는 칸만 짓고 채움) · **사진에 없는 작은길은 '아직 안 붙임'**(칸 선은 grid로 알지만 길은 붙인 테이프만) · 시험 자료 = `v2/towns/zz_grid.js`.
   **손글씨 이름표·소품 글자**: 연필로 작게 써서 판 전체 사진으로는 못 읽음 → 교사가 이름표마다 가까이 한 장씩 · **칸 주소는 판 전체 사진에서 맞춤**(소품도 인쇄된 이름으로 읽고 자리는 전체 사진).
   **사진 읽기 요령**: ① 판 = 검은 테두리 안만(네 모서리로 원근 바로잡기) ② 큰길·작은길은 **색이 아니라 폭**으로(4.8 / 좁은 것) ③ **바탕 마루(갈색 나뭇결·판자 이음매)는 구역도 길도 아님** — 길은 테이프만 ④ 주황 색종이·주황 블록은 갈색 마루와 비슷해 묻힐 수 있음 → 종이·블록 테두리와 그림자로 읽고, 안 보이면 `ai`에 적어 읽은 도면 확인에서 아이들에게 묻기 ⑤ 바로 위 한 장 + 글씨는 가까이 한 장. ⑥ **창문 빛 반사**로 검은 테이프가 하늘색으로 보일 수 있음(10-13 사진 오른쪽 위) — 물이 아님 · 파란 색종이는 종이 테두리·그림자·칸을 따라 이어지는 모양으로 읽기.
   **실제 수업 판(10-13 오후 · 교사 확정 · 아직 짓지 않음 — 완성 사진이 오면)**: ① **칸 맞추기** — 테이프가 두꺼워 선이 25cm에서 조금씩 어긋남 → 실제 위치를 재지 말고 **칸 주소(1~10 × 가~바)로 25cm 격자에 붙여 읽기**(칸 안의 종이·블록 = 그 칸 것) ② **길 폭** — 검은 테이프는 모두 같은 굵기(1:500이면 20m 넘음)지만 **테이프 폭을 쓰지 않음**: 큰길 = 판 이음매 세로 50·100·150·200 + 가로 75(넓게 `w: 4.8` · 인도 · `trees: true` 가로수) · 작은길 = 나머지 칸 선(`w: 2.4` 좁은 동네 길) · **이 구분은 길마다 `ai`로 적어 ✨ 어림 목록에 '큰길 n줄 / 작은길 n줄'로 묶여 보임**(아이들이 "큰길은 여기"로 바꿀 수 있게 — 바꾸면 그 길의 `w`·`trees`만 고침) ③ 학교 가5 = 실제 크기 · 둘레 길은 담 바깥으로 ④ **노란 색종이 = 논밭**(`type: 'fields'`) · 노란 블록 = 일하는 곳(가게·회사) · **검은 네모 종이 = 학교** · 파란 색종이 강 = 칸 차례(`cells`) ⑤ 진행 중 사진에 아이 얼굴이 나온 것(IMG_3642)은 쓰지 않음 — 완성 사진은 아이들이 안 나오게(교사께 전함).
2. "이 사진으로 마을 만들어 줘" → Claude가 사진을 자료로 옮김(아래 형식 · 안 보이는 것은 `ai: '이유'`) → push → `?town=<이름>&plan=1`.
3. **📐 읽은 도면 확인**(탑뷰 지도 · 격자 주소 A1~Y14) — 매트와 다른 곳을 아이들이 찾음 → 고쳐서 다시.
4. ▶ 걸어 보기 — 정문으로 나가 마을 · 🔎 장소(F) · 🗺 지도(M) · 🧱/🏘 두 겹(Y) · 🚲 자전거(B) · ☰ 메뉴(판·숫자·기록·하늘·영어).
5. 아이 요구("가로등이 없어서 무서워요") → 교사가 전함 → 그 판의 `fac`에 한 줄(`by`·`why` 적기) — **저절로 채우지 않는다**.
6. 새 도안(다시 배치) = **새 판**으로(예전 판은 남김 — 판 바꾸기·📊 숫자 비교·나중에 타임랩스).

## 자료 형식(정본 = `v2/towns/zz_test.js`)
좌표 = **판 cm**(왼쪽 위 0,0 · 오른쪽 x+ · 아래 y+ · 위 = 북) · 축척 `scale: 500`(1cm = 5m) · `mat: { w, h }` = 판 크기 cm · `school: [x0,y0,x1,y1]` = 판 위 학교 칸 — **칸 네 변을 실제 학교 담 상자(146×155m)에 맞추고 칸 밖은 그 가장자리부터 정확히 1:500**(교사 10-13 '학교 모델은 줄이지 말고 · 마을 쪽 1:500 그대로' — 학교 칸만 실제 크기 · 이웃 칸 크기 그대로) · **학교 칸 변 위의 길은 길 폭 절반 + 1m만큼 담 바깥으로** 밀어 학교를 파고들지 않음 · 학교 칸 안 블록(이름표·남색 판)은 짓지 않고 실제 학교 모델(✨ 어림에 적음) · `grid: { xs: [선 cm…], ys: [선 cm…] | cell: cm, cols: 'num', rows: 'hangul', order: 'rowcol' }` = 판 가장자리 칸 주소('다3' — 없으면 10cm A1~) · 정본 = `v2/towns/zz_test.js`(엔진 기능 전부) · `zz_grid.js`(매트 바둑판 · 칸 선 자리 `grid.xs`·`ys` — 첫·끝 칸이 다를 때).
```js
export const TOWN = { id, title, en, scale: 500, mat: { w: 250, h: 140 }, school: [110.5, 1, 139.5, 31], base: 'now', ai: [{ t, at? }], pop?: { house: 4, apt: 10 },
  layers: { now: { name: '오늘', en, nature: [], roads: [], blocks: [], zones: [], fac: [], labels: [] },
            before: { name: '개발 전', from: 'now', drop: ['b4', …], nature: [ …덧붙임·같은 id면 바꿈 ] } } };
```
- **nature** `{ id, k, rect | poly | line, name?, en?, ai? }`
  - `hill` 산·언덕: `h` = 쌓은 높이 cm(→ m = h×5) · `peak: [x,y]` 꼭대기 자리(없으면 가운데) — 가장자리에서 둥글게 솟는 봉우리 + 능선 잡음 + 산자락 흐림 · 나무가 덮음
  - `water` 물: `line: { pts: [[x,y]…], w: cm }` = 강(점 순서 = 흐름 방향 · 물결이 흐름) · `cells: ['마6','라7',…]` = 파란 색종이가 놓인 칸 차례(칸 가운데를 잇고 양 끝은 14cm 더 · `w` 없으면 6cm = 30m · **대각선 칸은 옆 칸 가운데를 거치는 ㄱ자(번갈아 → 물굽이) + 모서리 깎기** — 강이 칸 변 한가운데에서 길을 직각으로 건너 다리가 짧고 교차로와 반 칸 떨어짐 · ✨ 어림에 적힘) · `rect`/`poly` = 연못 · 물 안은 못 들어감(울타리 충돌) · 길이 지나면 **다리**(판 + 난간)
  - `forest` 숲: `sub: 'mixed'|'pine'|'broad'` · `field` 들: `sub: 'rice'|'farm'|'orchard'|'park'|'grass'` · `sand`
- **roads** `{ id, pts: [[x,y]…], w: cm | wm: m, big? }` — 테이프 = `w` cm(4.8 = 큰길 24m) · 매직 선 = `wm`(실제 폭 m — 선 굵기와 다름 · 9~12) · 폭 18m 이상 = 큰길(노란 두 줄 · 4차로). `trees: true` = 그 길의 기본 가로수(아이가 요구한 시설 `fac` 가로수와 따로 · 겹쳐 심지 않음) · `ai: '…'` = 큰길·작은길처럼 Claude가 어림한 것(✨ 목록에 같은 말끼리 '큰길 n줄'로 묶임). 모든 길을 한 폭으로 하고 싶을 때만 자료 맨 위 `roadW: cm`/`roadWm: m`(10-13 실제 판에서는 쓰지 않음 — 교사 '처음 계획대로'). 다리 = 길 폭 전체(가운데·양 가장자리)로 물을 보고, 판 길이 = 물 깊이가 닿는 곳 + 1.5m(길 띠는 다리 판 구간만큼 정확히 잘라 냄 · 길 아래 둑은 평평). 차도·인도·연석·가운데 선·교차로 모퉁이까지 = 길의 기본 구성(건널목은 시설).
- **blocks** = 아이가 꼭 정한 건물 `{ id, x, y, w, d, h, z?, c, rot?, kind?, name?, en?, home?, ai? }` — x·y = 가운데 · w·d·h = cm(판 6×3×1 · 정육면체 2·3·4) · `z` = 아래에 쌓인 높이 cm · `c` = 색(red·orange·yellow·green·navy·blue·white·…) · `name`이면 도감 종류(소방·경찰·병원·학교·도서관·우체국·공장·마트…) · `home: '이름'` = 그 아이 집(v2에서만 보임).
- **zones** = 색종이 구역 `{ id, k: 'live'|'work'|'green', rect|poly, dens: 'dense'|'normal'|'sparse', type?: 'house'|'apt'|'mix'|'shop'|'office'|'factory'|'park'|'field'|'rice'|'fields'(논밭 — 구역마다 논 또는 밭)|'forest'(숲), note: 아이가 종이에 적은 말 그대로, c? }` — 엔진이 길을 따라 필지를 나눠 채움(아이 블록·길·물·산은 비켜 감 · 씨앗 = 구역 id라 다시 지어도 같은 자리).
- **fac** = 아이가 요구한 생활 시설 `{ k, rule? | at?: [x,y], by: 요구한 아이(모둠), why: 아이가 한 말 }`
  - k: `streetlight` 가로등 · `crosswalk` 횡단보도 · `signal` 신호등 · `streettree` 가로수 · `bench` 벤치 · `busstop` 버스 정류장 · `fence` 울타리 · `flowerbed` 화단 · `parkedcar` 주차된 차 · `schoolzone` 어린이 보호구역
  - rule: `bigroads` 모든 큰길 · `allroads` 모든 길 · `crossings` 모든 교차로 · `bigcross` 큰길 교차로 · `houses` 모든 집 · `parks` 모든 공원 · `shops` 모든 가게 앞 · `school` 학교 둘레
- **labels** `{ x, y, t, en }` — 지도 글자.
- **props** = 아이가 판에 놓은 **종이 소품**(교사 10-13 인쇄지 — 소품마다 이름이 인쇄됨 · PROPS-1) `{ id, k, x, y | cell, face?: 'n'|'s'|'e'|'w', along?: 'ns'|'ew', name?, to?, pts?, w?, d?, road? }` — **블록과 같은 규칙: 놓은 자리·개수 그대로(엔진이 더 넣지 않음) · 기록 = 🧱 아이 것** · 실제 크기로 섬(가로등 6m · 정자 5m · 비닐하우스 22m)
  - 세우는 카드 k: `streetlight` 가로등 · `signal` 신호등 · `busstop` 버스 정류장 · `schoolzone` 어린이 보호구역 표지(이 넷은 가까운 길가로 붙고 길을 봄) · `pavilion` 정자 · `scarecrow` 허수아비 · `greenhouse` 비닐하우스(`along` 긴 쪽 · 없으면 길과 나란히) · `tiller` 경운기 · `bench` 벤치 · `trailhead` 등산로 입구 · `spring` 약수터 · `firesign` 산불 조심 팻말 · `fishing` 낚시터(40m 안 물가를 찾아 팻말 + 나무 데크) · `signpost` 이정표(`to: ['장소','장소']` = 아이가 쓴 이름 → 그 장소 쪽 화살표 + 거리 m · 마을에 없는 이름이면 ✨) · `card` 빈 카드(`name` = 아이가 쓴 이름)
  - 빈 카드 이름 풀이: 소품 이름(가로등·분수·동상·화장실·우체통·쓰레기통·꽃밭·나무·원두막…)이면 그 소품 · 건물 이름(소방서·카페·병원…)이면 2cm 블록처럼 그 건물 · **모르는 말이면 이름 팻말로 세우고 ✨**
  - 납작한 것 k: `crosswalk` 횡단보도(가까운 길에 가로질러) · `bridge` 다리(아래 '다리 원칙') · `trail` 산책로 띠(`pts` 판 cm) · `parking` 주차장 P(`w`·`d` cm · 칸 선·차·P 팻말)
