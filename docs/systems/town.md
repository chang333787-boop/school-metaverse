# 마을 세계 엔진 (TOWN-1 · 10-12)

> **언제 읽나**: 아이들 매트·모눈 사진으로 마을을 지을 때 · 마을 엔진(`v2/games/town.js`)을 고칠 때 · 교사가 "이 사진으로 마을 만들어 줘" · "○○ 구역에 넣어 줘" · 아이 요구("가로등이 없어요")를 전할 때.
> 늘 지킬 규칙(개인정보·홍보판·이모지·캐시·게이트)은 CLAUDE.md.

## 한 줄
**엔진이지 마을이 아니다**(교사 10-12 '메타버스가 마을을 만들어 버릴까 봐 무섭다'). 마을 내용(건물·길·구역)은 아이들이 매트에서 만든 것 — Claude는 사진을 **자료 한 장**(`v2/towns/<이름>.js`)으로 옮길 뿐이고, 엔진이 학교 정문 밖에 짓는다. 시험은 메뉴에 없는 `zz_` 자료로만(마을처럼 꾸미지 않음).

하나의 세계: 우리 학교 → 정문 → 우리 마을 → 자연환경. 쌓이는 세계(앞 활동 결과가 다음 무대 · 판 묶음). 배움이 먼저('우와'는 배움에서). 현실(매트·진짜 학교)과 견주는 메타버스 — 그래서 **누가 만든 것인지 기록을 섞지 않는다**.

## 여는 법
- `v2/?town=<이름>` — registry `town`(dev · 메뉴에 없음) · **홍보판(SM_PROMO)에선 열리지 않음** · `&layer=<판>` · `&look=mat`(🧱 매트 모습) · `&plan=1`(📐 읽은 도면 확인부터)
- 다른 놀이(20개)의 학교 경계·길격자·성능은 그대로 — 학교 밖은 **이 놀이가 켤 때만** 바뀐다(`map.world.outside` · 놀이가 멈추면 원래대로 · 시험 t3: 땅 높이·충돌 칸 6,981·숨긴 메시 0으로 복원 확인).

## 수업 흐름(교사 → Claude)
1. 아이들이 판에 마을(블록 = 꼭 정한 건물 · 색종이 = 구역) → 위에서 사진. **바닥판(10-13 확정 — 다시 매트 250×140)**: 바둑판 28cm 간격 가로 9칸 × 세로 5칸(첫·끝 칸 27cm · 한 칸 ≈ 140m) · 세로선 27·55·83·111·139·167·195·223 · 가로선 28·56·84·112 · 큰길 = 빨간 4.8cm 테이프(세로 83·167 · 가로 84) · 작은길 = 나머지 선(좁은 테이프 · 아무 색 · 또는 빨간 테이프 반 2.4cm) · 칸 주소 왼→오 1~9 · 위→아래 가~마(학교 = 가5 · 뒷산 = 가1·가2) · 강 = 교사가 파란 색종이(아래 → 오른쪽 위 · 큰길 테이프가 덮은 곳 = 다리 · 작은길은 강가에서 끊김) · 시험 자료 = `v2/towns/zz_grid.js`.
   **사진 읽기 요령**: ① 큰길·작은길은 **색이 아니라 폭**으로(4.8 / 2.4 이하) ② 가로 테이프가 매트 접는 자리(50·100·150·200cm)에서 1cm쯤 끊겨도 **한 길로 이어** 적기 ③ 매트 바탕 칸(50cm마다 하늘·연두·노랑·분홍)은 **구역이 아님** — 색종이는 바탕 대비 **종이 테두리**로 읽기(분홍 위 빨강·주황, 노랑 위 노랑, 연두 위 초록이 묻힘 — 안 보이면 `ai`에 적고 읽은 도면 확인에서 아이들에게 묻기) ④ 바로 위 한 장 + 글씨는 가까이 한 장.
2. "이 사진으로 마을 만들어 줘" → Claude가 사진을 자료로 옮김(아래 형식 · 안 보이는 것은 `ai: '이유'`) → push → `?town=<이름>&plan=1`.
3. **📐 읽은 도면 확인**(탑뷰 지도 · 격자 주소 A1~Y14) — 매트와 다른 곳을 아이들이 찾음 → 고쳐서 다시.
4. ▶ 걸어 보기 — 정문으로 나가 마을 · 🔎 장소(F) · 🗺 지도(M) · 🧱/🏘 두 겹(Y) · 🚲 자전거(B) · ☰ 메뉴(판·숫자·기록·하늘·영어).
5. 아이 요구("가로등이 없어서 무서워요") → 교사가 전함 → 그 판의 `fac`에 한 줄(`by`·`why` 적기) — **저절로 채우지 않는다**.
6. 새 도안(다시 배치) = **새 판**으로(예전 판은 남김 — 판 바꾸기·📊 숫자 비교·나중에 타임랩스).

## 자료 형식(정본 = `v2/towns/zz_test.js`)
좌표 = **판 cm**(왼쪽 위 0,0 · 오른쪽 x+ · 아래 y+ · 위 = 북) · 축척 `scale: 500`(1cm = 5m) · `mat: { w, h }` = 판 크기 cm · `school: [x0,y0,x1,y1]` = 판 위 학교 자리(실제 학교에 가운데 맞춤) · `grid: { xs: [선 cm…], ys: [선 cm…] | cell: cm, cols: 'num', rows: 'hangul', order: 'rowcol' }` = 판 가장자리 칸 주소('다3' — 없으면 10cm A1~) · 정본 = `v2/towns/zz_test.js`(엔진 기능 전부) · `zz_grid.js`(매트 바둑판 · 칸 선 자리 `grid.xs`·`ys` — 첫·끝 칸이 다를 때).
```js
export const TOWN = { id, title, en, scale: 500, mat: { w: 250, h: 140 }, school: [110.5, 1, 139.5, 31], base: 'now', ai: [{ t, at? }], pop?: { house: 4, apt: 10 },
  layers: { now: { name: '오늘', en, nature: [], roads: [], blocks: [], zones: [], fac: [], labels: [] },
            before: { name: '개발 전', from: 'now', drop: ['b4', …], nature: [ …덧붙임·같은 id면 바꿈 ] } } };
```
- **nature** `{ id, k, rect | poly | line, name?, en?, ai? }`
  - `hill` 산·언덕: `h` = 쌓은 높이 cm(→ m = h×5) · `peak: [x,y]` 꼭대기 자리(없으면 가운데) — 가장자리에서 둥글게 솟는 봉우리 + 능선 잡음 + 산자락 흐림 · 나무가 덮음
  - `water` 물: `line: { pts: [[x,y]…], w: cm }` = 강(점 순서 = 흐름 방향 · 물결이 흐름) · `rect`/`poly` = 연못 · 물 안은 못 들어감(울타리 충돌) · 길이 지나면 **다리**(판 + 난간)
  - `forest` 숲: `sub: 'mixed'|'pine'|'broad'` · `field` 들: `sub: 'rice'|'farm'|'orchard'|'park'|'grass'` · `sand`
- **roads** `{ id, pts: [[x,y]…], w: cm | wm: m, big? }` — 테이프 = `w` cm(4.8 = 큰길 24m) · 매직 선 = `wm`(실제 폭 m — 선 굵기와 다름 · 9~12) · 폭 18m 이상 = 큰길(노란 두 줄 · 4차로). 차도·인도·연석·가운데 선·교차로 모퉁이까지 = 길의 기본 구성(건널목은 시설).
- **blocks** = 아이가 꼭 정한 건물 `{ id, x, y, w, d, h, z?, c, rot?, kind?, name?, en?, home?, ai? }` — x·y = 가운데 · w·d·h = cm(판 6×3×1 · 정육면체 2·3·4) · `z` = 아래에 쌓인 높이 cm · `c` = 색(red·orange·yellow·green·navy·blue·white·…) · `name`이면 도감 종류(소방·경찰·병원·학교·도서관·우체국·공장·마트…) · `home: '이름'` = 그 아이 집(v2에서만 보임).
- **zones** = 색종이 구역 `{ id, k: 'live'|'work'|'green', rect|poly, dens: 'dense'|'normal'|'sparse', type?: 'house'|'apt'|'mix'|'shop'|'office'|'factory'|'park'|'field', note: 아이가 종이에 적은 말 그대로, c? }` — 엔진이 길을 따라 필지를 나눠 채움(아이 블록·길·물·산은 비켜 감 · 씨앗 = 구역 id라 다시 지어도 같은 자리).
- **fac** = 아이가 요구한 생활 시설 `{ k, rule? | at?: [x,y], by: 요구한 아이(모둠), why: 아이가 한 말 }`
  - k: `streetlight` 가로등 · `crosswalk` 횡단보도 · `signal` 신호등 · `streettree` 가로수 · `bench` 벤치 · `busstop` 버스 정류장 · `fence` 울타리 · `flowerbed` 화단 · `parkedcar` 주차된 차 · `schoolzone` 어린이 보호구역
  - rule: `bigroads` 모든 큰길 · `allroads` 모든 길 · `crossings` 모든 교차로 · `bigcross` 큰길 교차로 · `houses` 모든 집 · `parks` 모든 공원 · `shops` 모든 가게 앞 · `school` 학교 둘레
- **labels** `{ x, y, t, en }` — 지도 글자.

## 색 규칙 · 모양
- 빨강·주황 = 사는 곳 · 노랑 = 일하는 곳 · 파랑(남색) = 모두가 쓰는 곳 · 흰색 = 병원 · 초록 = 자연(정육면체 = 나무 · 판 = 풀밭) · 물 = 청록(남색 건물과 헷갈리지 않게).
- **두 겹**: 🧱 판 모습 = 블록·색종이·빨간 테이프 그대로(시설 없음) ↔ 🏘 마을 모습 = 도감 건물 + 구역 채움 + 시설. 같은 자리·같은 크기.
- **정성 단계**(교사 10-12): ① 매트 블록 → ② 도감 기본(지금 기본값) → ③ 아이 건물 카드 → ④ 학교 수준. 건물은 '자리·이름'과 '모양'을 따로 — 모양만 갈아 끼워 퀘스트·놀이가 그대로 돌게(③④는 다음 단계 · 실내는 필요한 건물만, 들어갈 때만 불러옴).
- 도감: 집 3갈래(박공·모임·평지붕 다가구) · 아파트(발코니·층 띠) · 가게(진열창·줄무늬 차양·간판) · 회사 · 공장(톱니 지붕·굴뚝·탱크) · 소방서(차고 문·망루·소방차) · 경찰서(띠·경광등·순찰차) · 병원(빨간 십자·구급차) · 도서관(큰 유리) · 우체국(빨간 우체통) · 학교(시계) · 공공(깃대·계단). 같은 종류도 씨앗으로 벽색·지붕·창 배치가 조금씩 다름. 건물 둘레 땅(마당·디딤돌 길·앞마당·주차장 칸) = AI가 채운 것.

## 기능
- 🔎 장소 찾기(이름 → 문 앞 · 길 그래프 최단 · 빨간 선 · 몇 m · 🚶 1.2m/s · 🚲 4.5m/s 실제 빠르기 — 어림 활동) · 🚌 가기 · 끊긴 길이면 '길이 이어져 있지 않아요'(소방차 출동 활동의 바탕).
- 🗺 지도: 높낮이 색 · 물 · 들·숲 기호 · 구역(용도 지역처럼) · 길 · 학교 지도 제자리 · 건물(아이 블록 진하게 · 채운 건물 연하게) · 장소 기호 · 범례 · 방위표 · 축척 막대 · ▦ 칸 주소(판 가장자리와 같게 · 장소 찾기 목록·지금 할 일 줄에도).
- 📊 마을 숫자(판 비교): 사는 사람(어림 · `pop`) · 나무 · 논·밭·과수원·숲·공원 넓이 · 물·산 · 건물 묶음 · 길 길이.
- 🌐 한국어 ↔ English(이름표·지도) · 하늘에서 보기 · 낮/노을/밤(밤 = 창 불빛·가로등).
- `window.SM_TOWN`(시험·시뮬 시나리오용): `find(이름)` · `route(이름, [x,z])` · `places()` · `stats()` · `setLayer` · `setLook` · `setLang` · `bus(이름)` · `cell(x,z)` · `toWorld(mx,my)` · `toMat(x,z)` · `ground(x,z)` · `counts`.

## 엔진 고리(다른 곳에 붙인 것)
- `world.js` `setTerrainOver(f)` — 학교 상자 밖 땅 높이 덮어쓰기(null = 원래) · `terrainAt`이 먼저 봄.
- `worldfx.js` `map.world.outside({ terrain })` — 학교 상자 밖 청크 메시 숨김(`userData.out`·`d.out` — main.js가 다시 켜지 않음) · 그 칸 충돌 비움 · 땅 높이 · `reset()`이 원래대로.
- `main.js` — `?town=` → 놀이 `town` · 오프닝 없음 · 홍보판 제외.
