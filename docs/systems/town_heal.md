# 🌙 힐링 묶음(HEAL-1 · 최종 차례 7번 줄) — 합친 최종 설계

사용자 10-24: "나머지 힐링은 가치 있음 · 재미·힐링·교육을 다 담는 것". 차례 7번 = ① 할 일을 선택으로(0/3 X) ② 해 질 녘·밤 따뜻한 불빛 ③ 잔잔한 소리 풍경 ④ 사진 모드·엽서. 우리 집 꾸미기는 나중이에요.
이 문서는 안 A(몸·장면)·안 B(엔진·세상 반응)와 다섯 역할 반박을 심판해 하나로 합친 것이에요. 설계할 때 코드는 읽기만 했어요.

**지키는 선**: 판타지 X · 아이 그림 X · 개인 순위·뽑기 X · 아이콘·%·숫자 막대·타이밍 막대 X · 엔진 > 클릭 퀘스트 · 보상은 rwCheck 하루 한도 · 하루 기력 X · 새 Light X · 크롬북 렉 X · 한국어로만 · 홍보판(루트 index.html·SM_PROMO)은 그대로.

## 2. 최종 설계

### ① 오늘 해 볼 만한 것(할 일 선택화)

**화면 흐름**: 칩(4209줄)은 지금처럼 '지금 할 일' 한 줄 → 누르면 `openTasks()` 창 → 줄을 골라 🧭 길 안내(지금 그대로).

**바꾸는 것**(`town.js` `openTasks()` 4292줄 · `town_game.js` `taskEv()`):
1. 제목 `📋 오늘의 할 일` → `🌤 오늘 해 볼 만한 것`(영어 `Things to try today`).
2. 설명 줄 → `이웃이 부탁한 일이에요. 하고 싶은 것만 골라요.` (한 문장 · '셋 다 +500'·'아침마다 새로 셋' 글 없음).
3. 줄 앞 `⬜`/`✅` 칸 → 지워요. 한 일은 그 줄 글을 지난 말로 바꾸고 흐리게(`opacity .6`) 둬요. 예: `배추 거두기` → `배추를 거뒀어요`. 지난 말은 `tasks()`가 줄을 만들 때 `tp`(과거형) 칸을 같이 넣어요. 없으면 `'… 했어요'`로.
4. `(n/need)` → 지워요. need > 1인 일은 글로만: 처음 = 줄 그대로, 하는 중(0 < n < need) = 줄 끝에 `— 하는 중`(숫자 X).
5. 보상 줄 `💰 ○원 받는 일`은 남겨요(보상을 아는 것은 고르는 근거라서). `why` 줄도 그대로예요(배울 거리 · 사실과 까닭).
6. `taskEv` 155줄 `task:all` +500 → 지워요. 셋 다 하면 돈 대신 **그날 마지막 일을 맡긴 이웃이 한 줄** 말해요(말하는 이는 몸 위 말풍선 · `bubbleAt`): `오늘 마을 일을 많이 도와줬구나.` 하루 한 번, 돈·하트 0.
7. 칩 글에 `1/3` 같은 숫자가 있으면 걷어요(짓는 사람이 4209줄 근처를 grep `/3`·`tasksDone`으로 확인).

**경제**: `node tools/harness/town_econ.cjs`로 전후 7일 하루 벌이를 견줘요. 줄어든 몫이 15%를 넘으면 `tasks()`의 줄마다 `rew`에 `+170`을 더해요(셋 × 170 ≈ 500 · 셋 다 했는지와 상관없이 · 보상 출처 `task:<id>` 그대로 rwCheck를 지나요).

### ② 해 질 녘·밤 따뜻한 불빛(새 Light 0 · 그리기 +0)

**2-1 창이 하나씩 켜짐**(`town.js` 3580~3582줄 셰이더 · `FACU`)
- `FACU`에 `uLate9: { value: 0 }`을 더해요.
- 셰이더: 창마다 둘째 해시 `float tt9 = fract(hh9 * 3.17);` · 켜짐 = `on9 * step(tt9, uLate9)`(지금 `on9` 자리를 이것으로). `uLate9`가 0 → 1로 오르면 켤 창(약 58%)이 하나씩 켜지고, 1 → 낮아지면 하나씩 꺼져요.
- `uLate9` 값(게임 시각 `GAME.S.min`으로 · 게임 1분 = 0.7초):

  | 게임 시각 | uLate9 | 실제 시간 |
  |---|---|---|
  | 06:00~17:20 | 0 | |
  | 17:20 → 19:10 | 0 → 1(부드럽게 · smoothstep) | 약 77초 동안 하나씩 |
  | 19:10~22:30 | 1 | |
  | 22:30 → 24:00 | 1 → 0.45 | 약 63초 동안 몇 개씩 꺼짐 |
  | 실내·잠 | 바꾸지 않음 | |

- `uNight9`(창 바탕 어둡기·창 빛 세기)도 같은 1초 tick에서 이어지게: 17:00 → 19:00 동안 0 → 1, 05:30 → 06:30 동안 1 → 0. `applyTime()`의 세 계단(4864줄 `FACU.uNight9.value = …`)은 **이 줄만** 지우고 나머지(물빛·유리·가로등 머리 색·`NIGHT9`·`homeLight`)는 그대로 둬요.
- 갱신: 이미 1초마다 도는 자리(시계 tick)에서 한 번. 값이 0.005보다 덜 바뀌면 쓰지 않아요. 매 프레임 일 0.
- 시계가 꺼진 마을(학교 시간 단추로만 바꾸는 판 · `S.clock === false`)은 지금처럼 세 계단이에요(`applyTime`이 정한 값으로 `uLate9 = night ? 1 : dusk ? 0.5 : 0`).

**2-2 가로등 빛 웅덩이가 구역마다 차례로**(`GLOW` 1792~1798줄)
- 웅덩이를 구역 칸(REG)마다 합칠 때 꼭짓점 색에 이미 세기가 들어가요. 여기에 꼭짓점 칸 `aOn`(float) 하나를 더해요: 그 구역 열쇠의 해시로 0.05~0.95.
- `GMAT`을 `onBeforeCompile`로 고쳐 `color *= smoothstep(aOn, aOn + 0.04, uLamp9)`. `uLamp9`는 17:40 → 18:40(약 42초) 동안 0 → 1, 06:00 → 06:20 동안 1 → 0.
- 가로등 머리(`lbucket` 메시)도 같은 `aOn`을 구역 해시로 넣어 웅덩이와 같은 때 켜져요(재질 하나 · uniform 공유).
- 사실 근거: 가로등은 해 질 녘 밝기·시각에 맞춰 저절로 켜지고, 같은 선에 묶인 등은 함께 켜져요. 그래서 '구역마다 한꺼번에, 구역끼리는 조금씩 다르게'로 해요(한 등씩 따로 켜는 연출 X).
- 하지 않음: 아는 이웃의 집 창(§1 B-4 · 차례 12번으로) · 새 Light · 새 메시.

### ③ 잔잔한 소리 풍경(`AMB`를 넓힘 · AudioContext 늘리지 않음)

**3-1 층 규칙 표**(`town.js` `ambTick` 5894~5897줄 · 0.25초마다 판정 · 소리 꼴은 아래)

| 층 | 언제(철 · 게임 시각) | 어디(조건) | 소리 꼴(새 버퍼 X) | 크기(gain 최대) | 사실 근거 |
|---|---|---|---|---|---|

**3-3 섞기**

- **음악 duck에 같이**: `town.js`에서 `MUS.duck(sec)`를 부르는 곳(지금 1곳)을 `duckAll(sec)`로 바꿔요. `duckAll` = `MUS.duck(sec)` + `AMB.master` gain을 0.5배로 `sec`초 뒤 되돌림. 새 duck 자리도 이 함수로만.

- **목소리 상한**: 동시에 울리는 짧은 소리(오실레이터) 6개까지. `AMB.v` 수를 `onended`로 줄이고, 6이면 그 소리는 건너뛰어요.
- 켜고 끄기: 지금 `twn-amb`(자연 소리)·`SET.mute`(모든 소리) 그대로. 새 설정 단추 X · 설명 창 X.
- 크기 기준(lessons E '소리는 배경'): 새 층 최대값은 모두 발소리 0.17보다 한참 작은 0.035 이하예요.

### ④ 사진 모드 · 엽서

**4-1 사진 모드(구도 잡기)**(`town.js` `shootTown` 둘레 · `photo.js`는 옵션만 더함)
- 들어가기: 메뉴의 📷 단추(지금 `shootTown(false)` 자리) · 키 하나(짓는 사람이 빈 키를 grep으로 고름 · `KeyP`는 main.js 마우스 보이기라 안 됨 · 후보 `KeyV`). 창·놀이·잠·하늘 보기·대화 중이면 안 들어가요(`shootTown(quick)`의 막는 조건과 같게).
- 들어가면: `body.ph-on`(화면 표시 숨김) · 몸 멈춤(`map.player.freeze(true)`) · 3인칭 카메라는 지금처럼 마우스 끌기·터치 끌기로 돌고, 휠·두 손가락으로 당기기(지금 카메라 거리 한도 안).
- 화면 아래 한 줄만(`#phHint` · `ph-on` 숨김에서 빼는 요소): 키보드 `끌어서 돌려요 · 스페이스 = 찰칵 · Esc = 나가기` / 터치는 키 글자 없이 단추 둘 `📷 찰칵` `나가기`(TOUCH-2 keytext 규칙).
- 찰칵: `takePhoto({ cd: [] , onFrame: () => PRESS.scan(), … })` — 3·2·1 없이 그 프레임. 찍은 뒤에도 사진 모드에 남아 더 찍을 수 있어요.
- 나가기: Esc · 나가기 단추 · **60초 동안 손을 안 대면 저절로**. 나갈 때 `freeze(false)`·`ph-on` 끄기를 `finally`에서 꼭.
- 이야기가 진행 중이어도 들어갈 수 있고, 나오면 이야기 창 되살리기 규칙(lessons C '창이 없으면 3초 뒤 다시')이 그대로 돌아요.
- 지금 있는 `K`(quick 기사 사진)는 그대로 둬요.

**4-2 엽서 = 사진 속 이웃에게 · 우체통에 넣기**
- `PRESS.scan`(town_photo.js 73줄)이 지금 읽는 동물에 더해, 화면 안 **일꾼(WKP)** 가운데 화면 키 4% 넘게 보이는 가장 큰 하나와 그 순간 **때(phase)·날씨(WX9)·칸(cellOf)**을 같이 남겨요(같은 프레임 · 화면 안 판정은 동물과 같은 투영 · 일꾼은 칸 3×3 안만).
- **받는 이 정하기**(창 X · 저절로):
  1. 사진에 일꾼이 담겼으면 그 일꾼(대표 몸 `repOf`).
  2. 아니고 동물이 담겼으면 그 동물과 이어진 일 이웃 — 작은 표 하나: 왜가리·백로·참개구리 → 논 일꾼 · 청둥오리·흰뺨검둥오리·수달 → 낚시터 일꾼 · 다람쥐·솔부엉이·고라니 → 숲(산림) 일꾼 · 나머지 → 그 칸에서 가장 가까운 일터 일꾼. 일꾼이 없는 마을이면 엽서를 만들지 않아요.
  3. 둘 다 아니면(풍경만) 그 칸에서 가장 가까운 일터 일꾼.
- 찍은 뒤 한 줄(`say`): `📮 낚시터 일꾼께 보낼 엽서가 생겼어요. 빨간 우체통에 넣어요.` — 받는 이 이름은 **하는 일로만**(실명 X · 아이 집 X).
- 엽서는 가방에 `엽서` 한 장(물건 · 팔 수 없음 · 하루 최대 3장 · 넘으면 `오늘 엽서는 다 썼어요.`).
- **넣기**: 빨간 우체통(`PROPS` `mailbox` · 앞마당 빨간 통 · 우체국 안 우체통) E `📮 엽서 넣기` → 엽서에 받는 곳이 **칸 주소**로 찍혀 보이는 작은 창 하나(사진 썸네일 + `받는 곳: 다3 칸 낚시터` + `넣기` 단추) → 넣기 = 우표 값 200원(게임 돈 · 돈 쓸 곳). 돈이 없으면 `우표 값이 모자라요.`
- **답장(다음 날 아침)**:
  - `town_news.js` `newsMake(c)`가 어제 넣은 엽서 하나를 골라 길 위 소문 한 줄을 만들어요. 글은 scan이 실제로 읽은 것으로만: `어제 노을 때 강가 왜가리 엽서 고마워요. 일터에 붙여 뒀어요.` (때·날씨·동물·칸 조각을 이어 붙임 · 없는 것은 말하지 않음).
  - 그 일꾼 일터 둘레에 **엽서 게시판**: 작은 판(0.5 × 0.35m) 하나가 일터 벽 앞면에 붙어요(lessons E '벽 앞면을 찾아서'). 색은 사진의 때·날씨로(노을 = 주황 · 밤 = 남색 · 비 = 회청 · 낮 = 하늘). E `엽서 보기` → 이 기기에 그 사진이 남아 있으면 사진, 없으면 `이 기기에서 찍은 엽서가 아니에요.` 한 줄.
  - 그리기: 엽서 판 전부 = InstancedMesh 하나(최대 12장 · 오래된 것부터 빠짐 · `matrixAutoUpdate = false`) → 그리기 +1.
  - 하트: `GAME.heart(k, 1, 'card')` — 꼬리 없는 출처 하나 · `RW_GEN.card = 2`(town_game.js 66줄 표에 한 칸). 하루 넷째 엽서부터는 소문·게시판만 생기고 하트는 없어요.
- **배울 거리**: 엽서에는 받는 곳 주소가 있어야 하고, 우체통에 넣으면 우체국이 모아 날라 줘요(사회 '고장의 공공 기관이 하는 일' · 칸 주소 읽기 = 지도 배움). 첫 엽서 때 한 번만 우체통 E 창에 `우체국은 우체통의 편지를 모아 받는 곳까지 날라 줘요.`

## 3. 저절로 생기는 '우와' 셋(엔진 결과 · 일일이 쓰지 않음)

1. **비가 그치면** 개울 소리가 커지고, 봄·여름이면 논가 개구리가 한꺼번에 울기 시작해요(날씨 바뀜 × 철 × 때 × 자리가 겹쳐서 · 가을·겨울엔 같은 비 뒤에도 조용).
2. **소리를 따라가면 진짜 있어요**: 가을밤 들판 귀뚜라미, 여름밤 큰 나무 솔부엉이, 여름 낮 숲 매미 — 소리가 나는 자리가 그 생물이 사는 자리라서, 귀로 찾아가 도감에 올릴 수 있어요.
3. **엽서가 마을에 남아요**: 어제 찍어 우체통에 넣은 장면을 받은 일꾼이 아침에 말하고, 일터에 가 보면 그 엽서가 붙어 있어요. 무엇을 찍었느냐에 따라 받는 이가 달라져요(왜가리 → 논 일꾼).

풍경(우와에 넣지 않음): 노을 동안 창이 하나씩 켜지고, 구역마다 가로등이 차례로 켜져요.
