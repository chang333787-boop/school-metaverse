# 🗺 거점·교류·지역 문제·지리 퀘스트(QUEST-2 설계 · 10-17)

사용자 10-17: "너가 봤을 때 교육적으로 어떤 거 같아 · 지리나 마을 문제 해결 같은 것도 · 다양하게 퀘스트를 지역 문제도 · 산에 사는 사람들이 물고기가 먹고 싶은데 없어 어떡하지 — 교류를 해야 되는데 그런 류 퀘스트도 · 교육용으로 해야 돼 · 마을 도서관 같은 게 거점이야? 거점을 정하면 좋겠어, GTA도 거점 같은 게 있지 · 설계 잘해 봐"

먼저 `town_lessons.md`(이상해 목록)를 지킨다 — 특히 길 안내 바로 · 가까운 곳부터 · 말하는 사람은 몸이 있음 · 셈 X · 사실만 · 지역 존중 · 교육을 잃지 않음.

## 1. 거점 — 🏛 어린이 도우미 본부(작은 도서관)
GTA의 거점(쉬는 곳·의뢰받는 곳·빨리 오가는 곳)을 우리 마을에 맞게:
- **본부 = 작은 도서관(다6 · 학교 정문에서 약 140m)** — 프롤로그에서 마을 수첩을 받는 곳이라 이야기와 이어지고, 학교에서 가까워 '가까운 곳부터'에 맞음. 책·지도가 있는 곳이라 배움의 거점으로도 어울림.
- 본부 안(실내 방):
  - 📌 **의뢰 게시판** — 마을 곳곳의 부탁(교류·지역 문제·지리)이 붙음 · 하루에 새 쪽지 1~2장
  - 🗺 **큰 마을 지도 판** — 동네마다 해결한 일·교류한 것이 표시됨(진행도 = 마을이 함께 좋아짐)
  - 📚 **책장** = 배운 개념 다시 보기(배움 별) · 🛂 마을 여권 도장대
  - 🧒 새 친구가 기다리는 자리 · 🚇 가까운 지하철역(곧)
  - **J를 줄여도 본부로는 늘 돌아갈 수 있음**(GTA 거점처럼)
- **동네 거점 = 마을회관·행정복지센터**(산·들·바다·시내마다 한 곳) — 그 동네 사람들의 부탁이 붙는 작은 게시판 · 동네 이야기의 출발점
- **쉬는 곳 = 내 집**(잠·저장·옷 갈아입기 — LIVING-1 '내 집 고르기')

## 2. 퀘스트 갈래 넷 — 모두 '배운 것을 써야 풀림'
### ① 교류(생산과 교환) — 4학년 사회 '필요한 것의 생산과 교환' · '촌락과 도시'
- 예 **「산 마을에 물고기를」**: 산 동네 어르신 "생선이 먹고 싶은데 여기선 안 잡혀" → (생각) 어디서 날까? 바다 동네 → (조사) 수산물 시장에서 무엇을 내주면 좋을까? 바다 동네는 산나물·버섯·꿀이 귀함 → (교환) 산에서 표고를 받아 → 버스·지하철로 바다로 → 바꿔서 → 산으로 → (되돌아보기) "왜 동네마다 서로 필요할까?" 한 줄
- 같은 틀로: 들(쌀) ↔ 시내(공산품·병원) · 바다(소금·김) ↔ 들(채소) · 산(목재·꿀) ↔ 시내 — 지역마다 **나는 것이 다르다 → 서로 필요하다 → 교통이 잇는다**
- 손에 남는 것: 장터 '교류 지도'(어느 동네에서 무엇이 오는지 선으로) · 교통을 이야기 안에서 씀(자전거 → 버스 → 지하철)
- 지킬 것: 어느 동네도 '모자란 곳'으로 그리지 않음 — 모든 동네가 주고 또 받음

### ② 지역 문제 해결 — 4학년 사회 '지역 문제와 주민 참여'
교과서 흐름 그대로 다섯 걸음: **문제 발견 → 원인 조사(관찰·사람들 말 듣기) → 해결 방법 견주기(기준표) → 정하고 실천(주민 회의·투표) → 바뀐 것 확인(그 자리 변화)**
- 예 **「학교 앞 길 건너기 위험」** — 아이들 패들렛 소원(A3 중간 횡단보도)과 이어짐: 차가 빨리 다님을 관찰 → 등굣길 주민·어르신 말 듣기 → 방법 셋(횡단보도·신호등·과속 방지 턱) 기준표 → 마을회관 회의에서 한 표 → **실제로 그 자리에 횡단보도가 생김**
- 예 **「불법 주차로 소방차가 못 지나가요」**(시내) · **「농수로가 막혔어요」**(들) · **「반딧불이가 줄었어요」**(강 — 물 맑게) · **「등산로가 망가졌어요」**(산 — 휴식년제) · **「다리가 낡았어요」**(패들렛 A7 다리와 이어짐)
- 아이 패들렛 소원이 있으면 **그 소원이 문제 해결의 끝 장면**(엔진 = 능력 · 내용 = 아이 소원)
- 정답 없는 고르기도 있음(기준에 따라 다를 수 있음) — 까닭 한 줄이 남음

### ③ 지리(지도) — 4학년 사회 '지역의 위치와 특성'
- **측량 도우미**: 전망대에서 두 산 중 더 높은 곳 고르기(등고선 간격 보기) · **관광 안내도 만들기**: 장소에 알맞은 기호·범례 고르기 · **보내는 편지 주소 읽기**(집배원 체험과 이어짐) · **노선도 읽기**(지하철 — 몇 정거장·어디서 갈아타기)
- 지도 배움 단계만 빨간 선 없이 · 고른 뒤엔 바로 길 안내(이상해 목록 C)

### ④ 생활·안전(지금 장 유지) — 더위·눈길·물놀이·불(직업 체험 소방관과 이어짐)

### 6.1 본부(작은 도서관) — 게시판 · 지도 판
- **자리**: 프롤로그에서 가는 그 작은 도서관(학교에서 가장 가까운 것) 앞면 벽에 붙은 게시판 하나 · 마을 지도 판 하나 — 큰 유리 오른쪽 · 책 꽂이 조형 왼쪽의 빈 벽(벽이 좁으면 판도 좁게 · 한쪽만 넓으면 나란히) · 판 + 위 띠 + 이름판 · 쪽지 다섯·동네 색 조각 · 기둥 X라 길·사람 줄을 막지 않음 · 정적 상자 = 짓기 때 한 번 · E 둘 `📌 의뢰 게시판` · `🗺 마을 지도 판`. 학교 앞 길·소화전 둘레엔 가로수를 심지 않음(신호 기둥·소화전이 가려지지 않게).
- **실내 팀과 겹치지 않게**: 방 소품 모양은 실내 팀 몫. 사서 체험 방이 `made.hub = [{ k: 'board' | 'map', stand: [x, y, z] }]`를 주면 그 자리에도 같은 E 둘이 생김(town_indoor.js 한 줄 · town.js가 `onHub: k => qst().hub(k)`를 넘김). 권하는 자리 = 게시판은 들어가자마자 왼쪽 벽(문에서 2~3m) · 지도 판은 가운데 큰 탁자나 맞은편 벽.
- **게시판**: 하루 한 번(아침) 이 막까지 열린 의뢰 가운데 아직 안 붙은 것 1~2장(가까운 곳부터 = `after` 차례) · 프롤로그 뒤부터 · 붙으면 알림 한 줄. 쪽지마다 보낸 사람(몸 있는 일꾼 · 그 동네) · 배우는 것 · ★ 도전 · `맡기`(지금 이야기는 쉬어 둠). 해결한 의뢰는 📜(★) 표시.
- **이야기 목록(Q)**: 맡은 의뢰만 줄로(이어 하기) · '본부 게시판에 새 쪽지 n장' · `🧭 본부 가는 길`(빨간 선 — J를 줄여도 본부로는 늘 돌아감).
- **마을 지도 판**: 동네마다 동그라미 + 도운 일 수 · 주고받은 선(교류 의뢰 · 2막 끝 '멀리서 온 물건') · 🚸 🚒 함께 바꾼 곳 · 📍 본부 · 방위표 · 범례(지도 단원과 같은 약속).

|---|---|---|---|
| 🦓 횡단보도 | 가게 앞에 차 세우기 어려워질까 걱정 | 건너는 곳이 보여 미리 천천히 | 건널 곳이 생겨 마음이 놓임 |
| 🚦 신호등과 횡단보도 | 신호 기다리는 차가 가게 앞에 줄 설까 걱정 | 짐 나르는 시간이 조금 늘었음 | 차례가 분명해 아이들이 덜 헷갈림 |
| 〰 과속 방지 턱 | 차가 천천히 다녀 조용해짐 | 턱에서 덜컹해 과일이 상할까 걱정 | 차는 느려졌지만 건너는 곳은 아직 멂 |
| 🔴 빨간 연석 | 손님이 잠깐 세울 곳이 줄어 걱정 | 어디에 세우면 안 되는지 알겠음 | 불이 나도 소화전을 바로 씀 |
| 🅿 공영 주차장 안내판 | 손님이 덜 헤맴 | 주차장에서 짐 나르기 힘듦 | 길가가 비어 걷기 편함 |
| 📷 단속 카메라 | 손님이 덜 올까 걱정 | 아무도 안 세움 | 오래 걸렸지만 소화전 앞이 비었음 |
- 학교 앞 길 자리 = 정문 가까운 길 가운데 **같은 길 위** 건널 곳(횡단보도·신호)이 40m 넘게 먼 곳(옆길 횡단보도는 이 길을 건너는 데 못 쓰므로 셈하지 않음) — 우리 마을 = 정문 남쪽 약 50m · 가장 가까운 건널 곳까지 49m.
- 같은 장터 상인 둘에게 듣지 않게 '하는 일이 다른 이웃'으로 길 안내 · 같은 갈래가 또 나오면 '그 밖' 말.

### 6.4 4학년 글 · 수첩 · 기록
- 지시문 한 문장 · 한 창에 할 일 셋 이하 · 셈 X(걸은 시간·거리·선 수는 읽기만).
- **낱말 상자**: 의뢰마다 새 낱말 둘(교류·수산물 / 도시·소비 / 염전·교류 / 지역문제·기준 / 사실·생각 / 등고선·측량 / 기호·범례) — 고르기·판단 창 위 단추, 누르면 뜻.
- **거꾸로 힌트 한 줄**: 의뢰마다 생각 단계 하나에 `↩ 거꾸로 생각: …`(끝 모습에서 거꾸로).
- **★ 도전 하나**: 위 표 · 하면 배너 한 줄 · 목록·게시판에 ★.
- **수첩 두 칸**: 📋 본 것·잰 것(사실 — 6초 보기 · 걸어서 잰 거리와 시간 · 센 등고선) / 💬 들은 말(생각 — 누가 무엇을 말했나). 까닭 고르기·사실 고르기·판단 창 안에 그대로 보임.
- **기록(나중 학급 기록 화면과 같은 이름)**: `S.story.rec[장] = { d0, d1, star, st: { 단계: { h 힌트 단계, tr 틀린 수, p 고른 것, w 까닭, l 불편해질 사람, t 한 줄, f 잰 값 } } }` · `S.story.nb[장] = { f, t }` · `S.story.board = { day, list, took }` · `S.story.qfix = { cross, park }` · 이야기 장도 같은 꼴로 단계마다 남김.
- **배움 별과 이음(QUIZ-1)**: 의뢰를 마치면 그 개념이 `GAME.S.learn`에 남아(문제 은행 출처 `st:의뢰`) 보너스 문제로 다시 나옴 — 교류 셋 → `region:trade`(소금 = `region:salt`도) · 학교 앞 길 → `safe:car` · `region:problem`(새) · 소화전 → `region:problem` · `life:factop`(새 · 사실과 생각) · `safe:hydrant`(새 · 소화전 둘레 5m) · 측량 → `map:contour` · 안내도 → `map:legend`. town_quiz.js에는 출처 몇 개와 새 개념 셋만 더함.
- 빈 칭찬 X: 맞히면 '무엇이 맞았는지' 한 줄(예: '정문 앞인데 건너는 곳이 멀어서 그래요.') · 정답 없는 고르기 = '고른 것: …' · `✨ 답이 반짝여요` → `👉 답에 노란 테두리가 생겼어요`(이야기 전체).

### 6.5 지리 = 볼 자료를 창 안에
- **측량 도우미**: 전망대 둘레 판 땅 높이로 두 산(두 꼭대기 사이 가장 낮은 곳보다 솟은 산 · 높이 차 있음)을 찾아 **등고선 지도를 창에 그림**(칸마다 네 귀퉁이 높이 → 선 조각 · 높이 숫자는 안 보임 · 가/나 = 섞어서 · 방위표 · 전망대 표시) → 더 높은 산 고르기 → 까닭(선이 더 많아요) → 가파른 쪽(선이 촘촘한 쪽 · 차이가 작으면 건너뜀).
- **관광 안내도**: 해수욕장·버스 터미널·관광 안내소 자리를 **지도 조각으로 창에 그림**(빨간 점 = 물어보는 곳) → 기호 고르기 → 왜 그 기호 → 처음 온 사람에게 필요한 곳 둘(정답 X) → **범례 칸이 붙은 지도**로 범례가 하는 일.
- 교류·지역 문제의 '어디에서 날까'도 지도 조각(어부·쪽지 준 일꾼 · 동네 이름)을 창에 그림. 메인 `api.mapSnip`(진짜 마을 지도 + 점 + 방위표)으로 그림 · 오른쪽 위 방위표 밑에 점이 숨지 않게 `ghost` 점(자리만 넓힘 · 그리지 않음)을 하나 더함 — mapSnip 한 줄(`if (p.ghost) continue`).

### 6.6 선생님 칸 '단원별로 보기'
- 이야기 목록 맨 아래 접힘 `📚 선생님용 — 단원별로 보기` · 단원 이름과 차시 이름 = 기획 Doc '교과서 목차' 탭 그대로(예: 4학년 1단원 지도 → 4-1-05 등고선 — 🗻 측량 도우미, 약 20분 ▶ 바로 열기) · 이야기 장과 의뢰가 함께 · ▶ = 막·게시판 잠금 없이 시작하고 그 자리 가까이로.

### 6.7 렉 · 계약
- 짓기 때 한 번: 본부 소품(정적 상자) · 학교 앞 길 셋(zebra · 신호 기둥·등 · 턱)과 소화전 장면(차 둘 · 빨간 연석 · 주차장 안내판 · 카메라)을 문(gate `q:…`)으로 미리 지어 둠 → 고르면 문만 켬(`qApply` — 보이기·충돌·신호 등). 신호는 켜졌을 때만 차가 섬(꺼진 신호 = 늘 초록). 매 프레임 일 0 · 새 Light X · 새 사람 X(말하는 사람 = 있는 일꾼·장터 상인·새 친구).
