# 일 시간(HOURS-1 · 사용자 10-24 '상인들이 영업 시간이 아니거나 일하는 시간이 아닌데도 진행되는 경우가 꽤 있네')

일꾼·상인은 일하는 때에만 E로 일(같이 해요 · 장터)이 열려요. 시간 밖에는 열지 않고 한 줄로 알려요: 머리 위 말풍선 "오늘 일은 끝났어요. 내일 07:00부터 해요!"(☕ 아침 전 · 😴 저녁 뒤) + 아래 알림 "🌙 ○○ — 지금은 쉬는 중 · 07:00~19:00 일해요". 이름표도 30분마다 '🌙 ○○ — 쉬는 중 · 07:00부터'로 바뀌어요.

## 시간표(`town.js` WHRS)
| 일꾼 | 일하는 때 | 까닭 |
|---|---|---|
| 기본(밭·과수원·표고·목장·논·나무 심기·갯벌·김·굴) | 07:00~19:00 | 해 있을 때 하는 일 |
| 🛒 장터 | 08:00~19:00 | 장 서는 때 |

| 🐟 부두 낚시 | 06:00~18:00 | 고깃배는 이른 아침 |
| 🍯 꿀 뜨기 | 09:00~17:00 | 벌이 한낮에 다님 |

| 👣 징검다리 | 늘 | 일이 아니라 놀이 |
| 📮 우체국 체험 · 📚 도서관 체험 | 09:00~18:00 | 문 연 때(`town_jobs.js` startJob) |

| 👮 경찰서·파출소 방(`town_bldg.js` · 112 신고 연습) | 늘 | 경찰서는 24시간 문을 엶 |
