# 🏁 우리 마을 — 성장·엔드 콘텐츠·교육 설계(GROW-1 · 10-17)

사용자 10-17: "레벨 숙련도가 없으면 결국 성장하는 그런 게 없는 거 같기도 해 · 게임 레벨링 시스템 고민" · "이 게임의 엔드 컨텐츠가 뭘까 · 뭐에 재미를 느낄까 애들이 · 교육적인 거는 생각보다 덜 들어간 느낌" · "완성도 있는 인디 게임 수준 · 렉 잡는 게 제일 중요"

## 진단 — 지금 왜 '오래 하고 싶은 까닭'이 약한가
- 놀이는 넓다(일 거들기·장터·요리·텃밭·낚시·별·곤충·스키·배…) — 그런데 **모두 '한 번 해 보면 끝'** 인 작은 고리. 해도 내가 달라지지 않고(성장 X), 마을도 달라지지 않음(변화 X), 끝에 닿을 목표가 없음(엔드 X).
- 교육은 대부분 **읽는 사실 한 줄**(일꾼 말·도감 설명·지식 카드) — 아이는 읽지 않고 넘긴다. 배운 것을 **써야만 앞으로 갈 수 있는 순간**이 거의 없음(예외: 이야기 1장 값 견주기·거스름돈).

## 4학년 아이가 재미를 느끼는 것(우리 게임에 있는 것 ↔ 없는 것)
| 재미의 뿌리 | 지금 | 빠진 것 |
|---|---|---|
| 내 것(소유) — 우리가 만든 마을·내 집 | ✅ 아주 강함(실제 판) | 내 집·나를 꾸미기(모자·자전거 색) |
| 성장 — 연습하면 는다 | ❌ | **솜씨 레벨 + 승급 미션** |
| 모으기 — 다 채우고 싶다 | 도감·도장 | 배지·칭호·'명예 주민증' |
| 함께 — 친구에게 보여 주기·같이 하기 | 함께하기 방 | 반 공동 목표(우리 반이 마을을 바꿈) |
| 발견 — 숨은 것 | 문어·무지개·반딧불이·독버섯 | 더 많은 비밀 + 단서 |
| 바꾸기 — 내 손으로 세상이 달라짐 | ❌ | **마을 프로젝트**(엔드) |

## 제안 — 세 기둥 + 하나의 끝
1. **🌟 솜씨(성장)** — 일솜씨·요리·농사·관찰·살림·탐험 여섯(1~10). 하던 놀이에서 저절로 늘고, 같은 일만 하면 덜 늚(고르게).
   - **보상 = 능력·배움·꾸미기**(힘 X): 탐험 2 = 작은 지도 방위표, 4 = 큰 지도 축척 막대(4학년 지도 단원 그대로), 일솜씨·요리 = 초록 칸 넓어짐(좌절 줄임), 살림 = 장터 값, 농사 = 거두는 수, 레벨마다 지식 카드 · 모자·자전거 색(꾸미기).
   - 솜씨 레벨·칭호는 **이 기기에서 나만 보기**(반 순위·견주기 X — 학급 기록 원칙과 같게 · 또래 10-17).
   - **승급 미션(교육의 핵심)** — 미션 자료 = 이야기와 같은 꼴(todo 30자 안 · 판정 없는 칸 힌트 둘 · slot) + `link: ['4-1-03', …]`(교과서 퀘스트 id — 2027 연습): 3·6·9레벨로 가려면 **배운 것을 써야 하는 미션** 하나(이야기 실행기 재사용 · 힌트 세 단계). 예) 탐험 3 = '방위표와 축척 막대로 어림해 북동쪽 ○○ 찾기(막대 몇 개쯤 — 칸 세기만 · 계산 X · 빨간 선 없이)' · 관찰 3 = '곤충과 곤충 아닌 것 나누기(거미·지네·나비…)' · 살림 3 = '쿠폰 다섯 장 안에서 꼭 필요한 것 고르기(작은 수 세기 — 교과서 4학년 3단원 꼴 · 값은 읽기만)' · 농사 3 = '싹 트는 데 필요한 것 고르기 → 심고 사흘 돌보기' · 요리 3 = '골고루 한 상 차리기(곡류·채소·단백질)' · 일솜씨 3 = '제철 일터 세 곳 찾아 거들기(달력 읽기)'.
2. **📖 모으기(완성)** — 도감·도장 + 솜씨 배지 여섯 + 칭호(새싹 → 꼬마 일꾼 → 마을 도우미 → 마을 솜씨꾼 → 마을 지킴이 → 우리 마을 박사).
3. **🤝 이야기·이웃(관계)** — 메인 스토리 장 다섯 + 이웃 ❤.
4. **🏁 끝 = 마을 프로젝트(바꾸기 · 반 공동)** — 아이들이 패들렛에 쓴 '마을 소원'(예: 다리·놀이터·도서관 꾸미기)을 선생님이 프로젝트로 올림 → 반 전체가 놀이로 모은 것(재료·돈·솜씨 미션)을 보탬 → 다 차면 **마을이 실제로 달라짐**(아이 소원 = 아이 판 내용 · 엔진은 '프로젝트 칸'만). 4학년 사회 '지역 문제 해결·주민 참여'와 맞닿음(투표로 다음 프로젝트 고르기). 개인 끝 = 솜씨 모두 5 + 도감 80% → **명예 주민증**(인쇄 가능 · 이름 = 아이가 넣음, 저장소 X).

## 교육을 '읽기'에서 '쓰기'로
- 배운 것이 능력이 됨(방위표·축척 = 탐험이 쉬워짐) · 승급 미션 = 배운 것을 써야 통과 · 이야기 장 = 생활 판단(예산·더위·눈길) · 마을 프로젝트 = 지역 문제·투표.
- 판정은 규칙으로만(또래 퀘스트 틀 명세) · 틀리면 반응 → 다시(벌 X) · 2027 교과서 엔진과 같은 데이터 꼴.

## 렉(가장 중요)
- 모두 이벤트로(경험치 = 이미 있는 TEV 한 곳) · 매 프레임 일 0 · 새 그리기 0(방위표·축척 = 이미 그리는 지도 캔버스에 · 꾸미기 = 색만 바꿈).
- 기능 셋마다 최적화 한 판(OPT-12: 크롬북 끊김 원인 순위 — 에이전트 조사 중).

## ⭐ 배움 별 + 보너스 문제(QUIZ-1 · 10-17 · `v2/games/town_quiz.js`)
사용자 10-17: "게임 루프상 동기 부여가 되면 좋겠는데 애들이 중독되면서 열심히 하면 좋겠어 · 배우는 개념들이 위에 나오는 거 좋은 거 같아 — 배운 개념들이 하루가 끝나든가 하루 중간에 한 번 튀어나와서 보너스 문제처럼"

**판단 = 몰입은 세게, 벌주는 장치는 빼고.** 연속 출석이 끊기면 잃는 것(스트릭 벌)·반 순위·뽑기(가챠)·불안 알림은 넣지 않는다(아이 건강 · 학급 원칙). 대신 되새김(간격 반복) 보너스 문제 + 모으는 재미(★·배지) + '내일은…' 예고.

### 고리
사실을 본다(위에 나오는 배움 글은 그대로) → 배운 개념으로 남음 → 낮에 한 번·잠들 때 보너스 문제 → 맞히면 ★ → 세 번 맞히면 익힘(★★★) → 갈래를 다 익히면 배지 → 하루 마무리 창 끝 '내일은…'
- **배운 개념 기록** `S.learn[id] = { d 처음 본 날, box 상자 1~5, ok 맞힌 수, ng 틀린 수, at 마지막으로 물은 날 }` — 상태로 알 수 있는 것(도감 돋보기·낚시·별 보기·바다 친구·숲 줍기·솜씨 지식 카드·이야기 장 끝·꽃가루받이 날)은 5초마다 훑고, 지나가는 글(일 놀이 창 위 일꾼 말 · 차 조심 배너 · 큰 지도 범례)은 `saw(열쇠)`로 남김. 바뀔 때만 저장. 처음 배우면 한 번만 '⭐ 배운 것은 수첩에 모여요' 알림.
- **낮 보너스(12~15시 · 하루 한 번)**: 창·놀이·대화·탈것·잠이 아닐 때, 일꾼 곁(9m 안)에 2초 서 있으면 **그 일꾼이** 대화창으로 묻는다(말하는 이는 몸이 있게 — 내 몸이 일꾼 옆으로 비껴 서서 일꾼이 화면에 보임 · 일꾼 머리 위 '잠깐! 문제 하나!'). 일 놀이를 끝내고 서 있는 그 순간에 자주 나옴. Esc로 넘겨도 벌 X(그날 낮은 끝, 밤에 둘).
- **하루 마무리(잠든 뒤 창 안)**: 하루 두 문제가 되게 — 낮에 풀었으면 하나, 아니면 둘. 오늘 새로 배운 수 한 줄. 둘 다 맞히면 **아침 선물**(요리 재료 하나 🥚🥛🌾🧈🍁 — 팔 수 없는 물건이라 경제 흉내 그대로).
- **간격 반복(라이트너 상자)**: 맞히면 다음 상자(1 → 하루 · 2 → 이틀 · 3 → 나흘 · 4 → 이레 · 5 → 두 주 뒤) · 틀리면 1상자 = 내일 다시. 고르는 차례 = 차례가 가장 오래된 것부터(밀린 것이 굶지 않게) · 하루 마무리엔 오늘 처음 본 것 하나를 섞음 · 차례인 것이 없으면 배운 것 가운데 별 적은 것으로 채움.
- **보상(가볍게)**: 맞히면 반짝(⭐ ★★☆ 팝) + 100원 + 솜씨 2(갈래 솜씨 — 자연 = 관찰 · 지역 = 일솜씨 · 지도 = 탐험 · 생활 = 살림 · 안전 = 탐험, 요리 카드는 요리) · 틀려도 솜씨 1(연습은 연습) + 해설 + '내일 다시 나와요'. 별은 줄지 않는다.
- **내 수첩 ⭐ 배움 탭**: 갈래(자연·지역·지도·생활·안전)마다 배운 것과 ★ · 익힌 수 %(익힘 ÷ 배운 것) · 갈래마다 배운 것이 다섯 넘고(갈래가 작으면 전부) 모두 ★★★이면 배지(한 번 받으면 그대로 · 배너). 빈 갈래 = 어디서 모이는지 귀띔 한 줄.
- **다시 풀기(수첩 · 하루 5번 · 차례인 것만 · 돈 X — 별과 솜씨 1만)**: 하루 두 문제만으로는 배우는 속도(하루 평균 둘)를 못 따라감 → 흉내(40일 · 맞힘 75%): 보너스만 = ★1 이상 41/65 · 한 번도 안 나온 것 18 · 익힘 6 → 다시 풀기 5번 더하면 ★1 이상 78/85 · 안 나온 것 6 · 익힘 32(20일째 18). 하고 싶은 아이만 · 상한으로 강박 X.
- **다른 팀이 남기는 배움(모션 팀 쇼 셋)**: 쇼가 끝나면 `GAME.S.learn[id] = { d, box: 1, ok: 0, ng: 0 }`(이 꼴 그대로) — 아쿠아리움 '바다 친구 이야기' = `nature:sound_water`(소리는 물속에서 더 빠르게(약 4배) 더 멀리) · 수달 = `nature:otter`(맑은 강 → 물고기 → 수달 · 천연기념물 · 주로 밤에 물고기) · 나비 = `nature:metamorph`(알 → 애벌레(허물 네 번) → 번데기(먹지 않음) → 어른벌레 = 갖춘탈바꿈 · 3학년 과학 '동물의 한살이') · 아쿠아리움 쇼의 다른 사실 셋(깊은 바다는 햇빛이 닿지 않아 깜깜 · 바다거북은 태어난 바닷가 근처로 돌아와 알 · 빛을 내는 해파리)은 소리 개념이 남으면 다음 훑기 때 함께(`learn:` 출처).
- **지도 문제는 보고 푼다(DIR-MAP · 사용자 10-17 밤 '소방서 우체국 지도상 위치를 외우라는 거냐?')**: 장소·방위를 묻는 문제는 그 창 안에 지도 조각(빨간 점·파란 점 장소 둘 + 방위표 · `mapSnip` — 이야기 고르기 창과 같은 그림)을 같이 보여 주고 읽어서 고름 · 장소 둘 = 이 마을 건물 가운데 70~350m · 사이 방위가 애매하지 않은 것(칸 가운데 ±12°) · 아이 집('○○네 집')·자연 칸·AI 어림 이름 X · 그림을 못 보이는 낮 대화창엔 지도 문제를 내지 않음(그 개념의 글 문제로) · 외워서 푸는 장소 위치 문제는 은행에 없음 · 지도가 필요 없는 개념 문제('축척이 뭐예요?')는 그대로.
- **내일은…(창 끝 한 줄)**: 장날 > 썰물 때(갯벌이 있는 마을) > 텃밭 자람 가운데 하나 + '배운 것 n개가 보너스 문제로 다시 나와요'.
- **하지 않는 것**: 연속 출석 벌 · 반 순위 · 뽑기 · 불안 알림 · 셈 문제(교사 '수학 앱이 아니니까' — 수는 119·세 개처럼 읽기만) · 지어낸 사실(게임이 보여 준 사실만 · 마을 설정은 '우리 마을에서는').
