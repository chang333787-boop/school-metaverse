## 2. 첫 화면에 남길 것(큰 지도 M을 열었을 때)
땅·물·길·구역 색(동네 색) · 학교 · 구역 이름 일곱 · **큰 장소 이름 8~12**(중요도 순 · 서로 120m 넘게 떨어진 것만) · 내 화살표 · 따라가는 목표 ❗와 빨간 선 · (있으면) 흐린 점 · 지금 생긴 일 점 · 옆 칸 = 짧은 범례 · 방위표(북 = 늘 위) · 축척.

중요도(정적 · 짓고 한 번 셈): 우리 학교 1000 → 바다·뒷산·강·호수·갯벌·해수욕장(넓이 순) → 소방서·경찰서·우체국·행정복지센터·도서관 → 병원·마트·시장·터미널 → 박물관·아쿠아리움 → 그 밖 공공. 같은 이름은 하나만 앞 단계에. 단계 0(≤12) · 1(확대 1.4배 ≥ · 70m) · 2(2.1배 ≥ · 35m) · 3(3배 ≥ · 나머지 큰 곳).

## 4. 이름표 겹침 규칙(그릴 때마다 · 차례대로 자리 잡기)
1. 나(화살표 + '나' 꼬리표) · 따라가는 목표(❗ + 이름 상자) 자리를 먼저 차지.
2. 우리 학교 → 단계 0 큰 이름(중요도 순) → 구역 이름 일곱(겹치면 위·아래·옆으로 비켜 봄) → 역 이름(🚌) → 칩 이름(중요도 순) → 아이 이름(🔖).
3. 이름 하나 = 기호 + 글 상자. 글 상자 자리 넷(아래 → 오른쪽 → 위 → 왼쪽)을 차례로 보고 다 겹치면 **그 이름을 숨김**(큰 이름은 기호도 같이 숨김 — 이름 없는 점 X · 칩 기호는 남김).
4. 확대(바퀴·두 손가락·＋－ 단추 · 1~4배 · 끌어서 옮김)하면 단계가 열려 이름이 더 나옴. 확대해도 북쪽 = 위 · 방위표 그대로 · 축척 막대는 확대에 맞춰 다시.
5. 누르기(끌지 않고 뗌) = GO-1 고르기 창 그대로(확대한 자리에서도 같은 땅 자리).

## 5. 내 화살표(세 지도 같은 꼴)
- 꼴 = 쐐기 화살(뾰족한 앞 + 홈 파인 꼬리) · 빨강 채움(ME-2 '나 = 빨강'과 이어짐 · 종이 지도 '현위치') + **흰 테두리 3px + 진한 바깥 선**(빨간 집·빨간 선 위에서도 떨어져 보임) · 큰 지도·칸 지도는 꼬리 쪽에 '나' 꼬리표.
- 크기(앞 끝 ~ 날개 끝 · 테두리 빼고): 작은 지도 17px(크롬북 80% = 14px) · 큰 지도 20~29px(지도 폭/52) · 칸 지도 25px. 목표 ❗(노란 원) · 흐린 점(흰 원) · 장소(흰 원) · 친구(색 원) 모두 둥근 꼴이라 꼴로도 갈림.
- 방향 = **실제로 움직인 쪽**(0.2초마다 자리 차이 · 걷기·옆걸음·뒷걸음·자전거·배·버스 모두) · 0.6초 넘게 멈추면 **카메라가 보는 쪽**(앞 키를 누르면 갈 쪽) · 25m 넘게 튀면(순간이동) 셈 X · 부드럽게 돌림.
- 매 프레임 일 0(0.2초 시계에서 한 번 · 새 객체 X · 카메라 행렬에서 바로 읽음).
