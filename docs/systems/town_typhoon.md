# 🌀 태풍이 온다(TYPH-1 · 성취 네 기둥 첫 증명 판)

정본 방향은 `docs/systems/town_achieve.md`예요. 이 문서는 그 표의 '태풍이 온다' 한 판을 실제로 지은 내용이에요.
코드는 `v2/games/town_typhoon.js`(A 넘김 꼴)에 있어요. `town.js`는 연결만 해요. 대피 길 사건은 사건 수첩 엔진 표 `town_case.js` `CASES.typhoon` 한 줄(`ext: 'typhoon'`)이에요.

## 1. 언제 오나
- 처음 판은 이야기 1막 끝 장(`a1_6`)을 마쳤거나 7일째가 되면 와요. 계절이 맞아야 해요(지금 판 · 여름 · 가을). 아침 11시 전에만 시작해요.
- 그 뒤에는 앞 판이 끝나고 21일이 지나면 와요. 계절이 맞는 아침에 다섯에 하나꼴로 와요.
- 시험할 때는 `SM_TOWN.typhoon.start()`를 불러요.

### 2-1. 태풍 날(TYPH-2 · 사용자 10-31 "태풍날 아무것도 못 하고 시간도 못 보내고 이벤트가 뭔가 이상해")
- **창 하나**: 태풍 날 창(`open7` · 창 갈래 `typstorm`)은 아침에 한 번 저절로 떠요(깬 뒤 2초 · 다른 창이 없을 때). 닫아도 **할 일 줄 「🌀 태풍 날 — 안에서 할 일 보기」 · 태풍 수첩 · 집 문가·대피소(학교 안)의 🌀 E**에서 다시 열려요. 수첩에도 ⏩가 있어요.
- **미룬 행사**: 잔치·계절 행사가 태풍 날과 겹치면 따로 알림을 띄우지 않고 `A.stormNote(t)` → `TYP.note(t)`로 태풍 날 창 맨 위 「📅 …」 한 줄이 돼요. 창이 떠 있으면 그 자리에서 고쳐 그려요. 태풍 날 아침엔 깬 자리 알림('정문은 바로 저기예요')도 띄우지 않아요.
- **안에서 할 일 넷**(하면 그만큼 게임 시각이 가요 · 알림 없이 창 안 글로 · 22시까지):
  | 할 일 | 하는 것 | 때 |
  |---|---|---|
  | 📻 라디오 태풍 소식 | 아침·11시·15시 소식 셋(다가옴 → 가장 가까이 → 멀어짐). 듣고 지금 할 일 셋 가운데 하나를 골라요. 틀리면 까닭 한 줄만 나와요. 들은 뒤엔 「다음 소식까지 쉬기」 | 20분 |
  | 🔦 집 안 태풍 대비 살피기 | 다섯 줄을 '맞아요/아니에요'로 나눠요(물 받아 두기 · 손전등·라디오 건전지 · 창문 잠그기 / 창문 열어 보기 X · 비 오는 길 하수구 보러 가기 X) | 30분 |
  | 📞 이웃에게 안부 전화 | 부탁을 들었던 이웃(이름 없는 역할)과 같은 반 친구. 도운 일이 있으면 그 일로 고마워하고, 못 했어도 탓하지 않아요 | 한 통 10분 |
  | 🎲 가족과 윷놀이 한 판 | 판 놀이 틀(`town_table.js` 윷놀이 · `A.table('yut')`) | 30분 |
  - 사실은 태풍 행동 요령 일반 상식만이에요(밖에 나가지 않기 · 창가에서 떨어지기 · 손전등 · 정전 때 냉장고 덜 열기 · 강가·고인 물 가까이 X · 지나갔다는 방송까지 기다리기). 겁주는 말·다치는 장면 X.
  - 보상: 할 일마다 처음 한 번 솜씨 1(라디오 = 관찰 · 살피기·전화 = 일솜씨 · 꼬리표 `case:typhoon` → rwCheck 하루 3). 윷놀이는 판 놀이 틀의 보상(`table:*`)을 그대로 써요.
- **밖으로 나가면**: 알림 한 번(「밖은 바람이 너무 세요. 곧 안으로 돌아가요.」) → 5초(`TY.grace`) 안에 돌아오면 그대로 → 아니면 어둡게 넘기며(`A.fade`) **마지막으로 안에 있던 자리**로 돌아와요(학교에 있었으면 학교 · 집이 없으면 정문 안). 그 자리는 다시 '안'이라 또 끌려가지 않아요.
- **⏩ 기다리기 = 메뉴 잠과 같은 길**(`A.sleep` = `sleepNow(false, true)`): 하루 마무리 창이 잠들기 전에 한 번 뜨고, 깬 뒤에는 다시 안 떠요 → 8일째 아침 결과 창.

## 4. 연결(town.js) — 캐시 번호는 메인이 올림
- `createTyphoon(A)`는 setEntries에서 DAY 바로 뒤에 지어요. 1초 칸은 `TYP.sec()`, 'day' 이벤트는 `TYP.day()`예요.
- 예보 `fcRaw`(7일째 비 · 6일째 흐림 · 8일째 맑음) · `frontOn`(태풍 날 전선 끔) · 풍향 깃발 `TYP.windAt` · `umbStrong` · `waterSec`(lv 1) · `LOOKX wx` 'storm'(town_look.js `OVC.storm`) · 날씨 창 한 줄 `TYP.wxLine()`
- 할 일 줄 `TYP.line()`(태풍 판 동안 이야기 줄보다 먼저 · 누르면 태풍 수첩) · 오늘 할 일 ⑤ `TYP.ctx(C)`(C.only · ev 'typh') · 위 가운데 줄 `TYP.goal()`(대피 길 확인 중 · 6일째 · 7일째) · town_day.js `A.typh(d1)` → '내일 기다리는 것' 맨 앞
- 태풍 날에는 EMG·RD sec를 쉬어요. 시험 손잡이는 `SM_TOWN.typhoon`(start · info · open · dbg · api)이에요.
- TYPH-2: A에 `homeDoor()` · `fade(fn)` · `table(g)`를 더 넘겨요. `sleep()`은 메뉴 잠과 같은 `sleepNow(false, true)`예요. 잔치(`town_feast.js`)·계절 행사(`town_season.js`)에는 `stormNote(t)`를 넘겨요. 손잡이 `TYP.note(t)` · `TYP.open7()` · `dbg.radio/check/call/yut/actAll/inSchool/safe/spots`.
- town_case.js 손잡이: `CASES.typhoon`(ext) · `export const CL`(ty_* 여섯) · plan에서 `R.ext`는 건너뜀. town_typhoon.js는 `./town_case.js?v=1`을 읽어요. **town.js의 town_case 캐시 번호를 올리면 여기도 같이 올려요.**

- 모습(합친 부품)은 상태 열쇠가 바뀔 때만 다시 지어요. 배 1 · 말뚝 2 · 밧줄 1 · 물품 탁자 1 · 임시 몸(가게 주인·어르신 · 이름 없는 역할)이 있고, 흔적은 곳마다 1이에요. 판이 끝나면 다 치워요. 새 Light는 없어요.

## 6. 시험
`zsh tools/ops/b2.sh node tools/harness/town_typhoon.cjs ourtown <포트>` (그리기 끔 · `--shots=폴더`면 켬)
- 예보 창 · 날씨 창 한 줄 · 예보 비 → 소문 · 사실/생각 나누기(틀리면 안 붙음)
- 2일째 부탁 셋 · 끈이 모자라 다 못 함 · 할 일 ⑤ · 물품 10분 · 배: 반대쪽 +30분 → 바람 쪽 40+15분 · 모래주머니: 먼 쪽 +30 → 강 쪽 40+45 · 끈이 떨어져 간판 못 함
- 3일째 부탁 넷 이상 · 가파른 비탈: 3칸 = 미끄러짐 + 20분 / 6칸 = 올라도 확인 X · 강가 = 멈춤 · 길로 걸어 학교 = 확인 · 어르신: 걸은 길 + 소문 근거(+10분) → 본 것
- 6일째 위 가운데 줄 · '내일 기다리는 것' · 7일째 비·센 바람·물 +1·창 · 밖 → 알림 한 번 → 몇 초 뒤 안으로 · 기다리기(마무리 창 먼저) = 다음 날
- `--storm` = 태풍 날 한 판만(TYPH-2 · 1분 남짓): 6일째 저녁 메뉴 잠 → 7일째 아침 창 차례(태풍 창 하나 · 창 뒤 알림 0 · 미룬 잔치 = 창 안 한 줄) → 할 일 넷 · ⏩가 할 일 줄·수첩·E에서 · 할 일 셋 = 때가 감 + 솜씨 · 라디오 다음 소식까지 쉬기 · 윷놀이 창 → 학교 안 머묾 · 밖 1.6초 = 그대로 + 알림 한 번 → 몇 초 뒤 안으로 → 6초 더 = 또 안 끌려감 → ⏩ = 마무리 창 한 번 → 8일째 결과 창 · 맑음 · 페이지 오류 0
- 결과 두 판: 반만 함(멀쩡 + 흔적 + 고치기 넷 + 고마움·아쉬움 · 고치면 둘 다 · 이웃 한 줄) / 다 함(모두 멀쩡 · 고치기 0 · 고마움만) · 페이지 오류 0
