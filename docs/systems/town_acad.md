# 🎓 학원 공부(ACAD-1 · 11-07)

교사 11-07: "학원에서 공부 요소만 더 추가하고 이번 주는 마무리하고 싶어." — 1~2주 안에 마무리할 게임이라 **이번 주 안에 끝나는 크기**로 짓는다.

먼저 `town_lessons.md`를 지킨다(B 화면 · CTRL-1 창 규칙 · C '수학 앱이 아니니까' → **학원 안만 예외** · D 손동작 겹침 · F 지키는 선). 홍보판(SM_PROMO)엔 마을이 안 열린다.

## 1. 아이 눈으로 무엇이 바뀌나
- 전: 학원 일곱 갈래가 모두 같은 퀴즈 판 셋(사실 하나 고르기)뿐 → 셋 풀면 끝, 다음 날도 같은 문제.
- 후: 선생님 곁 E = **오늘 수업 한 판**(다섯 문제 · 3~5분 · 쉬운 것 → ★도전 하나). 틀리면 **힌트 1 → 힌트 2 → 까닭**(정답 단추를 칠해 주지 않음 · 고른 틀린 보기는 ✗로 잠김). 맞히면 '오늘 배운 것' 한 줄.
- 잘한 판이면 **단계가 오르고**(1~5) 칠판에 내 별이 하나 붙고 가방 🏅에 그 과목 **수료 도장**이 하나 쌓인다. 📒 학원 수첩(수첩 탭 · 학원 안 단추)에서 과목마다 단계·도장·최근 배운 것을 본다.

## 3. 한 판 흐름 · 힌트 · 까닭
1. 하는 법 창(처음 한 번 + 매번 짧게): "오늘 배울 것: ○○ · 다섯 문제 · 틀리면 힌트가 나와요" → [수업 시작](기본 · Enter).
2. 문제 창: 맨 위 「할 일: …」 한 문장 · 물음(20px) · 그림(SVG·색 칸·큰 이모지) · 보기 단추(56px · 2×2 · 휴대폰 세로 1열) · 숫자 키 1~4.
3. 틀림 → 그 보기 ✗ 잠김 + **힌트 1**(어디를 보면 되는지) → 또 틀림 **힌트 2**(푸는 길 한 걸음) → 또 틀림 **까닭**(왜 그런지 끝까지 · 단추는 칠하지 않음 — 남은 보기 가운데 아이가 고름).
4. 맞힘 → ✓ + "오늘 배운 것: …"(그 문제의 한 줄) → [다음](기본).
5. 끝 창: ●(한 번에) ◐(힌트 뒤) ○(까닭 뒤) 다섯 칸 · 오늘 배운 것 셋까지 · 단계 결과 · 보상 줄 · [닫기] [📒 수첩] [한 판 더].
- 차례·리듬·동작 문제: 칸을 다 채우면 맞춤 → 틀리면 힌트 1 "앞에서 n칸까지 맞아요" → 힌트 2 다시 보여 주기 → 까닭(차례를 글로 · 왜 그 차례인지).

## 4. 수첩 · 별 · 도장 · 보상
- 상태 `S.acad = { v, s: { 과목: { st 단계 1~5, clr 마친 단계 0~5, up 단계 오른 날, rd 보상 날, n 수업 수, self 자습 수, learn [최근 셋], rec [최근 문제 id] } }, seen }`.
- **잘한 판** = 다섯 가운데 넷 이상을 까닭 보기 전에 맞힘. 수업 시간 · 잘한 판 · **과목마다 하루 한 번** 단계가 오름(1→2 … 5 → 수료) — 날을 넘겨 쌓이게.
- 단계를 마칠 때마다: clr +1 → 칠판 별(마친 단계 수 · 방에 들어갈 때 다시 그림) + 가방 🏅 **수료 도장** +1(📐 🔤 💡 📝 🎨 🎹 🥋 · ITEMS 'stamp' · 꼬리표 `acad:<과목>`) · 다섯이면 '수료'.
- 솜씨: 수업 시간 한 판을 마치면 그 갈래의 솜씨 +2(수학·영어·공부방·피아노·태권도 = 🧭 탐험 · 미술·과학 = 🔍 관찰 — 예전 학원 그대로) · 꼬리표 `acad:<과목>` · `RW_XP.acad = 1`(과목마다 하루 한 번 · rwCheck 한 문). 끝 창 줄 = 실제로 오른 양(0이면 '오늘 몫은 받았어요 — 이번 판은 연습').
- '배움' 솜씨를 새로 만들지 않은 까닭: 솜씨 하나 = 레벨 보상·모자·승급·장인 칭호·이웃 말 표 여덟 곳 → 이번 주 크기를 넘음. 대신 학원 수첩의 단계가 '배움 단계'.

## 5. 수업 시간
- 학원 문 = 10~21시. **수업 = 오전 10시~밤 9시(마을 시계 · DEB-2 11-08 토론 판정 — 예전 오후 2~7시는 첫 수업에 학원에 가면 '오늘 수업은 끝났어요'가 먼저 떴음 · 시계 빠르기 SPM 0.7과 과목마다 하루 한 번 상한은 그대로)**. 그 밖에 E(시험 바로 열기 등) → "수업은 오전 10시부터예요. 지금은 자습만 할 수 있어요."(밤 = "오늘 수업은 끝났어요.") → 자습 = 세 문제 · 단계·도장·솜씨 X · 수첩 '자습' 수만.
- 창이 열린 동안 마을 시계가 멈추는지는 마을 규칙 그대로(openP = 얼림). 수업 중 7시가 넘어도 시작한 판은 수업으로 셈.
