# 🫁 탐험 체력(STAM-1) + 게임성 ① 움직임 — 최종 설계(10-24 · 적대 토론 심판)

최종 차례 10번 줄의 설계예요. 사용자 10-24의 말 두 가지가 바탕이에요. 하나는 「젤다 기력처럼 많이 할수록 더 탐험」이고, 다른 하나는 「넣기가 아니라 얼마나 했을 때 어디까지 갈 수 있나 설계가 어려움」이에요.
안 A(몸·장면)와 안 B(엔진·세상 반응)를 두고, 다섯 역할이 반박했어요. 이 문서는 그 결과를 하나로 합친 정본이에요. 짓는 사람은 이 문서만 보고 지을 수 있어야 해요.
먼저 `town_lessons.md`와 `town_upgrade_plan.md`를 읽어요. 지키는 선은 이래요: 판타지 X · 아이 그림 X · 개인 순위·뽑기 X · 아이콘·%·숫자 막대·타이밍 막대 X · 하루 기력 X · 새 Light X · 크롬북 렉 X.

---

## 0. 한 줄 결정
- **체력 사다리는 헤엄과 오르기 두 동작에만 걸어요.** 칸이 늘면 더 먼 바위섬까지 헤엄치고, 더 높은 바위벽을 올라요.
- **활공(패러글라이더)은 체력으로 막지 않아요.** 거리는 출발대 높이와 바람이 정해요. 실제 비행도 그래요.
  - 체력은 오르기로 더 높은 출발대에 닿게 해 줄 뿐이에요. 그래서 '더 길게 활공'은 '더 높이 올라가서'로 이뤄져요.
- 우산은 **높이 12m 아래 낮은 턱에서만** 펴져요. 높은 곳에서 날기는 패러글라이딩 체험장에서만 해요(`town_freedom.md` §5).
- 비탈을 뛰어오를 때도 바퀴가 줄어요(사용자가 「달리기」를 말했어요). 하지만 사다리 밖이에요. 다 쓰면 걸을 뿐이고, 걷는 동안 바로 다시 차요.

## 1. 하루 한 바퀴에서 어디에 걸리나(PLAN-1 판정)
- 이 기능은 **나가기 → 하기 → 결과** 칸에 걸려요.
  - 나가기: 바다·산으로 나가요.
  - 하기: 몸으로 헤엄치고, 오르고, 날아요.
  - 결과: 바퀴 호가 하나 늘어요. 어제 못 가던 바위가 오늘 닿아요.
- 저녁 일기에는 「오늘 뒷산 밧줄 바위를 끝까지 올랐어요」처럼 한 줄이 남아요. 아침 기대는 「내일은 바위섬까지 헤엄쳐 볼까」예요.
- 기둥 ①(몸으로 하는 동사)에 오르기·패러글라이더 두 동사를 더해요. 기둥 ④(사회 배움이 열쇠)에는 바람자루로 이륙 방향 고르기(방위)를 더해요.

## 2. 숫자(정본)

### 2-1. 칸과 칸당 능력
| 값 | 정한 것 | 까닭 |
|---|---|---|
| 시작 칸 | 3 | 처음 헤엄 목표(뗏목)에 맞춤 |
| 최대 칸 | 10(이번 10번 줄에서는 9까지) | 9·10단계 자리는 15번 줄 땅(까망봉·긴 수영 코스)이 생길 때 |
| 헤엄 1칸 | 물속에서 움직인 거리 30m | 헤엄 빠르기 2.3m/s(지금 그대로) → 1칸 ≈ 13초 |
| 오르기 1칸 | 오른 높이 5m(내려가기는 반값 = 10m에 1칸) | 오르기 빠르기 0.9m/s → 1칸 ≈ 5.6초 |
| 비탈 달리기 1칸 | 달리며 오른 높이 10m(경사 10% 넘는 곳만 · 평지·내리막은 0) | 사다리 밖 · 숨소리·몸짓용 |
| 제자리 헤엄·매달려 쉬기 | 0(줄지도 늘지도 않음) | 물속·벽에서는 회복 없음 → 끝없이 가는 길 없음 |

**소모는 시간이 아니라 '간 거리·오른 높이'로 셈해요.** 창이 열리거나 멈춰 있어도 줄지 않아요. 아이가 서두르지 않아도 돼요.

### 2-2. 회복(쉼)
- 쉼은 **발이 땅(뗏목·바위섬·바위 턱 포함)에 붙어 있고 달리지 않을 때**예요.
- 1.0초 뒤 차기 시작해서, 빈 바퀴가 다 차는 데 3.0초 걸려요(일정한 빠르기).
- 걷는 동안에도 차요. 그래서 비탈 달리기로 다 써도 걸으면서 4초면 다시 차요.
- 한 줄 길(헤엄 길·오르기 길) 위의 발판 간격은 그 단계 칸보다 촘촘하면 안 돼요. 이건 하네스가 재요(§8).

### 2-3. 크기 공식
- 단계 k 목표의 크기 = **(k − 0.4) × 칸당 능력**이에요. 허용 오차는 ±3%예요.
- k−1칸으로는 0.6칸이 모자라 못 가요. k칸이면 0.4칸이 남아요.
- 크기는 **가장 가까운 발판에서 잰 거리**예요. 물가만이 아니라 다른 뗏목·바위섬에서도 재요.

### 2-4. 다 썼을 때(벌 X · 순간이동 X)
| 동작 | 다 쓰면 | 숫자 |
|---|---|---|
| 헤엄 | 누워 뜨기(생존수영) 자세 → **마지막으로 떠난 발판 쪽**으로 떠밀려요 | 0.6m/s |
| 헤엄(이어서) | 10초 뒤 안전요원 배가 보이게 다가와요 → 태워서 **언제나 해수욕장 모래사장**(안전요원 망루 앞)으로 가요 | 다가옴 6m/s · 돌아감 8m/s · 아무 키 = 건너뛰기(버스 결) |
| 오르기 | 손이 풀려 마지막 턱 또는 맨 밑까지 천천히 미끄러져 내려와요 | 1.5m/s |
| 비탈 달리기 | 걷기가 되고 숨소리가 나요 | 걸으며 회복 |

- 떠밀리거나 배를 타고 가서 목표지에 닿는 길은 없어요. 하네스 실패 조건이에요.
- 누워 뜨기 중에는 줄지도 차지도 않아요. 실제로도 누워 뜨기는 힘을 아끼는 자세예요.

### 2-5. 패러글라이더(GLIDE-1 · 체력과 상관없음)
| 값 | 정한 것 |
|---|---|
| 떨어지는 빠르기 상한 | 1.6m/s(`map.player.glide(1.6)`) |
| 앞 빠르기 | 걷기 × 1.3 = 5.5m/s(저절로 앞으로 감) |
| 활공비 | 약 3.4(실제 체험 기체는 8~10 · 마을 크기에 맞춰 짧게 · 이웃 말에 넣지 않음) |
| 돌기 | 50°/s |
| 브레이크(S·막대 아래) | 앞 4.0m/s · 아래 1.9m/s(내릴 곳을 맞출 때) |
| 바람에 밀림 | `CHEM.api.wind(day)` 쪽으로 0.6m/s · 센 바람 날(`umbStrong`) 1.0m/s |
| 이륙 | 출발 띠 4m 위에서 W(막대 위)를 1.2초 누르고 달리면 날개가 서요 → 띠 끝에서 떠요 |
| 이륙 방향 규칙 | **바람을 마주 보고만 떠요**(실제 규칙): 출발대가 보는 쪽과 바람이 불어오는 쪽 사이가 90° 안이어야 해요 |
| 출발대 | 곳마다 **서로 반대쪽을 보는 띠 둘** → 어떤 바람에도 한쪽은 늘 열려 있어요 |
| 착지 | 발밑 0.3m 안 → 서기 · 날개 접기 0.6초 |
| 착지 그림자 | 지름 3m 땅 그림자(plane 1개) · 0.1초마다 앞길 12점을 `groundAt`으로 어림(레이 X) |
| 못 내리는 곳 | 물·학교 칸(SR + 8m)·박공 지붕·걷기 경계 밖 → 30m 앞에서 몸이 그쪽에서 부드럽게 돌아가요(돌기 +30°/s) |
| 그래도 지붕에 닿으면 | 가장 가까운 '걸어 닿는 땅 칸'으로 미끄러져 내려와요(DOOR-3 칸 찾기 재사용) |

**출발대 셋**
| 출발대 | 자리 | 닿는 법 | 높이(어림) | 날 수 있는 거리(바람 없음) |
|---|---|---|---|---|
| P1 | 뒷산 전망대 | 걸어서 · **첫 체험은 여기만**(강사가 서 있음) | 약 50m | 약 170m |
| P2 | 주봉 정상 쉼터(동·서 띠) | 걸어서(등산로) · 첫 체험 뒤 | 약 330m | 약 1.1km |
| P3 | 정상 바위탑 꼭대기(동·서 띠) | **오르기 8단계로만** | 정상 + 38m | P2보다 약 130m 더 |

- 지금 정상에서 우산으로 약 500m 날던 것은 P2로 바뀌어요. 그래서 빼앗기는 것이 없어요.
- 오히려 두 배 넘게 멀리 가요. 대신 우산은 낮은 턱에서만 써요.

### 2-6. 우산(UMB-1 고침)
- 우산을 펼 때나 활공을 시작할 때 발밑 땅까지 높이가 **12m를 넘으면 우산이 펴지지 않아요.** 바람에 홀랑 뒤집히는 모습이 나와요(지금 있는 뒤집힘 모습을 다시 써요).
  - 이때 한 줄: 「높은 데서는 우산이 뒤집혀요 — 날고 싶으면 패러글라이딩 체험장으로 가요」(하루 한 번).
  - 12m 아래 턱에서는 지금처럼 2.2m/s로 천천히 내려와요. 그러면 가장 멀리 가도 약 40m예요.
- 출발대 띠 위에서는 우산을 펼 수 없어요.
- `UMB.high`(앞 2.6m에서 4m 넘게 낭떠러지)는 그대로 둬요. 다만 12m를 넘는 낭떠러지에서는 '높은 곳이에요! 우산' 안내를 띄우지 않아요.

### 2-7. 자전거 꺾기(손맛)
- 빠를수록 도는 빠르기(돌기 각속도)의 상한을 낮춰요. 8m/s 아래는 260°/s예요. 21m/s에서는 170°/s로 줄어요(그사이는 곧게 이어 줄임). 21m/s에서 도는 반지름은 약 7m예요.
- 자전거를 탈 때만 몸 기울기 상한을 ±0.2에서 ±0.35로 키워요. 걸을 때는 지금 그대로예요.
- 흙먼지: 돌기가 150°/s를 넘고 빠르기가 12m/s를 넘으면 뒷바퀴에서 나요. 있는 입자 풀을 다시 쓰고, 0.3초에 한 번까지예요.
- **교차로 봇이 실패하면 돌기 상한을 끄고 기울기만 남겨요**(§8 하네스 F).

### 2-8. 오르기(CLIMB-1 · 표시 있는 곳만)
- **오를 수 있는 곳은 밧줄·쇠사슬·쇠 발판이 박힌 바위벽뿐이에요.** 맨 바위·집 벽은 못 올라요. 턱 0.55m · 점프 0.97m 규칙은 그대로예요.
- 잡기: 오르기 길 밑동 1.0m 안에서 길을 바라보고(바라보는 방향과 0.7 넘게 같을 때) W(막대 위)를 0.3초 누르면 잡아요. E는 쓰지 않아요.
- 오르기: W를 누르고 있으면 올라가요. 쇠사슬은 0.9m/s, 밧줄은 0.8m/s예요. S는 내려가기예요.
  - 손을 놓으면 그 자리에 매달려요. 매달려 있는 동안은 줄지도 차지도 않아요.
- 놓기: 맨 밑 2m 안에서 S나 Space를 누르면 내려서요. 그보다 높은 곳에서 Space는 무시하고 「꼭 잡고 있어요」를 하루 한 번 띄워요.
- 꼭대기: 위 발판에 닿으면 0.4초 동안 몸을 끌어올려 서요.
- 휴대폰: 왼쪽 막대를 위로 **누르고 있기**예요(연타 X). 새 단추는 없어요.
- **갈래 고르기**(타이밍 X): 6단계 중턱 바위벽에는 길이 둘이에요.
  - **곧은 쇠사슬**: 28m를 한 번에 올라요. 빨라요.
  - **턱 있는 밧줄 길**: 28m 오르고 바위 턱에서 쉰 뒤 다시 28m 올라요. 돌아가는 길이고, 턱에 전망 자리와 사진 자리가 있어요.
  - 두 길 모두 6칸이 있어야 해요. 그래서 둘 중 무엇을 골라도 사다리가 깨지지 않아요. 고르는 기준은 '빨리' 아니면 '구경'이에요.
- 카메라: 매달리면 벽에서 3.2m 떨어지고 옆으로 0.8m 비켜요. 지붕·덮개 막이(E줄 규칙)와 같은 막이를 벽에도 써요.

### 2-9. 체력 바퀴(보이는 성장)
- 어깨 오른쪽 위(+0.5, +1.9m)에 세상 안 Sprite 하나로 그려요. 화면 HUD가 아니어서 휴대폰 화면을 가리지 않아요.
- 캔버스는 64×64예요. 칸 수만큼 호를 나눠 그리고, 칸 사이에 틈을 둬요. 숫자·%·막대는 없어요.
- 색: 찬 칸은 종이 교과서 결의 초록 잉크, 빈 칸은 연한 회색이에요. 1칸 아래로 떨어지면 남은 호가 주황으로 바뀌어요. 빛 번짐·글로우는 없어요.
- 보일 때: 헤엄·오르기·비탈 달리기 중이거나, 바퀴가 다 차 있지 않을 때만 보여요. 다 차고 1초 뒤 사라져요.
- 다시 그리기: 1/16칸 단위로 바뀔 때만, 1초에 10번까지예요.
- **칸이 느는 순간**: 바퀴가 나타나고 새 호가 0.8초에 걸쳐 그려져요. 숨 들이쉬는 소리가 한 번 나요. 한 줄: 「숨이 길어졌어요. 조금 더 멀리 갈 수 있어요.」 '멋져요' 같은 빈 칭찬은 쓰지 않아요.

## 3. 목표지 표(사다리 · 지금 있는 땅으로 다시 짬)
칸을 늘리는 도장은 **그 단계 칸을 끝까지 다 써야 닿는 자리**에만 둬요. 걸어서 닿는 곳(⛰ 정상 도장 등)은 칸을 주지 않아요.

| 9 | 까망봉 바깥 바위벽 | 오르기 | 43m | `D.edges` 까망봉(35m 봉 + 기슭) | → 10 | 15번 줄 |
| 10 | 바다 긴 수영 코스(도전) | 헤엄 | 288m | 부표 줄 바깥 고리 | 칸 그대로 · 도전 기록(11번 줄) | 15번 줄 |

- **썰물섬은 사다리에 넣지 않아요.** 썰물에 걸어서 가고, 늦으면 기다리거나 배를 타요(`town_explore.md` §33 그대로). 사용자가 말한 「섬까지 헤엄」은 부표 안 작은 바위섬 R2·R3로 이뤄요.
- 뗏목·바위섬·바위벽·출발대는 모두 아이 판에 없는 자리예요. 그래서 `ourtown.js`에 ✨ 꼬리표를 달아요(AI가 채운 빈칸 · 엔진 = 능력 규칙).
  - 아이 판에 바다 바위나 산 바위가 나오면 그 자리로 옮겨요.
- **차례대로 지어야 사다리가 안 끊겨요.** 10-1은 3→6, 10-3은 6→9예요. 못 지은 단계의 도장과 다음 목표는 놓지 않아요. 그래야 '못 가는 곳 0'이 지어진 것만으로도 성립해요.

## 4. 화면 흐름(아이가 겪는 차례)

### 4-1. 처음 헤엄(첫 30초 · 첫눈에 할 일)
1. 모래사장 안전요원 망루에 **안전요원(이름 없는 역할 · 몸 있음)**이 서 있어요. 물에 처음 들어가면 그 사람이 한 줄 말해요: 「숨이 차면 누워서 떠요 — 이렇게요」.
2. 안전요원이 망루 위에서 누워 뜨는 자세를 2초 보여 줘요. 잎새 뜨기처럼 팔다리를 벌린 자세예요.
   - 컷신이 아니에요. 카메라는 그대로고, 아이는 계속 헤엄쳐요.
3. 헤엄치면 바퀴가 나타나요. 줄어드는 호를 보며 '숨'이라는 걸 알아요.
4. 부표 줄 A 끝에 깃발 단 뗏목 R1이 모래사장에서 보여요. 세상 안 단서예요. 아이콘이나 빨간 선은 쓰지 않아요.
5. 뗏목에 올라 1초 서 있으면 뗏목 기둥의 도장함이 「꾹」 소리를 내요. 바퀴 호가 하나 더 그려져요. 수첩 일지에 한 줄이 남아요.

### 4-2. 다 써서 못 갔을 때
1. 누워 뜨기 자세로 떠난 발판 쪽으로 천천히 떠밀려요. 바퀴는 회색 빈 호로 보여요.
2. 10초 뒤 망루에서 안전요원 배가 나와 다가와요. 태워서 모래사장으로 가요. 그 사이 화면에 「구조 요청은 손을 흔들어요」 한 줄이 떠요.
3. **같은 길에서 두 번 다 쓰면**, 그 근처 몸 있는 이웃(모래사장은 안전요원, 산은 등산객)이 한 번 말해요.
   - 길마다 하루 한 번만 말해요.
   - 예: 「숨이 금방 차네요. 뒷산 바위에서 밧줄을 타 본 사람들은 숨이 길던데요.」
   - 정확한 자리 대신 **랜드마크 이름 하나**만 말해요. 방위·빨간 선·아이콘은 쓰지 않아요.

### 4-3. 오르기 자리의 단서
- 오르기 길마다 **등산객(이름 없는 역할 · 몸 있음)**이 가끔 매달려 오르는 모습이 보여요. 산 이웃 일과와 이어져 있고, 맑은 낮에만 나와요.
- 밧줄 밑동에는 나무 팻말이 있어요: 「밧줄 길 — 꼭 잡고 천천히」.
- 꼭대기 도장함은 실제 등산로의 스탬프 함 모양이에요.

### 4-4. 패러글라이딩 체험장
1. P1 뒷산 전망대에 **체험장 강사(직함만 · 몸 있음)**가 서 있어요. 옆에는 바람자루가 있어요. 강사에게 다가가 E로 말을 걸면 한 줄 말해요: 「바람자루가 날리는 쪽의 반대가 바람이 오는 쪽이에요. 바람을 마주 보고 달려요.」
2. 아이가 직접 띠 위에서 W를 눌러 달려요. 날개가 서고 떠요. 강사는 같이 타지 않아요(컷신 X). 첫 비행 중에는 착지 그림자가 보여요.
3. 내리면 수첩에 「패러글라이딩 체험을 했어요」가 남아요(`S.stam.para = 1`). 그 뒤로 P2·P3는 혼자 써요. P2에도 강사 한 명이 서서 바람 한 줄만 말해요.
4. 뒷바람 띠에 서서 달리면 날개가 서지 않아요. 바람자루가 보이고 한 줄이 떠요: 「바람이 뒤에서 불어요 — 반대쪽 띠로 가 봐요」. 반대쪽 띠는 늘 열려 있어요.
5. 비행 중에는 그 시각의 마을이 그대로 내려다보여요. 장날 장터, 버스, 해 질 녘 불 켜진 창이 보여요.

## 5. 엔진이 저절로 만드는 '우와' 셋(ENGINE-1)
1. **같은 정상, 날마다 다른 비행**: 하루 바람(WIND-1)에 따라 오늘은 동쪽 띠, 내일은 서쪽 띠에서 떠요. 바람에 밀려 날마다 다른 들판에 내려요. 아무도 그 착지 자리를 써 두지 않았어요.
2. **센 바람 날 더 멀리**: 같은 P2에서 떠도 센 바람 날(`umbStrong`)에는 바람 쪽으로 더 멀리 가요. 평소엔 닿지 않던 마을 끝 들판에 내려요(바람에 밀림 1.0m/s × 약 200초 ≈ 200m 차이).
3. **하늘에서 본 마을 엔진**: 비행 중에 이웃 하루 일과·장날·버스·밤 창문이 그 시각 그대로 보여요. 날마다 다른 풍경이에요.

만든 사람이 써 둔 결과도 있어요. 칸이 늘어 어제 못 가던 바위섬에 닿는 것이에요. 이건 사다리의 보상이고, 위 셋과 따로 세요.

## 7. 저장 꼴
```js
GAME.S.stam = {
  v: 1,
  n: 3,                    // 지금 칸(3~10)
  got: { R1: 12, C1: 14 }, // 도장 id → 받은 게임 날(평생 한 번)
  para: 0,                 // 첫 체험 했나
  fail: { R2: [15, 2] },   // 길 id → [날, 그날 다 써서 실패한 수]
  said: { R2: 15 },        // '숨이 차요'를 말한 날(길마다 하루 한 번)
  tip: { swim: 1, umb12: 15, hold: 0 }  // 처음 한 줄·하루 한 번 줄
}
```
- 저장(`GAME.mark()`)은 도장·실패·첫 체험 때만 해요. 매 프레임 localStorage는 쓰지 않아요.
- 남은 바퀴 양은 저장하지 않아요. 새로 열면 다 찬 채로 시작해요.
- **칸 +1은 보상 문(rwCheck) 밖이에요.** 이야기 보상처럼 평생 한 번 꼬리표(`S.stam.got[id]`)로만 막아요. 그래서 실제 날짜 하루 총량에 걸려 문이 잠기는 일이 없어요.
  - 같이 주는 덤 솜씨는 `skUp('explore', 1, 'stam:<id>')`로 문을 지나요. 하루 한도는 `RW_XP`의 기본 3을 따라요.
- 옛 저장에 `stam`이 없으면 `{ v:1, n:3 }`으로 시작해요. 이미 걸어서 받은 ⛰ 정상 도장은 칸을 주지 않아요.

## 10. 사실 근거(이웃 말·수첩에 쓰는 것만)
- **체력은 꾸준히 몸을 쓰면 늘어요**(체육: 건강 체력 — 심폐지구력·근지구력). 게임에서는 '끝까지 해낸 만큼'으로 보여 줘요. 칸 수치는 놀이 크기예요.
- **누워 뜨기는 힘을 아끼며 물에 떠 있는 생존수영 기술이에요.** 초등학교 생존수영 교육에서 배워요. 구조를 기다릴 때 손을 흔들어 알려요.
- **바다 수영은 부표 안에서, 안전요원이 있는 곳에서 해요.**
- **패러글라이더는 바람을 마주 보고 달려 이륙해요.** 날 수 있는 거리는 출발 높이·활공비·바람이 정해요. 체험 비행은 강사와 함께 정해진 체험장에서 해요.
- **우산으로는 사람이 날 수 없어요.** 게임에서도 낮은 턱에서 천천히 내려오는 것까지만 하고, 「놀이에서만! 진짜로는 다쳐요」 줄은 그대로 둬요.
- **암벽·바위 길은 쇠사슬·밧줄·발판이 있는 정해진 길로만 다녀요**(등산로 안전 수칙).
- 바람자루는 바람이 불어 가는 쪽으로 날려요. 그래서 반대쪽이 바람이 오는 쪽이에요(방위 읽기).
