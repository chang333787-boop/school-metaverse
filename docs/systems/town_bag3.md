## 1. 지금 무엇이 문제인가(고치기 전 사진 `bag3_before_*`)
- 가방(I) 한 창이 길게 내려감 — 요리 · 먹거리 · 재료 · 군것질 · 일한 보람 · 주운 것 · 도장 → 맨 아래 👕 옷·장비(카드 열여섯 줄) · 데스크톱에서 세 번 내려야 옷이 나옴.
- 위 탭 줄에 가방·이야기·꾸러미·일기·앨범(수첩 것)이 섞여 '가방 갈래'로 읽힘.
- 도구 1~5는 화면 아래 띠에만 있고 가방엔 없음 · 망원경·튼튼한 낚싯대는 '장비 카드'로 따로 나와 도구가 둘처럼 보임.
- **빠지는 물건**: 가게에서 산 기념품·놀이 도구(👕 티셔츠 · 🧢 · 🔑 · 🧸 · 🧩 · 🔳)와 마당 물건 보상(🌻 🏺 🎐) = ITEMS 갈래 'goods'인데 가방 갈래 표에 없어 **가방에 아예 안 보임**(산 것이 사라진 것처럼).

## 2. 갈래 표(모든 물건이 꼭 한 갈래)
| 탭 | 들어가는 것(자료 → 갈래) | 화면 |
|---|---|---|
| 🎒 물건 | ITEMS 갈래 dish · food · cook · treat · wild · farm(엽서·심은 모·양털) · ITEMS에 없는 글자(예전처럼 food로) | 네모 칸 격자 + 거르기 칩(전체 · 요리 · 먹거리 · 재료 · 군것질 · 주운 것) + 정렬 · 칸을 누르면 크게 보기 카드 |
| 🧰 도구·장비 | 도구 여섯(`TOOL_ORDER`) — 업그레이드 넷은 그 도구 카드 안(큰 물통 → 💧 · 튼튼한 낚싯대 → 🎣 · 넓은 빗자루 → 🧹 · 망원경 장비 = 🔭 도구) · 장비(목장갑 · 도시락통 · 장화 · 장터 수첩 · 등산화 · 이마 전등 · 수통) · 자리(내 좌판 · 두 칸 더 = 좌판 카드 안) · 씨앗(딸기 모종 · 사철 씨앗) · 태풍 준비물(끈 · 모래주머니 — 있을 때만) | 카드마다 '쓰임' 한 줄 · 켜짐 · 이마 전등만 켜기/끄기 · 아래 **도구 띠 1~6** |
| 👕 옷·꾸미기 | 보상 hat · scarf · bag · bike · flag(쓰기/벗기 · 갈래마다 하나만) · ITEMS 갈래 goods(마당 장식 · 기념품) | 옷 카드 격자 + 마당 장식 네모 칸(누르면 크게 보기 · 🏡 마당에 놓기) |
| 🏅 모은 것 | ITEMS 갈래 stamp · 보상 badge · nick(이웃이 부르는 이름 고르기) · recipe(받은 요리법) | 도장·배지 네모 칸 + 칭호 단추 줄 + 요리법 + 📖 도감 바로 가기 |

- 보상 deco(🌻 🏺 🎐)는 받으면 가방 글자(goods)가 되므로 👕 마당 장식 칸 하나로만(마당에 놓으면 가방에서 빠짐 = 마당에 있음).
- 수첩 탭(가방 · 할 일 · 이야기 · 꾸러미 · 일기 · 앨범 …)은 창 맨 위 **「📒 수첩」 줄**(작은 탭 · 휴대폰은 옆으로 밀기) — 가방 갈래 탭 넷은 그 밑 **큰 폴더 탭 줄** · 같은 줄에 섞지 않음.
- 전수 시험: 가방 글자 + 가진 도구 + 가진 보상(deco 뺌) = 화면의 `data-b3` 낱말을 모두 모아 **각각 정확히 한 번**(`town_bag3.cjs` ②).

## 4. 열 요소 — 어떻게
| # | 요소 | 하는 법 |
|---|---|---|
| ① | 인형 + 장비 칸 | **새 WebGL 컨텍스트 X** — 지금 렌더러(`SD2.renderer`)로 진짜 내 캐릭터를 4×… 작은 그림판(WebGLRenderTarget 300×400)에 한 번 그림(장면의 다른 것은 잠깐 숨김 · 빛은 그대로 = 새 셰이더 X · 그림자 굽기 끔 상태 유지) → 화소를 읽어 2D 캔버스에(sRGB 바꿈 + 밝기 맞춤) · **창을 열 때 + 입은 것이 바뀔 때만**(모습 서명 캐시) · 칸 = 머리(모자) · 목(목수건) · 등(가방 색) · 손(든 도구) · 발(장화·등산화) — 누르면 그 탭·그 묶음으로 |
| ② | 네모 칸 격자 | 같은 크기 64px(휴대폰 ≥56) · 빈 칸도 그림(줄을 채우고 최소 네 줄) · ×n 오른쪽 아래 |
| ③ | 크게 보기 카드 | 큰 그림 · 이름 · 갈래 · 쓰임(BAG-2 쓸 곳 줄 — 들은 '좋아하는 이웃'만) · 단추 = 😋 먹기(`data-eat`) · 🍽 나눠 주기(`data-share`) · 🎁 선물(`data-gift` · 곁에 일꾼) · 🛒 팔기(장터 상인 곁 → 장터 창) · 🏡 마당에 놓기(우리 집 마당 곁 → 마당 창 · 멀면 길 안내) · 🧪 실험(LAWS-1) |
| ④ | 도구 띠로 끌어 놓기 | 🧰 탭 아래 도구 띠 1~6(화면 아래 띠와 같은 모양) · 마우스 = 카드를 끌어 칸에 놓기 · 터치·키 = 카드의 「띠에 놓기」 → 칸 누르기(또는 1~6) · 놓으면 두 칸이 바뀜 · 저장 `S.tools.ord` · 숫자 키·아래 띠가 그 차례 |
| ⑤ | 어디서 났나 꼬리표 | `GAME.add`가 받을 때마다 `S.bag3.o[글자] = [x, z, 날, 차례]`(종류마다 마지막 하나 · 실내면 그 건물 문 자리) · 되돌림(mv:deco · cook · fridge · undo)은 안 바꿈 · 카드에 "📍 동네 이름 · n일째"(바다·갯벌 🌊 · 산 ⛰ · 들 🌾 · 강 🏞 · 학교 🏫) · 누르면 카드 안 지도 조각(mapSnip — 얻은 곳 + 나) |
| ⑥ | 새로 얻은 것 점 | `S.bag3.seen` — 없던 것이 생기면(가방 0 → 1 · 새 도구·보상) 칸과 탭에 빨간 점 · 그 탭을 한 번 보면 저장에서 지움(이번 창이 열린 동안은 칸 점 그대로 — 무엇이 새것인지 보이게) |
| ⑦ | 정렬 | 종류별 · 얻은 순(차례) · 값 순(ITEMS 값) — 🎒 탭 · 이 기기에 기억 |
| ⑧ | 효과 숫자 | 인형 밑 「지금 켜진 효과」 한 줄씩(목장갑 오르기 +35% · 등산화 오르막 숨 ½ · 수통 숨 돌아옴 1.5배 · 도시락통 먹은 힘 1.5배 · 장화 갯벌·논 안 느려짐 · 큰 물통 물 2배 · 튼튼한 낚싯대 14m · 넓은 빗자루 3m · 이마 전등 밤 · 먹은 힘 n시까지) — 코드의 실제 수만 · 싸움 능력치 X |
| ⑨ | 작은 소리 | 칸에 놓을 때 '톡'(삼각파 한 음) · 입을 때 '착'(짧은 두 음) · 탭 바꿀 때 아주 작은 딸깍 · 튀는 움직임 X(누르면 2px 내려감만) |
| ⑩ | 키보드 | I = 열기·닫기 · ←→ = 탭 · Esc = 닫기 · Enter = 손이 간 칸 누르기(CTRL-1 그대로) · 띠 고르기 중 1~6 · 마우스·터치 둘 다 |

- 이야기 단계가 give · sell · have · cook · law · buy면 🎒 탭으로 열림(law = 그 물건 카드가 열린 채) · tool 단계 = 🧰 · 곁에 일꾼(선물 가능)이면 🎒 · 그 밖엔 마지막 탭(이 기기 localStorage `sm-bag3-ui`).
- 곁에 일꾼이 있으면 🎒 탭 맨 위 「🎁 곁의 ○○ 일꾼에게 주기」 줄 = 줄 수 있는 것마다 큰 🎁 단추(`data-gift` · 💖 들은 좋아함) — GIFT-3 코치 줄 '② 아래 🎁 줄에서 고르면 곁의 일꾼에게 줘요' · 상인 곁 = 단추 없음 + '장터 상인은 사고팔기만'(SHARE-1 그대로).

## 5. 저장 꼴(옛 저장 그대로 읽힘)
- 새 칸 `S.bag3 = { v: 1, o: { 글자: [x, z, 날, 차례] }, seen: { 낱말: 1 }, n: 차례 }` — 모듈 칸 결(`bag2`·`rwd`와 같음 · SAVE_V 그대로). 옛 저장(칸 없음) = 마을을 지을 때 한 번 만들며 **지금 가진 것을 모두 본 것으로**(점 홍수 X) · 꼬리표는 그 뒤 얻는 것부터.
- `S.tools.ord` = 도구 차례(여섯의 순열이 아니면 기본 차례로 · 옛 저장 = 기본).
- 탭·거르기·정렬 = 이 기기(localStorage) — 저장에 안 넣음.
