# 🔁 '이상해' 목록 — 다시 안 생기게(LESSONS-1)

사용자 10-17: "내가 뭔가 이거 이상해 하면 다시 그게 생기지 않도록 다음 작업에서는 신경 써 주면 좋겠어, 지금까지 말했던 것들 모두 다"

**쓰는 법**
- 마을(오픈월드) 일을 시작하기 전에 이 표를 먼저 본다. 하위 에이전트에게 일을 줄 때도 "town_lessons.md를 먼저 읽고 지켜라"를 지시문 첫 줄에 넣는다.
- 사용자·교사·아이 눈 테스트가 '이상해'라고 하면 **그날 바로 이 표에 한 줄**(들은 말 · 무엇이 문제 · 규칙 · 확인 방법)을 더한다.
- push 전 마지막 점검 = 이 표의 '확인' 칸을 훑기. 자동 확인이 있는 줄은 그 검사를 돌린다.
