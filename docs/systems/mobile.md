# 휴대폰·터치·아이폰

> CLAUDE.md에서 옮긴 정본(10-10 — 줄은 그대로). **언제 읽나**: 터치 UI·phone.css·휴대폰 배치·아이폰 사파리·떨림을 고칠 때. 늘 지킬 규칙(개인정보·홍보판·이모지·캐시·게이트·NPC)은 CLAUDE.md에 있다.

### 터치 조작 (TOUCH-1 · 09-26 "스마트폰으론 못 보네")
- **코드 = `v2/js/touch.js`**(`createTouch`·`touchPrimary`) + main.js 연결부(`TOUCH` — `physics`의 아날로그 이동·점프, `hotTick`의 `TOUCH.setNear`, 캔버스 클릭 포인터 잠금은 터치면 안 함). 키보드·마우스 동작은 그대로.
- 켜짐: `(pointer: coarse)`이고 고운 포인터 없음, 또는 화면을 처음 터치한 순간 → `body.touch`. 그 전엔 터치 UI가 `display:none`(데스크톱 화면 변화 0).
- 왼쪽 45%(위 30% 제외) = 엄지 자리에 뜨는 조이스틱(`TOUCH.mx·my·m` — 키를 안 누를 때만 · 걷기 30~100%, 가장자리 ≥0.92 = 달리기) · 나머지 드래그 = 시점(yaw 0.0058·pitch 0.0042 rad/px) · 손가락은 identifier로 따로. 버튼: 점프(누르는 동안 = Space)·✋행동(= E, 할 것이 있으면 노랗게)·👁시점(= V).
- 터치면 시간·🎮놀이 칩은 왼쪽 위 📍 아래 줄, 도움말·fps 칩 숨김, 게임 칩은 미니맵 아래에 안 들어가면 미니맵 왼쪽(mapapi `layoutChips`). 세로면 '가로로 돌려 주세요'(글자만).
- **휴대폰 성능 판**(`SD2.gfx`): 터치 주 입력·짧은 변 ≤500 → mobile(픽셀 비율 ≤1.5·그림자 지도 1024) · 저사양(deviceMemory ≤3 또는 코어 ≤3) → low(≤1.25·그림자 끔) · `?hq=1` 데스크톱 품질 강제 · `?lq=1` low 강제.
- 손가락 상태는 창 blur·숨김 때 `reset()`, 끝 이벤트를 잃은 id는 다음 touchstart에서 버린다(끝없이 걷기 방지). 조이스틱 판은 화면 안으로 당기지 않는다(가장자리 누르자마자 달리던 문제). 터치 화면 크롬북은 진짜 마우스(pointerType 'mouse')·키를 쓰면 `disable()` → 데스크톱 화면·포인터 잠금으로 돌아간다(터치 주 입력 기기는 제외). 터치면 작은 미니맵이 버튼 위까지만 커진다(minimap `size`).
- 매 프레임 일 없음(이벤트 때만). 터치 UI를 고치면 main.js의 `touch.js?v=`와 index.html `main.js?v=`를 올린다.
- **유튜브 맨 위층(YT-FLOAT · 10-04 교사 아이폰 사진 — 영상 왼쪽 검은 띠·오른쪽 잘림)**: 아이폰 사파리는 상자(스크롤·둥근 잘라내기·transform) 안 유튜브 영상을 어긋나게 그린다 → 견학 영상 창(tour.js)·오프닝 영상 조각(film.js) 모두 iframe을 body 맨 위층 `position:fixed`(class `yt-float ttl-keep`)에 두고 창 안 영상 자리(holder)를 프레임마다 따라감(holder가 사라지면 같이 지움 · 투명도도 따라감). 유튜브 iframe을 새로 넣을 땐 이 방식으로(상자 안에 넣지 않는다).
- **홍보판 = QR로 학부모가 휴대폰으로 봄 → 휴대폰 최적화가 최우선**(교사 10-04 · v2·v3는 수업용).
- **아이폰 실측 전수 점검(MOB-3 · 10-04 교사 '휴대폰 다 알아서 찾고 완성 · 핸드폰 앱 개발자처럼')** — Xcode 27 + iOS 27 시뮬레이터 + Appium(스크래치 · 사파리 세션 · WDA 포트 8111 — 8100은 다른 파이썬 서버) · 시험 서버 = 저장 안 하는 8002(사파리가 홍보판의 옛 phone.css?v=12를 붙잡고 있었다) · 장면마다 겹침·가려짐(elementFromPoint)·화면 밖·12px 미만 글자를 수치로 0. 찾아 고친 것: ① **CSS :has()가 아이폰 사파리에서 '맞다'면서도 적용 안 됨** → `HAS-1`: main.js가 창이 열려 있으면 body에 `h-<이름>` 꼬리표(tour-talk·tour-media·tour-card·story-talk·story-end·memo-*·eng-note·esc-lock·hudAsk·lb-pop·wg-lobby·mm-ov) · phone.css·title.css는 :has 대신 꼬리표(**:has() 새로 쓰지 말 것**) ② **아이폰 가로 + viewport-fit=cover = 재생 중인 유튜브만 노치 여백(≈60px)만큼 밀림 · 글자가 다이내믹 아일랜드에 가림** → `SAFE-1`: 아이폰은 실행 때 viewport meta에서 cover를 뺌(양옆 = 어두운 여백 #0b1220) ③ 가로 화면 높이 = 사파리 주소창·탭 줄 빼고 290~340px → `LAND-1`: 휴대폰 가로는 게임 칩을 미니맵 왼쪽·목표 줄 아래 가로 한 줄 + 짧은 글('📖 1/15' · mapapi `shortChip`·`rowMode`) · `LAND-2`: 대화·영상·사진·자세히·도감·큰 지도가 열린 동안 HUD 숨김 · 사진·영상·자세히 창 = 화면 전체 · 세로 선택 목록 한 줄 칸 · 영상 글 덩이(R·A·S·끝 화면·갈래 글) 낮은 화면용 크기 · 모든 글자 ≥12px ④ 아이폰은 전체 화면 API가 없다(iOS 27 확인) → `A2HS`: '홈 화면에 추가'용 meta·아이콘을 실행 때 붙이고 첫 화면에 안내 한 줄(안드로이드는 첫 터치 전체 화면). 시험 도구 = 스크래치 appium/qa.cjs·s3.cjs(HUD·창)·s4.cjs(영상) — 시뮬레이터 손가락 좌표는 도구가 64px 어긋나므로 흐름은 click, 가려짐은 elementFromPoint로 잰다.
- **휴대폰 정석 점검(MOB-2 · 10-04 교사 '핸드폰용 정석·주의점대로 최적화 · 사파리 소리 안 남')**: ① 캔버스 = CSS로 늘 화면을 채우고(`renderer.setSize(w,h,false)`) 그리는 해상도만 `fitView`가 따라감(resize·visualViewport·돌림·ResizeObserver·1초 — 아이폰 주소창이 줄면 아래가 비던 것) ② 아이폰·아이패드는 저사양 판정 안 함(사파리가 메모리·코어를 감춤 · `GFX.ios`) ③ 휴대폰 자동 해상도 바닥 1배(0.6배 = 뿌옇고 계단) ④ 휴대폰도 MSAA ⑤ 소리 = 누를 때마다 `audioUnlock`(AudioContext 깨우기 + 빈 소리 · `navigator.audioSession.type='playback'` = 무음 스위치여도 동영상처럼) ⑥ WebGL 컨텍스트 잃음 = 알림 후 다시 불러옴 ⑦ 견학 영상 창(유튜브)이 열린 동안 3D는 1초에 4번(`SM_HOLD3D`) ⑧ 안드로이드 = 처음 화면을 누르면 전체 화면 + 가로 고정(아이폰 사파리는 미지원) ⑨ `-webkit-text-size-adjust:100%`(아이폰 가로 글자 키움) ⑩ 손가락 시점 프레임 동기(SHAKE-1) ⑪ 유튜브 맨 위층(YT-FLOAT). 실제 아이폰 확인은 교사(이 맥엔 Xcode·WebKit 없음).
- **떨림·멀미(SHAKE-1 · 10-04 교사 '폰으로 하면 계속 떨리고 멀미')**: 손가락 시점은 터치 신호마다 바로 돌리지 않고 `TLOOK`에 모았다가 `mouseApply(dt)`가 프레임마다 부드럽게(1−e^(−40dt)) — 휴대폰은 신호 박자 ≠ 화면 박자라 프레임마다 도는 양이 들쭉날쭉했다(흉내 시험: 프레임별 변동 37% → 13%). 휴대폰도 MSAA 켬(타일 GPU라 싸다 — 가장자리 지글거림이 걸을 때 떨림으로 보였다 · 저사양 `low`만 끔 · `?aa=0`). 영상(film.js)은 카드 뒤 흐림(backdrop-filter)·화면 색 필터를 뺐고(휴대폰에서 매 프레임 3D를 다시 흐려 떨림) 시계 = `document.timeline.currentTime` · 휴대폰 디테일 거리 100m · 유튜브 조각은 iframe 크기 그대로 + `scale(1.22)` 확대(아이폰은 칸보다 큰 iframe을 옆으로 밀었다).
- **휴대폰 배치(MOBUI-1 · 09-27 "핸드폰에서 지도가 다 가려")** — 장치는 하나: touch.js가 `body.touch` + `body.small`(터치이고 짧은 변 ≤500px = 휴대폰 · 태블릿은 .touch만)을 켜고, 휴대폰 모양은 전부 **`v2/phone.css`**(index.html `<link>` · 고치면 `phone.css?v=`)가 준다 — 데스크톱은 두 클래스가 없어 변화 0. 안전 구역: 왼쪽 위 📍 + 아이콘 칩(☀️ 🎮/⏹ — 글자는 `.lbl`로 숨김) · 가운데 위 목표 한 줄(`#hudGoal` 말줄임) → 물총 칸 → 알림 · 오른쪽 위 미니맵 조각(`#mmap.mm-th` 64~88px, 누르면 가운데 덮개 `.mm-ov` + 어둡게 `#mm-dim` + ✕ · 바깥 누르면 닫힘 — 덮개는 태블릿도) + 그 밑 게임 칩(`.gchip` · 키 안내 '(H)'는 뺀다 — mapapi `chipText`) · 왼쪽 아래 조이스틱만 · 오른쪽 아래 점프·행동·시점 한 줄(오른쪽 12·90·158px) + 게임 버튼은 행동 위(💧 right 92·bottom 92 — 새 버튼도 이 줄 왼쪽(≈ right 216) 또는 위 칸에). 견학 이야기 = 아래 시트(≤46%) · 도장 카드 = 전체 화면(✕ 고정) · 놀이 고르기 = 스크롤. 노치 = `env(safe-area-inset-*)`. 글자 `clamp()` · 12px 미만 금지. 게임 파일에 휴대폰 CSS를 따로 넣지 말고 phone.css에 id/class로 더한다. 리뷰(09-27): 터치에서 누르는 게임 칩(`hud.chip` opt.onClick → `.gtap`)은 44px 칸 + 투명 누름 자리 · ☀️/🎮 칩·✕도 44px · 휴대폰의 `#hint`·`#toast`는 글자만(pointer-events 없음 — 조이스틱 자리를 막지 않게, 같은 일은 ✋ 버튼) · 견학 이야기 창이 열린 동안 버튼·조이스틱 표시는 숨김 · 세로 화면은 목표 줄·물총 칸·알림을 칩 줄 아래로. 합치기(integ2 · 09-27): 엔진 ⬇ 웅크리기 = 버튼 줄 👁 왼쪽(right 222 · 세로 화면은 조이스틱 자리와 겹쳐 점프 버튼 위) · 가방 `.eng-inv` = 아이콘 칩 줄 밑 · 쪽지 `.eng-note`·자물쇠 `.esc-lock`·보기 창 `.hudAsk`가 떠 있는 동안 버튼·조이스틱 표시·안내 숨김(`:has`) · 자물쇠 창 = 왼쪽(목표 줄 밑 · 그동안 📍·☀️·🎮 숨김) — 전부 phone.css. 물총 팀 대결(G3-WG 09-27): 알림 줄 `.wg-feed` = 왼쪽 위 아이콘 칩 줄 밑(글자만 3줄) · 점수판 `.wg-board` = 가운데 · 휴대폰은 점수·시간을 한 칩(칩 줄이 💧 버튼에 닿지 않게).
