## 2. 수업 전
1. 저장소 폴더에서 `zsh tools/ops/core.sh`. 20~25분 걸려요(다른 시험을 같이 돌리면 더 걸려요). 끝 줄이 `통과 20 / 전체 20`이고 `DONE`이면 돼요. 떨어진 시험은 이름이 나오고 기록은 `/tmp/sm-core/<이름>.log`에 남아요. `town_cloud`만 떨어지면 인터넷이나 방 서버부터 봐요.
2. 배포 주소에서 3분 걸어 보고, 마을 주소에서 「이어하기」가 되는지 봐요.
3. 콘솔(F12)에서 `SD.perf()`의 fps가 30 이상인지, `SD.diag()`의 `crashes`가 0인지 봐요.
4. 크롬 탭을 줄여요. 다른 탭이 메모리를 먹으면 이 탭이 먼저 죽어요.

## 4. 비밀번호(값은 어디에도 적지 않아요)
- **선생님 비밀번호**(숫자 넷 · 선생님 칸·메모장·블록·함께하기 방이 같은 것)를 잊었을 때: Firebase의 `metaverse/memoPin` 칸을 지우고 `v2/?game=memo&setpin` 주소로 열어 다시 정해요. 규칙이 '한 번만 쓰기'라 지울 때는 규칙을 잠시 풀어야 해요. 세 번 틀리면 그 탭은 1분 쉬어요.
- **교사 열쇠**(반 표 ☁️ 서버 · 6~32자)는 반 코드를 아이에게 주기 **전에** 선생님 칸 → 반 표 → ☁️ 서버에서 먼저 정해요. 잊으면 방 서버에 관리 열쇠 `ADMIN`을 넣어 둔 때만 바꿀 수 있고, 아니면 새 반 코드로 옮겨요. `ADMIN`을 넣었는지는 **확인 필요**.

## 6. 고친 뒤 올리는 차례
1. 바꾼 파일만 `git add <파일>`(`git add -A`는 쓰지 않아요) → `python3 tools/ops/bump.py .`로 캐시 번호 → `git add -u`.
2. `zsh tools/ops/core.sh`(고친 기능만 볼 때는 `zsh tools/ops/gm.sh . 8821 "<하네스 이름>"`).
3. 커밋 → `git fetch origin && git rebase origin/main` → `git push origin HEAD:main` → 1~2분 뒤 새로고침.
4. 공개판: `zsh tools/export/town_export.sh /Users/dobuk/Projects/uri-maeul --commit "…"` → `git -C /Users/dobuk/Projects/uri-maeul push`.
