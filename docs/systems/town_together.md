# 👥 마을 함께하기 규칙(TOGETHER-1 · 10-18)

사용자 10-18: "함께하기 모드 하면 여러 가지 변수가 많을 것 같아 — 날씨·환경도 있고 퀘스트도 있고" · "함께하기 규칙 치밀하게 정해 — 기존 게임들이 함께하기 규칙이 좋지 않아서 좀 별로였던 것 같아 · 이거는 제대로 정하고 진행해"

먼저 `town_lessons.md`를 지킨다. 이 문서는 수업(한 반 20~30명 · 크롬북 · 선생님 한 분)을 기준으로 한다.

## 0. 다른 협동 게임이 별로였던 까닭 → 우리 규칙
| 흔한 실패 | 왜 별로인가 | 우리 규칙 |
|---|---|---|
| 친구마다 날씨·시간이 다름 | 같은 세상에 있는 느낌이 깨짐 | **세상 시계는 방에 하나**(§2) |
| 방장이 나가면 세상이 끝남 | 한 아이 때문에 모두 멈춤 | 세상 상태는 **방 문서**에 있음 — 누가 나가도 그대로 |
| 진행은 방장만 남음(손님은 남는 게 없음) | 손님 아이는 의욕이 없어짐 | **진행은 모두 각자 저장**(§3) |
| 한 사람이 창·컷신을 열면 모두 멈춤 | 기다리다 지루함 | **다른 사람을 멈추게 하는 건 선생님뿐**(§6) |
| 몸으로 문을 막기·밀기·가두기 | 괴롭힘 | 친구 몸은 **부딪히지 않음**(유령) · 카메라 앞이면 옅어짐 |
| 물건·돈 빼앗기, 남의 것 부수기 | 다툼 | 남의 물건을 가져가거나 부수는 길이 **아예 없음** · 주기는 받는 쪽 동의(§5) |
| 자유 채팅 | 욕·놀림 | **정해 둔 말·이모트만**(SAFE-1 · chatfilter) |
| 화면에 친구가 너무 많아 어지러움·렉 | 수업 30명 | **가까운 10명만 몸 · 나머지는 지도 점** · 이름표는 가까이서만 |
| 중간에 들어오면 꼬임 | 늦게 온 아이가 헤맴 | 들어오는 순간 방 시계·날씨·반 결정을 받아 맞춤(§7) |
| 인터넷이 끊기면 진행이 날아감 | 수업 망침 | 끊겨도 **혼자 모드로 계속**, 다시 이어지면 맞춤(§7) |

## 1. 방
- **방 만들기:** 선생님만(선생님 비밀번호). 방 코드 넷째 자리까지. 수업 방 = 반 하나.
- **첫 화면 두 갈래(TITLE-2 11-14):** 마을 첫 화면 [👥 같이하기] → [🏠 방 만들기](방장 = 만든 아이 · 2시간 · 번호 4자리 크게) / [🚪 방 들어가기](열린 방 목록 → 이름 + 번호) · 작은 🔒 선생님 방 — 들어가면 내 판(지금 칸)으로 이어하기(저장 없으면 하는 법 한 장 → 처음부터) · 방 칩 「👥 ○○ 방 · n명 · 내가 방장」 · 마을 방 창엔 학교 놀이 대기실 X · 정본 `town_open.md` 6절.
- **들어오기:** v4 로그인 번호로 들어옴(이름 X · '○번'). 같은 번호가 두 기기에서 들어오면 나중 것만 남김.
- **크기:** 30명까지(무료 동시 연결 100 안). 새 연결(스트림)은 열지 않고 방 통로 `rooms/<방>` 하나에 얹음(NET-2).
- **방 문서:** `{ seed, clock: { t0, day0, min0, speed, paused }, wx, season, fixes, vote, event }` — 선생님만 씀, 모두 읽음.(처음 설계 · 아직 안 지음)
- **방장 시계(HOST-1 · 교사 11-14 '같이하기 할 때는 시간 같은 거는 방장 기준으로'):** 시계·날씨·계절은 방 문서 대신 **시계 주인 기기**가 알림 — 방장(방을 만든 기기 · 아이 방 = 🧒 방장 · 선생님 방 = 선생님 기기)이 마을에 있으면 방장 · 없으면 먼저 들어온 친구. 자세한 규칙 = 아래 「HOST-1」.

## 2. 세상(모두 같이) — 방 문서가 정함
| 무엇 | 규칙 |
|---|---|
| 시간 | **방장 시계(HOST-1)** — 시계 주인이 10초마다 + 바뀔 때 시각(분)을 알리고 각자 기기가 서버 시각으로 흐른 만큼 셈 · 바꾸는 것(잠·기다리기·쉬기·시계 멈춤)은 방장만 · 방장 시계가 멈추면 모두 멈춤 |
| 날씨·예보 | **그날 날씨 = 시계 주인 것**(손님 판엔 '그날 정한 날씨'로 얹음 · 손님 저장의 예보·날씨 고정은 그대로) · 방장이 선생님 모드로 '오늘은 비' 하면 모두 비 · 손님의 날씨 단추 = 「방장만」 |
| 계절 | **시계 주인 것을 보기만**(손님 달력은 그대로 · 방을 나간 다음 아침부터 내 달력) |
| 장날·마을 사건(불 등) | `seed` + 날짜로 같은 날 같은 곳 · 불은 **함께 끄는 것**: 불 세기 하나를 모두 줄임 → 꺼지면 참여한 모두에게 '함께 껐어요' + 배운 개념 |
| 반이 정한 마을 변화(QUEST-2 지역 문제) | 함께하기에선 **반 투표 결과**를 모두 같이 봄(`fixes`) · 선생님이 투표 열기·닫기 · 혼자 할 땐 내가 고른 대로 |

## 3. 나(각자) — 절대 주고받지 않음
이야기 진행 · 가방 · 돈 · 솜씨·승급 · 도감 · 여권 · 수첩 · 학급 기록 · 내 마당 꾸미기. 친구와 다른 장을 해도 됨. 방을 나가도 그대로.

## 4. 함께하기에서 막히는 것·바뀌는 것
| 혼자일 때 | 함께하기 |
|---|---|
| 잠 → 다음 날 | **방장이 자면 모두 아침**(손님 판도 그 밤을 지남 = 손님 GAME.sleep 한 번 · 밭이 자람·하루 몫이 새로 · 손님 n일째 +1 · 집으로 X · 그 자리에서 짧게 어두워졌다 밝아짐 · 「🌙 방장이 잠들어서 아침이 됐어요」) · 손님 잠·쉬기 = 「⏰ 방장만 할 수 있어요」 · 손님 n일째를 방장 날짜로 바꾸지 않음(§3) |
| 날씨·계절 칩으로 바꾸기 | 칩은 보기만(시계 글 뒤 「⏰방장 시계」 · 먼저 온 친구가 이어 받았으면 「⏰방 시계」 · 멈춤이면 ⏸) · 바꾸기는 방장 기기(선생님 모드) |
| 이야기 '밤·비·계절 기다리기' | 손님 = 방장 시계를 따름(기다리기 단추 자리 = 「🌙 방장 시계로 밤이 되면 해요」 · 누를 수 없음) · 방장 = 기다리기 그대로(모두의 시계가 2초쯤에 걸쳐 따라감) |
| J 바로 가기 | 그대로(내 몸만) · 선생님 '모이기' 중엔 막힘 |
| 실내 방 | 각자(친구는 안 보임) · 문 위에 "○번이 안에 있어요" 표 |
| 버스·지하철·배 | 각자 탐(친구는 안 보임) · 내리면 다시 보임 |
| 일 놀이·미니게임 | 각자 · 같은 일꾼에게 둘이 오면 **두레**(둘이 번갈아·같이 당기기 — 따로 만듦) |

## 5. 친구끼리 할 수 있는 것
- **이모트·하이파이브**(EMOTE-2) · 정해 둔 말(빠른 말 칩)
- **선물:** 친구에게 E → 가방에서 하나 고름 → 친구가 '받기'를 눌러야 옮겨짐 · 하루 셋까지 · 돈은 못 줌(경제 지킴) · 받은 것은 '○번이 준 것'으로 수첩에 남음
- **같이 보기:** 쇼·불 끄기·두레는 함께 하면 같은 화면·같은 결과
- 못 하는 것: 밀기·막기·가져가기·부수기·남의 마당 바꾸기·자유 채팅

## 6. 선생님 칸(선생님 비밀번호 · 함께하기 메뉴)
모두 멈춤(입력 멈춤 + "선생님 말씀 들어요" 배너) · 모두 모이기(정한 자리로) · 시간·날씨·계절 바꾸기(HOST-1 뒤 = 선생님 방의 방장인 선생님 기기에서 바꾸면 방 모두 따라옴 — 따로 신호 X) · 마을 사건 시작 · 반 투표 열기/닫기 · 방 닫기 · 한 번호 내보내기(안전) · 반 결정 되돌리기.
선생님 기기가 꺼져도 방 문서는 남음(멈춤 중이면 멈춘 채).

## 7. 들어오기·끊김
- 들어올 때: 방 문서 읽기 → 시계·날씨·계절·반 결정 맞춤 → 내 저장 불러오기 → 친구 몸 보이기 시작.(HOST-1 = 마을에 들어오면 시계 주인 알림을 받아 시각·날씨·계절을 맞춤 · 1분 넘게 다르면 2초쯤에 걸쳐)
- 방을 나가면(HOST-1): 그 순간의 시각·날씨로 내 시계가 이어서 흐름(튐 X · 내 판에 저장 · 그날 날씨는 그대로 · 다음 아침부터 내 예보·달력).
- 끊기면: 마지막 시계로 혼자 계속(배너 "인터넷이 끊겨 혼자 하는 중") · 진행은 각자 저장이라 잃는 것 0 · 다시 이어지면 시계·날씨를 방에 맞춤(갑자기 튀지 않게 2초에 걸쳐).

## CLASS-MP(11-14) 반 코드로 저절로 함께
교사 11-14 '반 코드와 번호로 들어온 아이는 방을 고르지 않아도 같은 반 친구가 보이게'. 정본 코드 = `v2/games/town_classmp.js` · `v2/js/net.js`(`o.cls`) · `server/cf-rooms/src/index.js`(반 방·입장표·`/tset`).
- **들어오는 길 = 0걸음**: 반 코드(`?cls=`) + 번호 + 핀으로 판을 받은(`/load` 핀 확인 · 판이 없으면 첫 `/save`) 아이 = 마을에 서는 순간 같은 반 방 `c` + 16진 7자(반 코드의 PEPPER 해시 · 반 코드를 거꾸로 못 앎)에 웹소켓으로 붙음. **Firebase는 하나도 안 씀**(명단·박동·이모트·채팅 X · 시험에서 `/metaverse/rooms` 요청 0). 저장 칸(반 코드 없음)·공개판·홍보판은 예전 그대로(아예 안 만듦).
- **이름 대신 번호**: 머리 위 「7번」(영어 「No. 7」 · 지금 이름표 틀 · 40m 안) · 번호는 서버가 **입장표에서** 읽음(보낸 `u`는 버림) → 다른 번호인 척 X · 핀을 모르면 못 들어옴. 이모트 = 웹소켓 `{t:'e', m: 번호}`(반 방은 서버가 그 밖의 칸을 버림 = 자유 글 X).
- **입장표**: `/load`·`/save` 답의 `mp = {r, tk, u}`(메모리에만) · 표 = `번호.날.서명`(PEPPER HMAC · UTC 날 그날과 다음 날) · 틀리거나 없으면 4004로 닫음 → 화면은 조용히 혼자(새 표를 받았을 때만 한 번 더 · 같은 날 표는 같은 글이라 되붙기 고리 X). 같은 번호가 다른 기기로 들어오면 먼저 것을 4005 + 「다른 기기에서 들어왔어요. 여기서는 혼자 놀아요」.
- **보이는 것**: 가까운 10명 몸(NET-CF3) · 작은 지도·큰 지도 친구 점(있는 점 틀) · 같은 세계끼리만 · 웹소켓 명단에 있는 동안은 가만히 있어도 안 숨음(반 방만 · 예전 방은 5분 규칙 그대로). **세상 시계·날씨는 아직 각자** — `mp-in`을 켜지 않아 잠·기다리기도 각자(다음 걸음 = §9-1 · 함께하기 방은 HOST-1로 방장 시계 · 반 방은 방장이 없어 시계 주인 정하기부터 — 아래 HOST-1 '남은 것').

- **끄는 길 둘**: 선생님 칸 → 반 표 → ☁️ 서버(교사 열쇠로 받은 뒤) 「👥 우리 반 함께 보기 켬/끔」(`/tset` · 처음 = 켬) — 아이는 다음 `/load`·`/save` 답부터(놀던 아이도 3분마다 하는 확인 `/load`에서 몇 분 안에 나감) · 기기 하나 = 주소 `?mp=off`.

## HOST-1(11-14) 방장 시계 — 함께하기 방 안에서는 시각·날씨·계절이 방장 마을 기준
교사 11-14 밤 '같이하기 할 때는 시간 같은 거는 방장 기준으로 돌아가게 하면 될 듯'. 정본 코드 = `v2/games/town_host.js`(시계 주인 고르기·알림·따르기) · `v2/games/town_game.js`(`host`·`cont`·`guard`·`tag`·`minF`·`hostStep`) · `v2/js/net.js`(`fx` 칸 읽기 `fxPeers`·`srvNow`·`bornAt`·`myFx`) · `v2/games/town.js`(막기 자리·손님 밤 `hostNight`).
- **시계 주인**: 방장(방을 만든 기기 = `SM_MP.isOwner()`)이 마을(밖·실내)에 있으면 방장. 방장이 마을에 없거나(학교 맵 등 · 세계 머리표 's') 30초 넘게 소식이 없으면(창을 닫음 = 바로 · 끊김·숨은 탭 = Firebase 박동 20초 뒤) = **마을에 있는 기기 가운데 방에 먼저 들어온 기기**(들어온 시각 = 그 기기가 방에 붙은 때 + 서버 시각 차 · 같으면 id 순). 모든 기기가 같은 명단·같은 규칙으로 같은 기기를 고름(다투어 쓰기 X). 고른 기기가 30초 안에 시계를 안 쓰면 다음 기기. 마을에 나 혼자면 내 시계.
- **쓰는 칸 = 내 Firebase `players/<id>/fx`** — 방 통로(`rooms/c<번호>`) 그대로라 새 스트림 X(NET-2). `ctl`의 새 칸(`ctl/tw`)은 **DB 규칙이 막음**(match·cmd·chat만 받음 · zz 방에서 401 확인) → 규칙을 바꾸지 않으려고 사람 칸의 `fx`(규칙: q·s 숫자 · a·b = 숫자 열 칸 · 예전 마법사 마을 빛줄기 칸 · 학교·마을 방에선 아무도 안 씀)에 실음.
  `{ q, s: 분(소수), a: [날씨 0맑음·1비·2눈, 계절 0지금·1봄·2여름·3가을·4겨울, 멈춤 0·1, 잠 = 주인의 n일째, 방장 0·1, 방에 들어온 시각(서버 ms), 주인 0·1], b: [서버 시각(.sv)] }`
  - 마을에 들어오면 한 번(들어온 시각 알림 · 주인 0 · 서버에 없으면 5초마다 다시) · 주인이면 10초마다 + 바뀔 때(잠·날씨·계절·멈춤·밤/아침·기다리기로 3분 넘게 건너뜀·손님이 처음 옴 — 1초 칸이라 1초에 한 번까지).
- **손님이 따르는 것**: 시각 = 받은 분 + (지금 서버 시각 − 알림의 서버 시각)만큼 흐른 값 · 1분 안이면 그대로, 더 벌어졌으면 2초쯤에 걸쳐 앞뒤로 따라감(`hostStep` · 매 프레임 새 객체 X) · 자정은 넘지 않음(하루는 방장이 잘 때만) · 내 '시계 멈추기'·창 멈춤은 따르는 동안 안 씀.
  그날 날씨 = 내 판의 '그날 정한 날씨'(`setWeather` → `WXD9` · 저장 X · 예보 전선·아침 예보로 안 덮음 `wxHold`) · 계절 = 보기만(`setSeason` · 창·놀이가 없을 때 · 내 달력 X · 아침 다시 칠하기 안 함 `seaHold`) · 멈춤 = 같이(⏸).
  **주인이 자면**(주인 n일째가 늘면): 시계를 멈춰 두고(거꾸로 6시로 흐르지 않게) 창·놀이·대화가 끝나면(40초 넘으면 바로) 내 판 `GAME.sleep()` **한 번**(몇 밤이 지났든 · 보상 하루 한도 rwCheck는 그대로) → 아침 시각으로 따라감. 주인이 바뀌면 잠 셈은 새 주인 것으로(지난 잠 X · 기다리던 밤은 마저 지남).
- **손님이 못 하는 것**: 잠(침대·메뉴)·쉬기(저녁까지)·기다리기(이야기)·시계 멈추기·날씨·계절 단추 = 「⏰ 방장만 할 수 있어요. 시간과 날씨는 방장 마을을 따라요」(먼저 온 친구가 주인이면 「지금 시계를 맡은 친구만…」) — 새 창 X · 예전 mp-in 막기 자리(`waitTo`·이야기 `wait`)는 이제 손님만 막음(방장은 기다리기 됨).
