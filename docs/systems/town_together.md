# 👥 마을 함께하기 규칙(TOGETHER-1 · 10-18)

사용자 10-18: "함께하기 모드 하면 여러 가지 변수가 많을 것 같아 — 날씨·환경도 있고 퀘스트도 있고" · "함께하기 규칙 치밀하게 정해 — 기존 게임들이 함께하기 규칙이 좋지 않아서 좀 별로였던 것 같아 · 이거는 제대로 정하고 진행해"

먼저 `town_lessons.md`를 지킨다. 이 문서는 수업(한 반 20~30명 · 크롬북 · 선생님 한 분)을 기준으로 한다.

## 0. 다른 협동 게임이 별로였던 까닭 → 우리 규칙
| 흔한 실패 | 왜 별로인가 | 우리 규칙 |
|---|---|---|
| 친구마다 날씨·시간이 다름 | 같은 세상에 있는 느낌이 깨짐 | **세상 시계는 방에 하나**(§2) |
| 방장이 나가면 세상이 끝남 | 한 아이 때문에 모두 멈춤 | 세상 상태는 **방 문서**에 있음 — 누가 나가도 그대로 |
| 진행은 방장만 남음(손님은 남는 게 없음) | 손님 아이는 의욕이 없어짐 | **진행은 모두 각자 저장**(§3) |
| 한 사람이 창·컷신을 열면 모두 멈춤 | 기다리다 지루함 | **다른 사람을 멈추게 하는 건 선생님뿐**(§6) |
| 몸으로 문을 막기·밀기·가두기 | 괴롭힘 | 친구 몸은 **부딪히지 않음**(유령) · 카메라 앞이면 옅어짐 |
| 물건·돈 빼앗기, 남의 것 부수기 | 다툼 | 남의 물건을 가져가거나 부수는 길이 **아예 없음** · 주기는 받는 쪽 동의(§5) |
| 자유 채팅 | 욕·놀림 | **정해 둔 말·이모트만**(SAFE-1 · chatfilter) |
| 화면에 친구가 너무 많아 어지러움·렉 | 수업 30명 | **가까운 10명만 몸 · 나머지는 지도 점** · 이름표는 가까이서만 |
| 중간에 들어오면 꼬임 | 늦게 온 아이가 헤맴 | 들어오는 순간 방 시계·날씨·반 결정을 받아 맞춤(§7) |
| 인터넷이 끊기면 진행이 날아감 | 수업 망침 | 끊겨도 **혼자 모드로 계속**, 다시 이어지면 맞춤(§7) |

## 1. 방
- **방 만들기:** 선생님만(선생님 비밀번호). 방 코드 넷째 자리까지. 수업 방 = 반 하나.
- **들어오기:** v4 로그인 번호로 들어옴(이름 X · '○번'). 같은 번호가 두 기기에서 들어오면 나중 것만 남김.
- **크기:** 30명까지(무료 동시 연결 100 안). 새 연결(스트림)은 열지 않고 방 통로 `rooms/<방>` 하나에 얹음(NET-2).
- **방 문서:** `{ seed, clock: { t0, day0, min0, speed, paused }, wx, season, fixes, vote, event }` — 선생님만 씀, 모두 읽음.

## 2. 세상(모두 같이) — 방 문서가 정함
| 무엇 | 규칙 |
|---|---|
| 시간 | 방 시계 `t0` + `speed`로 **각자 기기가 셈**(계속 주고받지 않음) · 선생님만 바꿈 · `paused`면 모두 시계가 멈춤 |
| 날씨·예보 | 방 `seed` + 날짜로 정해짐(모두 같은 결과) · 선생님이 '오늘은 비'처럼 고정 가능 |
| 계절 | 방이 정함 |
| 장날·마을 사건(불 등) | `seed` + 날짜로 같은 날 같은 곳 · 불은 **함께 끄는 것**: 불 세기 하나를 모두 줄임 → 꺼지면 참여한 모두에게 '함께 껐어요' + 배운 개념 |
| 반이 정한 마을 변화(QUEST-2 지역 문제) | 함께하기에선 **반 투표 결과**를 모두 같이 봄(`fixes`) · 선생님이 투표 열기·닫기 · 혼자 할 땐 내가 고른 대로 |

## 3. 나(각자) — 절대 주고받지 않음
이야기 진행 · 가방 · 돈 · 솜씨·승급 · 도감 · 여권 · 수첩 · 학급 기록 · 내 마당 꾸미기. 친구와 다른 장을 해도 됨. 방을 나가도 그대로.

## 4. 함께하기에서 막히는 것·바뀌는 것
| 혼자일 때 | 함께하기 |
|---|---|
| 잠 → 다음 날 | **내 화면만 쉼**(시계는 안 감) · "친구들과 함께라 시간은 모두 같이 흘러요" |
| 날씨·계절 칩으로 바꾸기 | 칩은 보기만 · 바꾸기는 선생님 칸 |
| 이야기 '밤·비·계절 기다리기' | 방 시계를 따름 · 기다림이 3분 넘으면 "선생님이 밤으로 바꿔 줄 수 있어요" |
| J 바로 가기 | 그대로(내 몸만) · 선생님 '모이기' 중엔 막힘 |
| 실내 방 | 각자(친구는 안 보임) · 문 위에 "○번이 안에 있어요" 표 |
| 버스·지하철·배 | 각자 탐(친구는 안 보임) · 내리면 다시 보임 |
| 일 놀이·미니게임 | 각자 · 같은 일꾼에게 둘이 오면 **두레**(둘이 번갈아·같이 당기기 — 따로 만듦) |

## 5. 친구끼리 할 수 있는 것
- **이모트·하이파이브**(EMOTE-2) · 정해 둔 말(빠른 말 칩)
- **선물:** 친구에게 E → 가방에서 하나 고름 → 친구가 '받기'를 눌러야 옮겨짐 · 하루 셋까지 · 돈은 못 줌(경제 지킴) · 받은 것은 '○번이 준 것'으로 수첩에 남음
- **같이 보기:** 쇼·불 끄기·두레는 함께 하면 같은 화면·같은 결과
- 못 하는 것: 밀기·막기·가져가기·부수기·남의 마당 바꾸기·자유 채팅

## 6. 선생님 칸(선생님 비밀번호 · 함께하기 메뉴)
모두 멈춤(입력 멈춤 + "선생님 말씀 들어요" 배너) · 모두 모이기(정한 자리로) · 시간·날씨·계절 바꾸기 · 마을 사건 시작 · 반 투표 열기/닫기 · 방 닫기 · 한 번호 내보내기(안전) · 반 결정 되돌리기.
선생님 기기가 꺼져도 방 문서는 남음(멈춤 중이면 멈춘 채).

## 7. 들어오기·끊김
- 들어올 때: 방 문서 읽기 → 시계·날씨·계절·반 결정 맞춤 → 내 저장 불러오기 → 친구 몸 보이기 시작.
- 끊기면: 마지막 시계로 혼자 계속(배너 "인터넷이 끊겨 혼자 하는 중") · 진행은 각자 저장이라 잃는 것 0 · 다시 이어지면 시계·날씨를 방에 맞춤(갑자기 튀지 않게 2초에 걸쳐).

## 8. 화면·렉
- 친구 몸: 가까운 10명만(인스턴스 · 그리기 ≤ 11번 — TOGETHER-0) · 나머지는 작은 지도·큰 지도 점(번호).
- 이름표: 15m 안에서만 · 겹치면 옅게.
- 자리 보내기: 초당 4번 · 멈춰 있으면 안 보냄.

## 9. 짓는 차례
1. 방 시계·날씨·계절 하나로 + §4 막기(어긋남이 가장 눈에 띄는 곳)
2. 선생님 칸(멈춤·모이기·시간·날씨·계절)
3. 반 결정(투표 → 모두 같은 마을) + 불 함께 끄기
4. 선물·두레
- 시험: 브라우저 셋을 한 방에 넣고 → 시계 차이 1초 안 · 날씨 같음 · 한 명 나감·다시 들어옴 · 선생님 멈춤 · 끊김 흉내 → 상태 교차 하네스에 '함께하기' 상태 추가.
