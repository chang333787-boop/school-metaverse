## 네 기둥
1. 🗓 계획하는 하루 — 시간·체력·가방·기한이 모자람 · 고르지 못한 것이 내일
2. 🧠 알아내야 열리는 길 — 사건 수첩(소문/본 것) · 묶음으로만 확인 · 찍어서 X
3. 🧗 몸으로 자라는 능력 — 탐험 보상 = 실제 능력(헤엄·오르기·활공) · 실험 규칙으로 여러 방법
4. 🏘 내 결과가 남는 마을 — 사건·꾸러미·준비가 마을을 바꿈 = '나의 길' 여섯

지키는 선: 판타지·전투 X · 스트레스 = 시간이 모자람·다시 생각하기 · 벌·실패 화면·순위 X · 4학년이 해낼 수 있는 높이 · 막대·꾹 X(docs: memory feedback-productive-struggle)
