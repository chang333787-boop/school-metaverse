# 🎮 조작을 일반 게임처럼(CTRL-1 · 11-01)

교사 11-01: "지도 말고도 일반 게임하고 동떨어진 조작 요소 있으면 조사해서 고쳐야지."

- 견준 게임: 아이들이 익숙한 PC·태블릿 게임(마인크래프트 · 로블록스 · 동물의 숲 · 젤다 · 스타듀 밸리 · 원신 · 포트나이트)
- 코드: `v2/games/town.js`(keyDn · openP · footBtns·defBtn · dialog · 오른쪽 클릭) · `v2/js/main.js`(TWN_MODAL — 창이 떠 있으면 화면 누르기·Tab이 잠그지 않고 휠이 카메라를 안 움직임 · 마을 밖은 그대로) · `v2/games/town_tips.js`(⌨ 조작 도움 '창과 대화' 묶음)
- 시험: `zsh tools/ops/b2.sh node tools/harness/town_controls.cjs ourtown <포트>`
- 목적지 고르기 창(J·지도·F·흔적 지도에서 장소 누름)은 GO-1, 긴급 출동 따라오기는 그 팀 일 — 이 표는 겹치는 줄을 '남김'으로만 적음

## 1. 모든 창이 같은 규칙(고친 뒤)

| 하는 것 | 데스크톱 | 휴대폰 |
|---|---|---|
| 닫기(뒤로) | Esc · 머리 오른쪽 ✕ · 창 바깥 누르기 · 같은 키(I·M·J·F·Q·H) | ✕ · 창 바깥 톡 |
| 바깥 누르기 예외 | 창 안에서 누른 채 밖에서 놓음 = 안 닫힘 · 글 칸에 쓰던 글이 있으면 안 닫힘(한 줄 '✕나 Esc') | 같음 |
| 확인 | Enter = 기본 단추 | 기본 단추(초록)를 톡 |
| 기본 단추 | `data-def` 단추 → 아래 줄의 초록 단추 하나 → 초록이 없으면 닫기 · 초록이 둘 넘으면(고르기) 없음 · 사기(buy)·놓아주기(rel)·지우기(del)·처음부터(reset)·나가기(quit)·그만(stop)·다음에(no)는 기본 X(되돌릴 수 없는 것 · lessons E96) | |
| 알림 창(창 안 단추가 닫기·좋아요 하나뿐) | E · Space · Enter 모두 닫기(대화창·쪽지와 같게) · 연 지 0.3초 안의 키는 X | 톡 |
| 단추 차례(아래 줄) | [닫기·취소(왼쪽)] [보조] [기본(오른쪽 · 초록)] — CSS `order`라 모듈 HTML 차례와 무관 | 같음 |
| 단추에 손(포커스)이 있을 때 | Enter·Space = 그 단추(브라우저 그대로) | |
| Tab | 창이 열린 동안 = 단추 사이 옮기기(마우스를 잠그지 않음) | |
| 휠 | 창 위 = 창만 스크롤 · 창·대화·놀이 판이 떠 있으면 카메라 거리 그대로 | 두 손가락 = 창 스크롤 |
| 창 뒤로 새는 키 | E·숫자(도구)·이동 키는 창 뒤의 가게·문·도구로 안 감 | ✋는 창이 덮음 |
| 대화 넘기기 | E · Space · Enter · 대화창 클릭 · 빈 화면 클릭(고르기가 떠 있으면 X) · 1~4·방향키 = 고르기 · Esc = 끝 | 대화창 톡 · 빈 화면 톡 |

## 3. 새 창·새 조작을 만들 때
- 창은 `openP`로 연다(Esc·✕·바깥·Enter·Tab·휠 규칙이 저절로). openP를 안 쓰는 판(`.twn-play` 같은)은 `main.js` TWN_MODAL에 클래스를 더한다.
- 아래 줄(`.bx` 마지막 `.row`)에 단추를 둔다. 닫기·취소 = `class="sub" data-a="x"`(또는 `data-a="no"`) · 기본 = 초록(sub 아님) 하나. HTML 차례는 아무래도 됨(보이는 차례는 CSS가 맞춤).
- Enter가 다른 단추를 눌러야 하면 그 단추에 `data-def` · 되돌릴 수 없는 기본(사기·지우기)은 `data-a`를 buy·del 같은 이름으로(기본에서 빠짐) — 새 이름이면 town.js `NODEF9`에 더한다.
- 창 안에서 Enter·Space를 따로 쓰는 칸은 그 칸에 포커스(tabindex)를 두거나 글 칸(input)으로 — 창 규칙보다 먼저 받음.
- 새 키를 만들기 전에 이 표에서 그 키가 비었는지·관례가 무엇인지 보고, `town_tips.js` rows·TIP에 한 줄.
