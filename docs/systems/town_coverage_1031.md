# 메인 퀘스트가 마을을 얼마나 덮나(COVER-1 · 10-31)

사용자(교사) 10-31: "메인 퀘스트가 전반적인 모든 기능을 다 담는지는 잘 모르겠어. 지역도 이리저리 다 골고루 가고 그러는지 등. 메인 퀘가 절대적인 건 아니지만 오픈월드니까 그래도 그런 역할은 해야 하지 않을까. 메인 퀘 다 돌고 나서도 할 거 있으면 계속 플레이 시간을 유지하는 거고."

## 한눈 요약
1. **기능 83개 가운데 메인 퀘스트(20장·124단계)가 '써야 풀리게' 쓰는 것은 18개예요.** 일부만 쓰는 6개를 더하면 24개(29%)예요. 칩을 소개만 하는 것이 11개이고, 한 번도 안 나오는 것이 48개(58%)예요.
2. **지역 8곳(구역 7 + 판 밖 탐험 땅) 가운데 메인이 가는 곳은 6곳이에요.** 관광(나들터)과 판 밖(층층골·까망봉)은 0번이에요. 대표 장소는 53곳 가운데 22곳(일부 3곳 더)에 가요.
3. **가장 큰 빈틈 다섯**: ① 긴급·사건 엔진 8개가 0번이에요(1-1 '길 잃은 새 친구'는 112 엔진과 따로 놀아요). ② 도구 띠·화학 규칙·실험 표가 0번이에요(PLAN-1 기둥 ①②). ③ 관광·판 밖은 0번이고, 시내는 둘러보기·가게뿐이에요. ④ 내 집·아침 소식·하루 마무리가 메인과 안 이어져요(잠 1번 · 부엌은 실명 아이 집). ⑤ 4막·에필로그 5장은 몸·놀이 단계가 0이고, 잔치 엔진의 '첫 잔치'(14일째)와 피날레 '첫 잔치의 밤'이 따로 놀아요.
4. **다시 짜기**: 새 장은 0이에요(의뢰 하나를 메인으로 옮김). 있는 20장의 단계 목적만 바꿔 장마다 '처음 기능 하나 + 새 곳 하나'를 짝지으면 기능 56/83, 지역 8/8, 장소 30/53(일부 7)이 돼요.
5. **엔딩 뒤**: 잔치 엔진 14일 주기를 등뼈로 삼아요(지난 잔치 결과가 다음 잔치로 이어짐). 여기에 계절 두 번째 해·날씨 사건·동네끼리 교류 의뢰·장인 칭호를 걸어요. 고리 14개 가운데 6개는 지금 엔진 그대로, 6개는 조금 고치고, 새로 짓는 것은 2개(집 늘리기·협동 판)예요.
