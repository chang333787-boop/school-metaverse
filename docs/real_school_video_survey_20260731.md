# I. 전 구역 공통 요소 (반복 패턴)

이것들이 "학교 실내처럼 보이게" 만드는 기본 결이다. **현재 3D에 대부분 없다.**

## 1. 천장
| 요소 | 실물 | 현재 3D |
|---|---|---|
| 복도·교실 천장 | **흰 텍스처 타일**(작은 요철 무늬 사각 패널, 600각 그리드) | ❌ 단색 평면 |
| 급식실 천장 | **격자 우물천장**(정사각 함몰 패널이 바둑판으로) + **박공(가운데 높은 경사)** | ❌ |
| 신관 복도 천장 | **깊은 우물천장**(정사각 격자 요철, 급식실보다 깊음) | ❌ |
| 현관 천장 | **목재 루버**(가로 살 마감) | ❌ |
| 천장 설비 | **원형 스피커**, **화재감지기**, **스프링클러 노출배관 + 사선 브레이스**, 검은 사각 센서박스 | ❌ 전부 없음 |

## 2. 조명 — **현재 3D에 조명 기구가 사실상 없다**
| 위치 | 실물 |
|---|---|
| 복도 | **정사각 매입 형광등**을 천장 중앙선에 일정 간격 |
| 교실 | **긴 직사각 LED 평판등 6개**(2열×3줄) |
| 급식실 | 우물천장 격자 안에 **정사각 매입등 다수** + 커튼 앞 **트랙 스포트 1줄** |
| 계단실 | 계단참 천장 매입등 |
| 실외 | 조명탑(콘크리트 전주+4구), **더블암 가로등**, 현관 위 다운라이트 |

프로젝트 규칙상 Light를 늘릴 수 없으므로 **`lamp()` MeshBasicMaterial 판**으로 기구 형상만 재현하면 된다.

## 3. 냉난방·설비
- **천장 카세트 에어컨**(4방향 흰 사각 그릴) — 교실·급식실
- **벽걸이 에어컨**(흰 대형) — 창 위 높은 곳
- **천장 매달린 프로젝터**(비닐 씌움) — 교실
- **벽걸이 선풍기** — 교실 창측
- **정수기**(회색/검은 스탠드) — 교실·복도
- **소화기(빨강) + 소화기 표지 + 소화전(빨강 함)** — 복도·교실 곳곳
- **초록 비상구 유도등**(벽 부착, 화살표) — 복도·계단
- **손소독제 디스펜서**(검은, 문 옆 벽)
- **디지털 도어락**(검은 세로) — 신관 교실문·특별실

## 4. 바닥
| 구역 | 실물 |
|---|---|
| 구관 복도 | **흰 대형 타일(중앙) + 양쪽 검은 대리석 테두리 띠(폭 약 30cm)** ← 가장 강한 시각 패턴 |
| 신관 복도 | 베이지 대형 타일 + **짙은 회색 걸레받이 띠** |
| 로비·계단·2층 | **회색 테라조**(인조석) 대형 타일 |
| 교실 | **원목 마루**(신관=밝은 톤 / 구관=오렌지빛 톤) |
| 급식실 | 회색 테라조 |
| 유치원 복도 | 흰 타일 + 검은 띠 + **갈색 포인트 타일** |
| 공통 | **노란 점자블록**(출입구·계단 앞), **주황 유도선**, **노란 발자국 스티커** |

## 5. 벽 — 구역마다 다르다 (현재 3D는 전 구역 동일)
| 구역 | 실물 |
|---|---|
| **구관 복도** | **연두 세로골판 굽도리(≈1.1m) + 갈색 몰딩 띠 + 크림 상부 + 나무 핸드레일(둥근 원목 봉)** |
| **신관 복도** | 순백 벽 + 짙은 회색 걸레받이 + **붉은 벽돌 노출 기둥** |
| **계단실·2층 복도·급식동** | **상부 연민트 / 하부 노랑(머스터드) 2톤**, 경계는 허리 높이 |
| **유치원** | 베이지/분홍 패널 + **캐릭터 벽화** + 스테인리스 핸드레일 |
| **급식실** | 상부 회청색 + 하부 갈색 나무 웨인스코팅 |
| **현관 로비** | 크림 + **짙은 갈색 목재 몰딩·프레임**(기둥마다 케이싱) |

## 6. 창 — 종류가 5가지나 된다
1. **외벽 대형 창** — 갈색(브론즈) 알루미늄 3~4연, 흰 인조대리석 창턱
2. **란마(문 위 고정 유리창)** — 교실문·급식실문 위 가로 유리 2~3짝
3. **실내창(복도↔교실)** — 복도 사물함 **위**에 유리창 줄. 교실 초록칠판이 비쳐 보인다
4. **격자 무늬 반투명 유리** — 교무실·행정실 등 사무공간 실내창
5. **고측창** — 체육관 벽 상부 작은 창 1열
+ **계단참 대형 창**(3×3 격자 9칸 + 하부 수직 창살)
+ **2층 복도 유리 난간**(반투명 격자 무늬 유리)

## 7. 게시물·팻말 — 위치가 일정하다
- **천장에서 내려오는 파란 세로 팻말**: 행정실·당직실·급식실·도서관·유치원·원무실·학년
- **초록 대형 게시판**: 복도 벽·현관 로비 (학생 작품 액자 다수)
- **창턱 위 학생 작품 전시**: 석고 부조판, 계획표 — 신관·동관 복도
- **교실 뒤벽**: 회색 펠트/코르크 게시판 + 원형 벽시계 + 한글 자모 카드 줄
- **문 옆 아크릴 가로 명패**
- **금색 프레임 액자**(상장·표창) — 구관 복도
- **스탠드 배너**("사이버 폭력 예방", "화성오산교육")
- 벽 부착 **A4 문서 액자**(안전점검표 등)

## 8. 사물함 — 3종류
| 위치 | 형태 |
|---|---|
| **복도(창 반대편)** | **원목색 3단 개별 락커** + 손잡이 + 곰돌이 이름표. 그 위 스테인리스 상판, 그 위 실내창 |
| **교실 뒤벽** | **흰색 개별 사물함** 2~3단 × 10칸 이상 (원형 손잡이) |
| **구관 복도 창 아래** | **짙은 갈색 목재 수납장** 연속 줄 |
| **현관** | **원목 신발장** 3단 × 여러 열, 칸마다 이름표 |

# V. 확인 필요

1. **2층 범위** — 정면상 2층은 중앙~서쪽 구간뿐, 동쪽 절반은 단층. 2층 복도는 **운동장(남)을 보고 외부 발코니 난간**이 있다. data.js의 "서관 위에만 2층"과 어긋날 수 있어 배치도 대조 필요.
2. **체육관 x 좌표** — 광각 왜곡 때문에 영상만으론 못 정한다.
3. **도서관 내부·화장실 내부**는 영상에 없다(문까지만). 별도 촬영 필요.
4. 중정 유리문 프레임에 촬영자 반사가 있다 — 공개물 사용 금지.
