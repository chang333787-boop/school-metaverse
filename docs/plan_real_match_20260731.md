## 3. 사용자 확인이 필요한 것

1. **#33 2층 계단** — 코드는 서관 실내 12단(남→북). 영상은 급식동/당직실 지나서 계단이고 2층 복도가 운동장(남)을 본다. **계단이 실제로 어느 동 어디에 있는지** 알려주세요.
2. **#8 체육관 내부** — 영상에 없습니다. "입구→복도(양쪽 화장실)→문→본실"에서 복도 길이·화장실 위치를 대강이라도.
3. **#30 창고** — 동관 안의 '창고'(복도와 분리, 북쪽 외부문)와 텃밭 옆 **노란 컨테이너**가 같은 것인지 다른 것인지.
4. **#35 도서관 앞 구조도** — 어떤 구조도(학교 배치도?)가 도서관 앞 어디에 있는지.
5. 2층에 실제로 무슨 실이 있는지 (현재 6학년/5학년/소담실).
